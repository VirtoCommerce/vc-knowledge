It depends on the list's scope, and the platform answers three different ways to the same anonymous request. Scope AnyoneAnonymous: sharedWishlist resolves in full for a caller with no account at all - list name, every line item with sku, images, all product properties, availableQuantity, salePrice/listPrice and a subtotal. Scope Organization: the field errors with extensions.code Unauthorized, 'Anonymous access denied or access token has expired or is invalid', raised by XCart's PurchaseSchema.AuthorizeAsync, and the storefront turns that into a redirect to /sign-in?returnUrl=. Scope Private: HTTP 200, no error at all, data.sharedWishlist null, which the storefront renders as 404. Two consequences. First, no account is needed for an Anyone list, so that scope is genuine public exposure of store prices under a guessable-length GUID. Second, the null and the Unauthorized are distinguishable, so an anonymous holder of any key can tell an organization-scoped list that exists from a private one, without being able to read either.
