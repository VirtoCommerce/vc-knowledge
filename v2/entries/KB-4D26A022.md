No. A shipment created by checkout is born EMPTY: its items collection is [], however many line items the order has. The order line items are not copied, referenced or split into it. Allocation is a separate, manual act -- in Admin the shipment's line-items grid starts with zero rows and an Add item button, whose picker lists the order's line items with an editable Qty and an Avail column showing the quantity not yet placed on any shipment. So a shipment is a fulfilment INTENT carrying method, address and money, and the item-level allocation happens later and by hand; an agent that reads shipment.items to learn what was ordered gets nothing, and must read the order's own items instead. This also means shipment item quantity is free to differ from order line item quantity, which is what makes partial shipments expressible.
