The platform serves GraphiQL at /ui/graphiql - not /graphiql, not /ui/playground, both of which 404 - and it accepts the operation as a ?query= URL parameter, so a whole query can be delivered by navigation and then run with the single Execute button. What matters is the principal: it sends NO credential, so it executes as Anonymous even when the Admin SPA is signed in in the same browser, because the Admin SPA holds its bearer token in memory rather than a cookie. Query.me there returns userName Anonymous and isAdministrator false. That makes it an excellent lane for establishing exactly what an unauthenticated caller can reach - and a dead end for anything gated, which for XCart's wishlist fields is all of them: both Query.sharedWishlist on a non-public list and Mutations.createWishlist return extensions.code Unauthorized with an XCart PurchaseSchema.AuthorizeAsync stack. Authenticating it means pasting a bearer token into its Headers tab, which is the thing to avoid; use it for the anonymous half of a question and a real client for the rest.
