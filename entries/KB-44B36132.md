With an admin bearer token, GET /api/platform/settings/Authorization.EnablePersistentStorageTokenValidation and GET /api/platform/settings/VirtoCommerce.Platform.Security.PasswordHistory both answered HTTP 500 with body {"message":"Setting with name <name> is not registered","stackTrace":null}. Authorization:EnablePersistentStorageTokenValidation is an appsettings key, not a registered platform setting, so its value cannot be read through this API. GET /api/platform/settings?names=<that name> ignored the filter and returned an unfiltered list of registered settings (200). A missing resource is reported as a server error rather than 404.
