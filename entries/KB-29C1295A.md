Created a contact via POST /api/members (memberType Contact, two organizations in contact.organizations, no status field -> status null) plus a Customer user for B2B-store. Password sign-in issued a token (POST /connect/token 200), but the following GetMe (POST /graphql, Query.me) returned HTTP 200 with data AND errors[]: 'Error trying to resolve field selectedAddressId', path me.contact.selectedAddressId, code INVALID_OPERATION; the storefront stayed on /sign-in with the toast 'Something went wrong. Please try again later.'. After PUT /api/members with status=Approved on the same contact (nothing else changed) the same session/sign-in worked normally. A sibling contact created in the same run WITH status Approved never hit it.
