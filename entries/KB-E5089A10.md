Signed-in B2B buyer, /bulk-order, Copy&Paste mode. Submitting only valid SKU,qty lines added them and navigated directly to /cart with no modal. Submitting one invalid SKU (alone, or together with a valid one) showed a dialog titled "Add to cart SKU errors" listing the SKU as "Invalid product" with only a Close button (the valid line was still added to the cart). The "Adding products to cart result" modal with View cart / Print / OK is opened instead by "Add all to cart" on /account/saved-for-later (also used by list details and, for Completed orders only, Reorder all on order details) — that is the route to test the View cart button layout.
