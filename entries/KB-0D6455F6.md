Guest, Edge 1920x1080, 3 iPhones (iPhone 8, SE 2022, XR) in one compare tab. All showed 9 rows; values differed only for Price per unit, SKU and Cellular; Availability read 1454 In stock for all three. The line read 'Differ: 3 of 9 rows'. Clicking Differences showed 4 rows: Price per unit, Availability, SKU, Cellular, so the identical Availability row stayed. After pinning the identical Brand row, Differences showed 5 rows (Brand first) and the line still read 3 of 9. Reproduced 3 times, including after a reload. The source at the deployed build matches: N counts rows with differs=true, and the filter keeps differs rows plus a fixed list [price, availability] plus pinned rows. The same logic is in vc-frontend 2.59.0 and 2.60.0, so it is not specific to this PR build. When Price and Availability both differ and nothing identical is pinned, N equals the shown row count.
