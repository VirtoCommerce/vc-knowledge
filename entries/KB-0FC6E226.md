In Stores > store > Payment methods (and Shipping methods) the list grid shows an Is active checkbox column that does not react to clicks. Opening a method row shows a detail blade with an Is active switch; toggling it and pressing Save changes isActive (POST /api/payment/search or /api/shipping/search with storeId reflects it) and the xAPI cart availablePaymentMethods / availableShippingMethods change immediately. GET /api/stores/{id} no longer carries paymentMethods/shippingMethods arrays.
