Anonymous Query.store(storeId).settings.authenticationTypes on all 12 stores contains "Passkey". 11 stores with no saved authentication schemes answer ["GoogleSSO","Passkey","Password"] (priority descending, then display name, so Password is last and GoogleSSO first). The one store with saved schemes answers ["Password","GoogleSSO","Passkey"]. GET /api/store-authentication-schemes/{storeId} shows Passkey isActive=true with id null / createdDate 0001-01-01 (not persisted) and position 0, equal to the saved Password position 0. GET /api/platform/security/sign-in-methods (anonymous) returns Passkey priority 0 and Password priority 0, GoogleSSO priority 2. Before this change Password was always first. The Passkey module registers no setting and no permission (platform settings and permissions listings contain none), so the per-store switch is only the store authentication scheme.
