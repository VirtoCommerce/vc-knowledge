Build 3.0.0-alpha.2685 (vc-frontend-next), guest, Firefox 375x812. Opening Main menu moves focus to the panel (nav.mobile-menu__panel, tabindex=-1, aria-label 'Main menu', no role, no aria-modal). Tab order inside: Theme toggle, language selector, Close, then menu links, last is Settings on the home page (or 'View all products in the category' when the Catalog submenu is auto-expanded on /catalog). The next Tab leaves the panel into main content (home: 'Browse catalog'; /catalog: breadcrumb Home, Open filters, Switch to grid view) whose boxes all sit under the 94%-opaque panel, so the focus ring is not visible. Shift+Tab from the panel or from its first control goes to header Cart / Toggle search bar, also under the panel. main, header and footer carry no inert and no aria-hidden; body overflow is hidden. Escape closes the menu even when focus has escaped, and returns focus to the Main menu button. Not a keyboard trap; a focus-order / focus-obscured gap.
