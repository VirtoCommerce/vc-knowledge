On a stand where the Skyflow module (3.1005.0) is installed but the deployment config carries none of the Payments__Skyflow__* keys (tokenURI, vaultURI, gatewayURI, vaultId, tableName, TargetPaymentMethod, TargetConnectionRoute), the storefront still offers "Pay with Skyflow" on /cart; selecting it leaves the PAYMENT CARD block on "Loading...", shows a "Payment method is unavailable" toast, and Mutation.initializeCartPayment answers with a NULL_REFERENCE error. A stand that has the full Payments__Skyflow__* set does not show this. So this symptom points at missing Skyflow configuration on the deployment, not at a Skyflow code defect — check the stand's platform config before filing.
