On vcptcore_qa1 (theme 2.62.0-pr-2552-942a) a B2B buyer placed an order with a payment method that needs no card; its details page /account/orders/{id} (status New, unpaid) offered only 'Pay now' and no 'Cancel order', also after a reload. The theme source has no buyer cancel action: order-details.vue only renders an existing order's cancelReason when the status is Cancelled. A test that needs a cancelled order must cancel it the way an administrator does (Admin order blade Cancel, or PUT /api/order/customerOrders with isCancelled=true + cancelReason); setting only status=Cancelled is not a cancellation for the account dashboard figures.
