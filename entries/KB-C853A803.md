Signed-in B2B buyer, theme 2.59.0: category page and /search?q=hoodie toolbars show only 'Show in stock' and 'Available at branches'; no 'Purchased before' checkbox. The store setting Order.PurchasedProductStoreFilter.Enable (VirtoCommerce.Orders) was unset (null, default false). vc-frontend category-controls.vue renders the checkbox only when that module setting is enabled (usePurchasedBefore.ts). A missing checkbox on a store with the setting off is configuration, not a defect.
