Set VirtoCommerce.Search.ElasticSearch8.NGramTokenFilter.MinGram to 3 (was unset, default 1) in Settings and saved. Nothing changed until a Delete and build of the Category type; after it, 2-character keyword prefixes in xAPI Query.categories returned 0 while 3+ character prefixes were unchanged. With IndexTotalFieldsLimit=10, Delete and build of PickupLocation failed with "Failed to submit mapping ... (400) on PUT ...-backup/_mapping" and the active index stayed intact (blue-green). The settings blade's "Reset to default value" needs Save, and afterwards the API returns the default value (1, 50, 1000) rather than null. Rebuild the type again after restoring, or the changed analyzer stays in the backup slot.
