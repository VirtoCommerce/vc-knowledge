Read from the rendered head after hydration (signed-in buyer, B2B-store). A published plain Page Builder landing page and a multilanguage Page Builder page emit og:site_name only (no og:url, no rel=canonical; the multilanguage page adds hreflang links) and the document title stays the generic 'Virto Commerce'. PDP and category pages on the same build emit og:url equal to their own absolute URL (with the /fr/ prefix under French) and a store-prefixed title. A Page Builder page on a second stand running theme 2.61.0-pr-2570 (without the multilanguage change) showed the same generic title and no og:url, so the gap predates the multilanguage feature.
