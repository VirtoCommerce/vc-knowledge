Admin token, POST /api/order/customerOrders with currency GBP (platform currencies were USD, EUR, XPT) and one line item: HTTP 500 {"message":"Sequence contains no matching element"}; no order created. Workaround that works: create the currency (POST /api/currencies, e.g. ISO test code XTS), create the order in it, then DELETE /api/currencies?codes=XTS — the order stays, now in an unconfigured currency, and DELETE /api/order/customerOrders still removes it afterwards.
