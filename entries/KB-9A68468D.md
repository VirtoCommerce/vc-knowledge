Signed in as a sales rep (B2B store, org with 8 orders), applied Custom date 10/01/2026-10/13/2026 via the Filters popover. Reopening the popover three times (closing each time by clicking outside) showed Start/End preserved as 10/01/2026 and 10/13/2026, no validation message, and Apply DISABLED every time (Reset enabled). Ticking a status checkbox enabled Apply; unticking it again disabled Apply. So Apply reflects 'pending changes vs applied filters', not range validity; an unchanged, valid applied range reopens with Apply disabled. A separate observation in the same popover: a single typed bound (Start only or End only) leaves Apply disabled until the input is blurred, while typing the second of two bounds enables Apply live before blur.
