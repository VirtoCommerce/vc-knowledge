As administrator over REST: POST /api/assets/folder rejects a name like 'tpl-{{=window.x=1}}' (400, lowercase validator), but a multipart POST /api/assets?folderUrl=<parent>/tpl-{{=window.x=1}} uploading a file returns 200 and creates that folder, and file names such as 'tpl-{{=window.x=2}}.png' are accepted. Uppercase folder names (e.g. AGENT-TEST-...) are likewise created by upload. The upload response carries createdDate 0001-01-01 and size 0; the real dates/size appear only in the GET /api/assets listing. DELETE /api/assets?urls=<folder url> deletes a non-empty folder recursively, but the parent listing can still show the deleted folder for a few seconds.
