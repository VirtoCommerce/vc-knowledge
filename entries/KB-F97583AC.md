I signed in on desktop (1920) as a user with two Approved, unlocked organization memberships. xAPI GetMe returned contact.organizations.totalCount=2 with no errors. The account-menu dialog on home, /account/dashboard and /compare showed the name plus the current organization as a subtitle, then Purchasing / Marketing / Corporate / User / Logout. It had no Organizations list, no organization radios and no organizations-search. At 390px the main menu → Corporate → "My organizations" listed both organizations as radios with the current one checked. Source at vc-frontend-next d67b0e0a: header-account-menu-panel.vue renders TopHeaderOrganizations only if IS_ORGANIZATION_SWITCHER_SHOWN && isMultiOrganization, and the constant is hard-coded false (commit d5cc49aa, VCST-6030, "hold the organization switcher out of the account panel" pending design). So desktop users cannot switch organization. VirtoOZ documents the switcher under Organizations in the account menu, and upstream vc-frontend 2.60.0 still renders it there.
