On PageBuilderModule 3.1033.0-pr-170-236e (2026-10-08), Admin Content workspace (#!/workspace/content) > store > Pages > click contacts.en-US.page or homepage.page (both Published) opens a page blade titled 'New page' with Relative path / File name / Language / Permalink and toolbar Save, Reset, Preview page, Design, Unpublish, Search index. The blade calls GET /api/pagebuilder/git/publish-status (200), GET /api/pagebuilder/template?draft=true (200) and GET /api/pagebuilder/git/legacy-draft?path=...&storeId=...&type=pages, which returns 404 with an empty body; the platform shows a '404: Not found' notification (View details / Dismiss) and logs a console resource error. Reproduced on two pages. Not yet compared against a non-PR build.
