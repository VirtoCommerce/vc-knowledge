The Admin back-office login page HTML embeds the running platform version as a Version string, and it is the only anonymous way to read it. /api/platform/modules requires authentication and carries module versions only, and /api/platform/version does not exist (404). /health can keep answering 200 from the old instance while a restart is still under way, so it does not prove a new build is serving.
