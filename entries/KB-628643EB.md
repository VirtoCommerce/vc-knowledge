Theme 2.60.0-pr-2543-fdab-fdabd62d, Chrome 1920, guest, /agent-test-ga4-html-product-lists. As a DevTools probe (no user path), changing the first card's data-product-price in the id-less list agent_test_html_partial from 8.85 to 9.99 pushed exactly one new view_item_list for that list with the new price, and none for the id-carrying list; setting it back to 8.85 pushed one more (the comparison is against the last sent set, not the first). Changing a card's data-product-price in the id-carrying list agent_test_html_full (data-product-id present) to another value pushed nothing: id-keyed lists compare by id only, so a price-only change is not re-reported. DOM churn without a value change (header search dropdown, currency dropdown, menu, theme toggle) pushed nothing for either list.
