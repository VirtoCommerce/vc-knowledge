Adding the same product twice to a cart consolidates into one line with the summed quantity, so itemsCount does not count adds; subtotal arithmetic is a sturdier signal. A configured line item is never consolidated: re-adding an identical configuration, and merging carts, always create a separate line, BY DESIGN - the existing-line lookup skips configured items and the configured-item add always inserts a new line, with no comparison of configuration content. Configurations that differ are of course separate lines as well.
