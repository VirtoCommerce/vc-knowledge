First name and Last name render a red required asterisk and are validated by vee-validate: Save stays disabled while either is empty (on a NEW rep and when clearing the value on an EXISTING rep), and an inline error renders under the field reading 'The firstName field is required' / 'The lastName field is required' -- the raw camelCase model key, not the visible label. Length caps are enforced on typed input: First name truncates at exactly 128 characters (220 typed) and Salutation at exactly 256 characters (300 typed). Observed on VirtoCommerce.SalesRep 3.1011.0-pr-17-47fb, @vc-shell/framework v2.6.0.
