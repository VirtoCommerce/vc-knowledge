GET /ucp/v1/carts/{cartId} binds only store_id, currency and culture_name from the query string, so an anonymous caller cannot pass buyer_id and always gets 400 invalid_request 'buyer_id is required for anonymous continuation.' The MCP get_cart tool accepts buyer_id and reads the same anonymous cart. X-Buyer-* headers are rejected by design.
