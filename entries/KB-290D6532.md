2026-10-14 07:53-08:08Z, B2B-store, buyer signed in. Query.fileUploadOptions(scope:"product-configuration") returned null (GetFileUploadOptions in the HAR). On the PDP of a configurable product, both an optional and a required File section render the drop zone with the "Browse your files" button disabled and an amber warning "File upload is not available." (data-test-id file-uploader-unavailable) in place of the formats/size requirements line. Clicking the area opens no file chooser, a drag-and-drop of a PDF is refused (dragover not accepted), and 0 POST /api/files/product-configuration were sent across 3 reloads. An optional section keeps "None" checked and Add to cart works; a required section keeps Add to cart disabled with the checklist "ID Proof - required / Upload a file", so it cannot be completed. German locale shows "Das Hochladen von Dateien ist nicht verfügbar." Registered scopes on the same stand (quote-attachments, return-attachments, organization-logos) keep a working picker.
