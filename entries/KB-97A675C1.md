Approved is pre-filled with the requested quantity; one click commits at once with no confirmation dialog, sets return status Approved/PartiallyApproved/Rejected, locks Quantity/Approved/Decline reason read-only, and writes a ReturnApproved/PartiallyApproved/RejectedEmailNotification journal entry within ~1s (7 of 7 observed). Decline reason input enables only when Approved < Quantity.
