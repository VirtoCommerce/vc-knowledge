Yes. On Return 3.1003 a return created through PUT /api/return (no id, status New, quantity 1 of a line ordered and delivered 20) made returnableItems(orderId) report returnableQuantity 19 for that line, isReturnable still true. POST /api/return/search with orderId returned exactly the returns of that order. DELETE /api/return?ids= followed by deleting the order left no residue; deleting the order alone leaves returns whose Order number and Customer are empty in the Admin returns grid.
