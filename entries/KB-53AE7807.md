No. On vc-frontend 2.60.0-pr-2511-81f1 a failed upload in a configurable product File section shows 'Unknown scope ''.' although the 200 response carries errorParameter 'product-configuration', and an oversize file shows 'File size exceeds the allowed' with no limit. The en.json strings use positional {0}; useErrorsTranslator turns errorParameters into a named object {"0": value}, so the placeholder renders empty. Pre-existing (translator unchanged since 2025-01); filed as VCST-6281.
