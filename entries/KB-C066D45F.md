On vcst_qa with PageBuilderModule 3.1033.0-pr-170 (2026-10-08), opening a Published page's details blade (#/page-builder-active/details/{id}), expanding Scheduling and picking a new Start date (10/15 or 10/16) in the date picker shows the new value in the input, but the blade Save button stays disabled; closing the blade gives no unsaved-changes prompt and reopening shows the original date. Editing the Name field in the same blade does enable Save, so the blade is editable — only the date-picker change is not registered. Scheduling dates therefore cannot be changed from this blade by a user; treat as a suspected defect until confirmed.
