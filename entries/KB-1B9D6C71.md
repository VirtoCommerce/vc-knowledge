Admin token, TaskManagement 3.1005.0. POST /api/task-management with {name, priority:"Normal", type} and no isActive answered 200 with isActive:false, and a GET read isActive:false. WorkTask.IsActive is a plain bool with no initialiser (source at tag 3.1005.0, WorkTask.cs:26) and Create sets nothing, so the C# default false is stored. A client that wants an active task must send isActive:true (as the Admin app and earlier kb entries do). Consequence for tests: a REST-created task without isActive is already 'archived' by isActive and an isActive:false assertion after finish passes vacuously.
