Read through GET /api/platform/settings/modules/VirtoCommerce.SiteBuilder as admin: the module exposes the global settings SiteBuilder.General.OzAgentUrl, SiteBuilder.General.StoreUrl and SiteBuilder.General.StorePreviewPath. OzAgentUrl was empty on vcst_qa at 12:30Z and later held the Virto OZ production address (set by an operator during the day); that address answers 200 with cross-origin-embedder-policy credentialless and cross-origin-resource-policy cross-origin, as the iframe embedding needs. The module README (site-builder#1 @ 28d00e0) says Site Builder copies Page Builder's OzAgentUrl, StoreUrl and StorePreviewPath once on first start where it has no value of its own; on Page Builder stands vcptcore_qa1 and vcptcore_regression PageBuilderModule.General.OzAgentUrl is empty, so nothing is copied there. The assistant's tools also need builder:read (and builder:create / builder:update / builder:publish for writes), per docs/ai-assistant.md. Not observed: the assistant panel actually opening or acting.
