With an admin token, GET /api/platform/modules returned VirtoCommerce.SalesRep with version "3.1013.0-pr-18-d367" — the full prerelease build string (base 3.1013.0 plus the -pr-<number>-<short sha> suffix), identical to the version in the module's AzureBlob BlobName pinned in vc-deploy-dev backend/packages.json, so declared and deployed compared equal. It is not reduced to the base version, so matching a PR artifact needs the exact string; a semver comparison that reads the suffix as numbers treats a different PR build of the same base as newer. Published guides describe prerelease tags only as -alpha/-beta/-rc.
