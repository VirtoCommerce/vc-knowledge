A file page (saved through POST /api/pagebuilder/save draft=true, published through /api/pagebuilder/git/publish) and a database page (saved through POST /api/page-builder-pages/grouped/{groupId}/content, published through /grouped/publishing/{groupId}?publish=true) each got five extra sections: type unknown-section; title with heading "script"; text whose HTML held an iframe, an img with onerror, an a href=javascript: and an a href=sms:, plus an undeclared "data-qa" setting; call-to-action with buttons javascript: and mailto:; slider with a javascript: slide url. The server stored the content unchanged. On the storefront both pages rendered the same way: no element for the unknown section; the title rendered as h2; the text kept <img src="x"> without onerror, dropped the iframe, and rendered the javascript: link as <a> with no href; the sms: link and the mailto: button stayed working links; the javascript: CTA button rendered as a <button> with no href; the slide had no anchor; no data-qa attribute. Clicking each unsafe element logged nothing and did not navigate; the console showed no SyntaxError. Every section root still carries attributes model and settings with the value [object Object].
