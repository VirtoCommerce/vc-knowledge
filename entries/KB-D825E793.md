Signed in as admin, opened Configuration > Stores > B2B-store > Settings widget in the Admin Shell. The blade showed a flat list of accordions keyed by leaf group name (Application Insights, General, SEO...) with only Save/Reset in the toolbar. There was no search box, no module>group tree, no modified dot, no per-setting reset and no Edit as JSON. The dictionary setting 'Purchase request source statuses' rendered the literal text "null" in its combobox. The classic store Settings widget (#!/workspace/store) on the same stand has search, a module>group tree, blue modified dots, per-setting reset icons, Edit as JSON and a pencil that opens the allowed-values dictionary editor. The shell's global Settings blade (#/settings) has search, a tree with modified counts, a Modified filter, 'Reset to default' per setting, Export/Import JSON, Edit as JSON, Reset cache, and 'Edit values' on dictionary settings. It has no Restart, which classic global Settings has.
