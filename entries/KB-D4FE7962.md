On vcst_qa (PageBuilderModule 3.1033.0-pr-170-236e, Platform 3.1076.0), opening the existing published pages homepage.page and contacts.en-US.page for store B2B-store from Admin Content > Pages sent GET /api/pagebuilder/git/legacy-draft?path=...&storeId=B2B-store&type=pages, and each request returned 404 (network log, regression run REG-2026-10-08-0812, case BSM-083). The source shows this is intended. PageBuilderController.GetLegacyDraft returns NotFound when gitContentPolicy is not enabled for the store, because on the blob flow a "-draft" file is the live draft, not a leftover. The edit-page.js loadLegacyDraft error callback deliberately swallows the 404 so it shows no banner. The page blade still loaded with Preview, Design and Unpublish enabled. So this 404 alone is not a defect. A user-visible error toast on that 404 was claimed but did not appear in the captured screenshots, so it is unconfirmed.
