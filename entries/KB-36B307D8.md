Module VirtoCommerce.SqlQueries 3.1006.0-pr-25-6559 (adds setting SqlQueries.General.CommandTimeout) on platform 3.1078.0, Linux container, SQL Server. With timeout 10 and query "WAITFOR DELAY '00:00:15'; SELECT 1", POST /api/sql-queries/execute-preview, POST /api/sql-queries/execute-query/{id} and POST /api/sql-queries/execute/{id}/{xlsx|csv} each return HTTP 500 after ~10 s with body {"message":"Unknown error 258","stackTrace":null}. The platform log shows SqlException "Execution Timeout Expired. The timeout period elapsed prior to completion of the operation or the server is not responding." with inner Win32Exception (258) "Unknown error 258"; the response carries the inner exception's message, so the caller never sees the word timeout. With timeout 60 the same calls return 200 after ~15 s; with the default 30 a 35 s query fails at ~30 s.
