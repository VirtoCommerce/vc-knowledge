Read in vc-module-x-cms at commit 35cb129 (PR #28, build 3.1010.0-pr-28-35cb): GetPageDocumentAlternatesQueryHandler builds a PageDocumentSearchCriteria with Status = Published, CertainDate = now, OrganizationId = the request's organization, and now FilterByOrganization = true, including when the organization is empty. So a visitor without an organization should not find versions made for one, and a user of organization B should not find organization A's versions. That is the same filter pageDocuments and pageDocument(id) use. A unit test covers organizationId null and "org". Not yet observed live on a stand.
