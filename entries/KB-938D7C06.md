For a signed-in shopper the cart's Discount and coupons sidebar renders preset cards from promotionCoupons with first 4 sorted by endDate ascending, so only the first four public active coupons appear, in that order; any other code is still usable through the Custom code field. An applied card's button flips from Apply coupon to Remove coupon. For an anonymous shopper no preset cards render and the coupons query is not sent; only the Custom code field shows, and typed codes still apply.
