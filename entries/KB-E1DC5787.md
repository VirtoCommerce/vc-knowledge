As a B2B buyer: initial subscription orders return {renewalId:null, renewalNumber:null, renewalScheduledDate:null, isManualRenewal:false, subscriptions:[{subscriptionId, subscriptionNumber, productId, intervalUnit, intervalCount, intervalLabel 'every month', status, isStartedByOrder:true}]}. Renewal orders (made by POST renewals/{id}/process) return renewalId/renewalNumber/renewalScheduledDate set and isStartedByOrder:false; a grouped renewal lists every subscription it covers (3 subscriptions, 2 of them the same product merged into one order line of quantity 2 — the line carries no line-item id, only productId). Passing another customer's order ids returns [] with no error (mixed with an own id, only the own entry comes back). An admin token also gets [] for a customer's orders (scoped to the caller's own orders). Without a token: errors[] 'Anonymous access denied…' code Unauthorized. Storefront /account/orders shows the 'Subscription' badge only on renewal orders and the order page alert 'Placed automatically by your subscription for the delivery of <date>. Subscriptions SUB-…  Manage subscriptions' only on renewal orders.
