POST /api/push-message with {topic, shortMessage, status: 'Sent', startDate in the past, memberIds: [<contact/member id>]} returned the created message with its id. All 11 messages sent in sequence were listed in the recipient's xAPI pushMessages(withHidden: true) within about 1 s; a batch of 3 appeared within about 4 s (polled every 4 s). The recipient-side items[].id equals the push message id from the admin API, and one message shows the same id in every recipient's inbox. New rows arrive with isRead=false, isHidden=false. markPushMessageRead(command: {messageId}) returned true and flipped isRead on that one row only (visible 11, read 1, unread 10 afterwards).
