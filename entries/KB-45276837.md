Store 3.1009.0, Platform 3.1076.1, 2026-10-13. Stores > open a store > URLs section: "Store asset URL" (next to "Store URL", no "Secure store URL") has a question-mark help icon (glyph U+F059). Clicking it shows the field description as text under the input ("Base URL used to serve this store's asset (image) URLs via the Experience API ... Leave empty to use the global/admin default.") plus a "Hide description" link; no popover/tooltip element appears. Empty input shows placeholder "Enter asset base URL"; GET /api/stores/{id} returns assetPublicUrl null when unset.
