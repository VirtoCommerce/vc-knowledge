2026-10-12 on vcst_qa, admin token. POST /api/order/customerOrders/search {organizationId: <org>} returned only orders whose organizationId equals that org (two test orgs, 2 orders each, no foreign rows), and an all-zero GUID returned totalCount 0, so the criterion is applied and not ignored. POST /api/return/search {organizationId} with no status flag behaved the same: only that organization's returns, drafts and cancelled included, and totalCount 0 for an organization with none. POST /api/customer/organization-memberships/search {organizationId} also returned only that organization's memberships.
