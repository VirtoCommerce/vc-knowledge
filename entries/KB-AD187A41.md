Both UIs show a customer's loyalty points on the contact blade: a "Loyalty balance" widget opens the "Loyalty operation log" (Operation, Amount, Balance, Created). Programs are managed separately (classic: More → Loyalty; Admin Shell: Marketing → Loyalty Programs). Classic widget tile shows the balance value (e.g. 16418). Admin Shell puts the widget in the blade's widget overflow and shows a "99+" badge (count of operations) instead of the balance, so the balance is only inferable from the newest log row.
