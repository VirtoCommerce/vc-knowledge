2026-11-23, admin, vcptcore_qa1 switched to Assets__Provider=AzureBlobStorage. A top-level folder in Asset Management is an Azure container (url https://<account>.blob.core.windows.net/<name>). Admin SPA #!/workspace/assets -> New folder 'vp9375 ui space' at the root: the prompt accepts it, POST /api/assets/folder returns 500 and the error dialog shows Azure 'The specifed resource name contains invalid characters ... ErrorCode: InvalidResourceName, Status 400'. Same over REST for name 'vp9375 space' at the root, and for {name:'child', parentUrl:'<account>/vp9375 space'}. The server validator allows spaces (it rejects uppercase, <3 or >63 chars, leading/trailing/double dashes with 400), but Azure container names cannot contain spaces. Inside a valid container, child names with spaces, leading/trailing spaces, digits, a grandchild, and absolute or relative parentUrl all return 204.
