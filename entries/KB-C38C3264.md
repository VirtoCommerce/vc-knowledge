As administrator in /apps/page-builder-shell (store B2B-store), opening a Draft page stored with permalink '/agent-test-6443 legacy-s8?x' shows no field error and Save disabled on a clean form. Changing only Name enables Save; PUT /api/page-builder-pages/grouped returns 200 and the stored permalink is unchanged. Changing the permalink to another invalid value marks the field invalid and disables Save and Publish; reverting to the stored value returns the form to clean. The same rename on a Published page stored with '/agent-test-6443-legacy%20pct' also saves. Clicking Clone on a page stored with '/agent-test-6443 legacy-s18' sends POST /api/page-builder-pages/grouped, which returns 400; the shell shows the rule text in a toast and a blade alert, and no copy is created. Cloning a page with a valid permalink returns 200 and creates '<name> (copy)' at '<permalink>-copy'.
