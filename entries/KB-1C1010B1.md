B2B-store, theme storefront (SPA: HTTP 200 on every route; 'not served' renders the 404 'Page not found' view). A published Site Builder page shown to an anonymous visitor; after switching Visibility off in the shell page blade (Personalization & Access control) and Save (PUT /api/site-builder-pages/grouped 200), the page stays Published with no pending draft (publish-status {published:true, hasChanges:false}) and takes effect without re-publishing: the anonymous visitor gets the 404 view, a signed-in B2B buyer still sees the content, and the list row gains the 'Personalized' badge. With Organization set to one organization (organizationId saved, again no re-publish needed): a buyer of that organization sees the page; a buyer of another organization and an anonymous visitor get the 404 view with none of the page text. The User groups dropdown lists the store's customer groups (here contract-contract2, Wholesaler, VIP) and saves userGroups as a string.
