Query.products returns an order value per facet (term_facets[].order, range_facets[].order). The storefront /catalog sidebar shows all range facets first (price, then attribute ranges such as Size_EU) and then the term facets in order. On vcptcore_regression (theme 2.59.0) Size_EU has order 12 but is shown second, right after price; on vcptcore_stable (theme 2.51.2) price has order 2 but is shown above BRAND (0) and COLOR (1). The term facets keep their configured relative order, and a reorder in Admin Facets is reflected immediately. The behaviour is the same on both releases, so it is not a regression of the newer theme.
