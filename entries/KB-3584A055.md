Orders 3.1018.0: PUT /api/order/customerOrders with currency 'ZZZ' -> HTTP 500 'Sequence contains no matching element'; createdDate 'not-a-date' -> HTTP 500 NullReferenceException (also 500 on vcptcore_stable, Orders 3.1009.0). The currency lookup is DefaultCustomerOrderTotalsCalculator.GetCurrency -> currencies.First(c => c.Code == code), identical at 3.1009.0 and 3.1018.0, so both 500s predate Stable 16. CustomerOrderValidator checks lengths/required only: unknown CustomerId, StoreId and Status strings are accepted with 204.
