On vcst (theme 2.63.0-pr-2667-0444-0444048a) a buyer with two accessible organizations opened /403 (page title '403 Access denied', heading 'Access denied'). The header showed the Organizations button (data-test-id organizations-button, label 'Organizations: <current org>'), and clicking it opened a dialog 'Organizations' with a listbox of both orgs, both enabled. Opening the account menu popup (account-button) showed only the user-name link and Logout: no Organizations listbox. Source agrees: organization-switcher.vue renders only when isMultiOrganization (contact.organizations.totalCount > 1, blocked statuses excluded server-side) and is registered as a header extension, not tied to the route; the older account-menu listbox was moved to the header by PR #2667. The state with a pinned blocked org (denial landing reached by sign-in) was not built: it needs writes to contact and membership status.
