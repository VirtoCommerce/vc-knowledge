Return 3.1005.0-pr-28-fb4f, platform 3.1078.0, 2026-10-12, Admin SPA as administrator. On a Completed, fully delivered order with a line of 25, six successive admin returns were made through More > Returns > Add new return > Customer orders picker > Line items (quantity 1 each), and each was then saved with status 'Canceled' from the return blade's Status select (the stand's dictionary offers only that spelling). Every subsequent Line items blade (GET /api/return/available-quantities/{orderId}) again offered Quantity 25 for that line, and an older return of the full 25 units in status Canceled did not hold them either. So the single-l Canceled status releases units like Cancelled does; a Canceled return's available-statuses is ["Canceled"] only.
