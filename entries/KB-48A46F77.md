PATCH /api/inventory/{id} with a JSON Patch body (application/json-patch+json) replacing inStockQuantity and status returns 204; the id is the inventory record's, which GET /api/inventory/products/{productId} lists per fulfillment center. Full-object PUT updates to the single and bulk inventory routes returned 500 with re-fetched payloads. The persisted InventoryStatus is Disabled, Enabled or Ignored - InStock is not a value (400); in-stock is a derived availability flag on the xAPI product. Adding to cart silently does nothing when the inventory record is Disabled, and a product with trackInventory false ignores quantity and is always available.
