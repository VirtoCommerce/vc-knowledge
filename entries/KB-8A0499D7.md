On vcst_qa (ES8, blue-green), a Product Build (no delete) was started from the admin Search index blade and canceled from the Indexation process blade at about 1100 of 4861 documents; the push notification ended 'Indexation has been canceled' (19:59:26Z). GET /api/search/indexes then reported Product lastIndexationDate 19:59:25Z and the grid showed 'a few seconds ago', exactly as after a completed build, with the document count unchanged. So the Last indexed value cannot distinguish a canceled partial run from a full one; read the notification instead.
