On Return 3.1005.0-pr-28-62f9 CreateReturnCommandType has no storeId field. A buyer signed in with storeId=Electronics created and submitted a return on an order of B2B-store; GET /api/return/{id} showed storeId B2B-store. To put a return in another store the admin PUT /api/return with storeId changed was needed (accepted, kept).
