Stable 16 regression W1, 2026-10-13, Cart 3.1012.0 / XCart 3.1039.0. POST /api/carts/{id}/coupons/{code} with a valid active coupon answered 204, but a following GET of the cart showed coupons[] empty and no discount: the REST cart endpoint does not recalculate or persist the coupon. The same coupon applied through the storefront xAPI mutation addCoupon was accepted and produced the expected discount (-40 on the test cart). So a REST-cart coupon case that expects coupons[] to contain the code tests a path the storefront does not use; verify coupons through xAPI addCoupon / cart.coupons instead. Classified as by design for the legacy REST cart, not a Stable 16 regression.
