Chromium 1920x1080, signed-in rep, 3 fresh loads. Enter on a row's 'Call customer' button (multi-number customer, 3 numbers) opens the list, aria-expanded=true, focus on the dialog container. Tab x3 reaches each tel: entry in order with the list still open. A 4th Tab moves focus to the next row's organization link: the popover body goes display:none, aria-expanded=false, and elementFromPoint at the link's centre returns the link (not covered). Shift+Tab from the first number returns focus to the trigger and closes the list. Escape on a number closes it and focus returns to the trigger. Mouse: icon click opens; clicking a number (tel: href) closes it with no page navigation; clicking outside closes; opening a second row's list closes the first (one open at a time). Single-number customers render a direct tel: link labelled 'Call customer, <number>' instead of a list; customers without a number get a disabled button 'Call customer, No phone number'. This is the fixed behaviour of VCST-6753 (focusout handler on the list).
