vc-frontend-next build 3.3.0-pr-23, TechFlow org maintainer on /company/members. TechFlow Organization.Roles = [org-employee]; member agent-test-multiorg's TechFlow membership role = org-maintainer. GetOrganizationContacts returned rolesInOrganization [org-employee, org-maintainer] (org-level role merged in first) and the Roles cell read 'Organization employee, Organization maintainer'. Actions > Edit role opened 'Change role' (single-select radio list of assignable roles) with 'Organization employee' preselected and Save disabled until another radio is chosen. Choosing 'Organization maintainer' + Save sent ChangeOrganizationContactRole {roleIds:[org-maintainer]} -> succeeded:true, a no-op for the membership. So the dialog's 'current role' is rolesInOrganization[0], not necessarily the membership's own role. Also: clicking an option's label text did not select its radio; only the radio indicator did.
