Observed once on PageBuilderModule 3.1034.0-pr-172-5aad, Platform 3.1076.0. The shell got its token from POST /connect/token (grant_type=impersonate, scope=offline_access); the response said expires_in 1799. About 4 min 47 s later, GET /api/page-builder-pages/grouped/{id} returned 401 with an empty body. The shell logged '[@vc-shell/framework#use-async] Async action failed: Unauthorized' and navigated to #/login. No token refresh was attempted before the redirect. The Admin SPA cookie session in the same browser was still valid, and reopening the shell URL still landed on the shell login form. Signing in there restored access. The cause is not established. Other agents were signing in as the same admin user on this shared stand at the time, so the token may have been revoked server-side.
