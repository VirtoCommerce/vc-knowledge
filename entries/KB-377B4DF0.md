On a stand running SalesRep 3.1018.0-pr-33-8d4a (open PR #33, base dev f58dbbc, which does not contain PR #30) with Marketing 3.1010.0 installed, introspection of /graphql/sales-rep lists 29 queries and 6 mutations and neither it nor /graphql has salesRepCoupons; a rep token asking for it gets 'Cannot query field salesRepCoupons on type Query'. The storefront route /company/my-customers/{organizationId}/coupons renders the host 404 page (title 'QA & 404 Page not found') for a signed-in rep, and plugin.json declares 11 routes, none ending in /coupons. A stand carries one PR build of a module at a time, so whichever open PR was deployed last decides whether the coupons surface exists.
