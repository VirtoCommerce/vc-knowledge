On theme 2.60.0-pr-2523-466f (Firefox 151), as an organization maintainer opening a colleague's Requested return from the organization tab, the summary grid shows Status, Date, Order number and Requested by. All four labels are span.text-sm.text-neutral-600, computed rgb(82,82,82) = #525252 (token --color-neutral-600) on the white card = 7.81:1, at 1920 px (4 columns) and 375 px (2x2 grid). The page holds no button, link or input inside main (no Cancel return, no Edit). On the viewer's own Requested return the same three labels are identical, there is no 'Requested by' block and 'Cancel return' (118x38 px, #de3131 on white, 4.58:1) is present. Under the dark scheme (html.dark) the neutral-600 token flips to #9b9b9b and all four labels measure 6.88:1 on rgb(17,15,14). axe-core 4.12.1 reports 0 violations on both details pages (only the known VcWidget aria-labelledby incomplete). Earlier builds used text-neutral-400 (#a3a3a3, 2.52:1).
