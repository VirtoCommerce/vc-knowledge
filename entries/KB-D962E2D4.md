Live on vcst 2026-11-05 ~15:24Z (SalesRep 3.1018.0-pr-33-ff13 backend, plugin bundle pr-33-8d4a in the browser), signed in as SR_REP_NOCUSTOMERS (0 served orgs, salesRepTaskFilterRules []): the Status combobox on /company/tasks is enabled and opens; its dropdown lists one option, "No options available", and that option is disabled. Source agrees: in vc-module-sales-rep#33 sales-rep-task-filters.vue the Status VcSelect binds :items="statuses" with no disabled binding, and the UI kit's vc-select.vue renders a disabled VcMenuItem with ui_kit.select.no_options when the item list is empty (the kit's EmptyItems story). The Customers select and the New task Customer select behave the same way for this rep. So a case asserting the select is disabled is wrong; assert that it opens to the single disabled "No options available" item.
