On vcst (theme 2.63.0-alpha.2681) an 11-organization buyer whose first sign-in opened org A switched to org B in the header Organizations switcher, signed out from the account menu, then signed in again by password: the header showed org B active immediately, with no prompt to pick an organization. The last-active organization is restored on password sign-in, the same as the one-time-code path (KB-0080ED6D); there is no separate configured default.
