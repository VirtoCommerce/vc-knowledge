The storefront table component's row click opens the row's detail URL with window.open in a new tab rather than routing in place, BY DESIGN, so the listing tab keeps its position. It applies to /account/orders, the dashboard Latest orders widget and /account/quotes. Ctrl+click or middle-click give the same new tab, and Back does not return to the listing because navigation never happened in that tab.
