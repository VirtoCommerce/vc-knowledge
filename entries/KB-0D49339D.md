Stable 16 (Platform 3.1076.1), Admin Stores > Add (New store blade) with all required fields filled: Code 'AGENT TEST-x' (space+hyphen) and 'AGENTTEST x' (space) keep Create disabled; 'AGENTTEST-x' (hyphen only) enables Create. Existing store ids such as B2B-store also contain a hyphen, so a hyphen is a valid store code character; only the space is rejected client-side.
