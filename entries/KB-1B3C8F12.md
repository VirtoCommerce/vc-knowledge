Signed in as a sales rep, /company/my-customers sent exactly one SalesRepCustomers query on load, search, page change and sort (no per-row SalesRepCustomer). Each row has a "Send message" icon and a call control. No number: span role=button aria-disabled=true aria-label "Call customer, No phone number", focus/hover/tap shows tooltip "No phone number". One number: anchor aria-label "Call customer, <number as stored>", href tel: with digits and a leading + only (e.g. "+1 (555) 020-3040" -> tel:+15550203040; "+1-555-040-5060 x45" -> tel:+1555040506045, the extension is folded into the digits; "(555) 010-2032" -> tel:5550102032, no + added). Several numbers: button aria-haspopup=dialog opens role=dialog "Choose a number to call"; entries are the primary contact's phones labelled with the contact name, then the org address phone labelled with the org name; equal numbers in different formats collapse into one entry. Escape inside the list closes it and returns focus to the trigger. The customer profile Phone row links the first entry of the same list and offers the same list next to it; with no number the Phone row is absent, and with no primary contact (only reps are members) the Primary contact row is absent too. An ownerless org's primary contact was its non-rep buyer; the rep's own phone never appeared.
