In the Page Builder shell page blade, permalinks '/my page test 0812', '/page&test?q=1#anchor0812' and '/страница-тест-0812' were all saved as typed ('Page saved successfully', GET grouped returns the raw permalink) and published. On the storefront the space and Cyrillic permalinks resolve (browser percent-encodes them), but '/page&test?q=1#anchor0812' typed or linked as shown in the blade (storefront host + permalink) returns the 404 page because ? and # start the query/fragment; only the fully percent-encoded path /page%26test%3Fq%3D1%23anchor0812 resolves the page.
