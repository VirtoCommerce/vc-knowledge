The vc-frontend theme sets no production COEP (vite.config.ts sets unsafe-none for the dev server only, same in 2.51.2 and 2.59.0). The deployed storefront document carries what the vc-deploy-dev infra/environments.yml storefront.headers block declares (unsafe-none -> unsafe-none; require-corp -> require-corp). Under require-corp, product images on an Azure blob host sent with no Cross-Origin-Resource-Policy and no Access-Control-Allow-Origin are blocked by the browser; images on platform hosts that send CORP same-site/cross-origin still load. The platform host serves COEP credentialless, COOP same-origin, CORP same-site.
