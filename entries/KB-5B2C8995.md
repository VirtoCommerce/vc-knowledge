On the VCST-5989 PR build (Seo 3.1006.0-alpha.101, Catalog 3.1049.0-pr-910), the admin profile language was set to de and the Admin was reloaded. Debug of a category slug outside the store's catalog showed: Stages blade 'Phasen des SEO-Link-Debuggings', columns 'Stufe' and 'Anzahl der Elemente', Stage 0 'Stufe 0: Kandidaten - SEO-Einträge mit diesem Slug, die die Resolver geprüft haben, einschließlich der abgelehnten.', and German titles for Stufe 1-6. The Candidates blade showed 'Kandidaten des SEO-Link-Debuggings', columns Semantische URL, Aufgelöst, Ablehnungsgründe, Objekttyp, Objekt-ID, Sprache, Geschäft, Aktiv, the reason 'Die Kategorie oder das Produkt befindet sich nicht im Katalog des Shops' (a Catalog-module key), and the footnote 'Abgelehnte Einträge werden nur für Module aufgeführt, die ihre Auflösung erklären können.'. No English text, no dotted seo.candidate-reasons key, no bare reason code. The Object Type cell keeps the data value 'Category', as it does in English.
