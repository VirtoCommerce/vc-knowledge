Read in source. option-product.vue and option-product-none.vue render a bare VcRadioButton in the product card's media slot (no ariaLabel, label or slot content) and the product name in a separate VcProductTitle, so the native radio has an empty name; VcRadioButton supports ariaLabel and only warns in DEV builds. The two option files and vc-radio-button.vue are byte-identical at the PR #11 base, head and Next dev, and the upstream vc-frontend main has the same markup (option-product.vue unchanged for naming since 2025). PR #11 does not touch them, so the defect is pre-existing and shared, not introduced by the merge.
