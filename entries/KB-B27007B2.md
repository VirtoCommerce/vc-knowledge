On theme 2.59.0 / Platform 3.1076.1 (vcptcore_regression, 2026-10-13) and theme 2.51.1 / Platform 3.1039.13 (vcptcore_stable, same day), a Customer signed in to B2B-store, account dashboard open, then the user was deleted (DELETE /api/platform/security/users?names=) and its contact deleted. The next navigation (/account/orders, and / after it) rendered a completely white page with no header or footer. POST /graphql GetPageContext returned HTTP 200 with data.pageContext null and errors[0].extensions.code NULL_REFERENCE ('Error trying to resolve field pageContext'); the stable build's details show System.NullReferenceException in VirtoCommerce.XFrontend.Data.Queries.PageContextQueryHandler.Handle (PageContextQueryHandler.cs:66). Console: ApolloError: Error trying to resolve field 'pageContext'. No redirect to sign-in, no message; same behaviour on both builds, so it is not new in the later one.
