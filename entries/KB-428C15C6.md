2026-10-29 on vcst_qa: VirtoCommerce.Passkeys 3.1000.0-pr-1-a25f installed, xAPI store.settings.authenticationTypes = [Password, AzureAD, GoogleSSO, Passkey], theme 2.61.0-alpha.2605. /sign-in shows only 'Sign in with Entra ID' and 'Sign in with Google'. The host fetches the Passkeys plugin mf-manifest.json and remoteEntry.js (200), and the plugin registers its button under the 'identityProviders' extension category, but the deployed host identity-providers chunk is the pre-#2601 version: it only lazy-loads built-in ./<type>-provider.vue files (azuread, googlesso) with a null error component, and has no ExtensionPoint for identityProviders, so the 'Passkey' type silently renders nothing and passkey-provider-*.js is never requested. The button appears only with a theme that contains vc-frontend#2601 (merged to dev 2026-10-28, commit 5a5e6a4f), as observed on vcptcore_qa with theme 2.61.0-pr-2601.
