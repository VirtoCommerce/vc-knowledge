Unauthenticated POST /api/otp/request with Origin header, body {storeId, email} for a freshly created Approved customer user of that store: the response was HTTP 200 with body {succeeded:false, error:{code:"otp_disabled", description:"OTP sign-in is disabled for this store."}, maskedEmail:"<masked>", lockoutSecondsRemaining:null}. The status code alone does not tell a disabled store from a sent code; callers and tests must read succeeded and error.code. The masked email is still returned even though no code is sent.
