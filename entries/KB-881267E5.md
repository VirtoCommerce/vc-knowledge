Read GET /api/platform/settings/TaskManagement.TaskTypes with an admin token on a local stand (platform 3.1083.0, TaskManagement 3.1005.0, Sales Rep module built from source at the unreleased PR vc-module-sales-rep#26). The setting belongs to module VirtoCommerce.TaskManagement, is a dictionary (isDictionary true) of ShortText, is not public (isPublic false), has value null and defaultValue "Registration Review". Its allowedValues are: Registration Review, Order Review, Order Processing, Product Catalog Management, Pricing and Promotions, Content Management, Customer Support, Other, Call. "Call" is the value the Sales Rep build under test adds at startup, per its PR description; the other eight were present without it being involved. Because the setting is not public, an anonymous store-settings read does not return it: read it through the admin REST API.
