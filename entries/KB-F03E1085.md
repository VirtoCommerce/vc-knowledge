Opened the order-goal (order-mission-modal) and featured-SKU (sku-mission-modal) modals on /account/missions. Each root div has role=dialog, aria-modal=true and aria-labelledby pointing at the Headless UI DialogTitle h2 holding the mission name; axe-core aria-dialog-name passes and computes the name, and Playwright getByRole('dialog', {name: <mission name>}) resolves. Background is aria-hidden. The Playwright MCP aria-snapshot YAML renders the node as plain 'dialog' without a name, so reading the name off that snapshot gives a false 'unnamed dialog'.
