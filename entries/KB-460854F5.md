Set SiteBuilder.Store.PreviewUserIds on B2B-store to one buyer's user id (via the store record; a POST /api/platform/settings with the store object answered 204 but did not change the value, and PUT /api/stores with value null leaves a value in place while "" clears it). The designer's 'Preview as' menu then offered 'Anonymous visitor' and that buyer's login; choosing the buyer issued a POST /connect/token (200) and relabelled the button. The preview kept a signed-out header ('Sign in', no organization name). With the inspector off, the quantity stepper and header links in the preview are covered by an overlay element: Playwright reports '<div></div> intercepts pointer events', a real mouse click leaves the quantity at 0 and does not navigate. The buyer's carts (admin POST /api/carts/search) were identical before and after.
