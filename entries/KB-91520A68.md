On a category with no automatic-link query, POST .../automatic-links returned 204 and the category's list entries stayed empty (the stand had 0 queries in POST /api/catalog/automatic-link-queries/search). After creating a query with POST /api/catalog/automatic-link-queries {targetCategoryId, sourceCatalogId, sourceCatalogQuery:"Garden"}, POST .../automatic-links (204) linked the 2 products the keyword matches within ~6.6s: POST /api/catalog/listentries on the target category returned them and the product links carry isAutomatic:true. DELETE .../automatic-links (204) removed them within ~5.6s. Only links flagged isAutomatic are touched; manual links are not. The recompute searches the source catalog through the search index, so it only finds indexed products.
