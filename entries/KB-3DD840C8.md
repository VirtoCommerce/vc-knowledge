2026-11-23, vcptcore_qa1 on Assets__Provider=AzureBlobStorage, admin over REST. Container 'vp9375-cdn' created (204). POST /api/assets/folder {name:'child-a', parentUrl:'https://<account>.blob.core.windows.net/vp9375-cdn'} -> 204; same with parentUrl 'https://cdn.example.com/vp9375-cdn' or '<platform host>/cms-content/assets/vp9375-cdn' -> 500 InvalidResourceName (Azure, 400). Source (AzureBlobProvider.CreateFolderAsync): an absolute parentUrl is made relative with BlobServiceClient.Uri.MakeRelativeUri; for a different host that returns the absolute URL unchanged, so the first path segment ('https:') is used as the container name. The Admin SPA sends the parent folder's listed url as parentUrl, so when listings return folder urls on a CDN/public host (CdnUrl / PublicUrl configured), every subfolder creation fails while top-level folders (no parentUrl) succeed.
