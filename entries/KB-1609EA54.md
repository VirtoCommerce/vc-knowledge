On vcst_qa 2026-10-23 (MFA 3.1000.0-pr-1-cf83): the password grant's 400 two_factor_required body returns the ticket as JSON property twoFactorToken, but the mfa grant must receive it as form field two_factor_token. With a bogus ticket, every combination of {twoFactorToken, token, mfa_token} x {code, verification_code, otp, mfa_code} answered 400 invalid_request / missing_parameter; only two_factor_token + code reached validation (invalid_grant / invalid_two_factor_token). With a real ticket and the journal code, grant_type=mfa + two_factor_token + code + storeId answered 200 with access and refresh tokens, and the access token's amr claim was "mfa".
