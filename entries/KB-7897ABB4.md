B2B-store, admin, Admin Shell > Sites > B2B-store > designer > Discard all changes, with a published custom type TP holding a draft and a never-published type TN. The list reads 'Section type "<TN picker name>" (never published)' and 'Section type "<TP picker name>"'. TP ticked alone: confirm button is the primary (yellow) 'Discard'. TN ticked alone: an alert 'Delete the section type "<TN>"? It is a block an AI agent created for this store. It was never published and there is no other copy, so it cannot be restored. Pages that place it will show nothing in its place.' and the confirm button becomes a red 'Discard and delete'. Confirming sends one POST designer/discard (200); afterwards no request for TN's template file, no new console error, and TN is gone from Add section > Custom sections while TP stays; GET template?draft=true for TN answers 404.
