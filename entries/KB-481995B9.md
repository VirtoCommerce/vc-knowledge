With an admin bearer token on a stand where both modules are installed (Admin shows Loyalty programs 12 and Return list 88): GET /api/loyalty/programs?take=5 -> 404 and GET /api/returns?take=5 -> 404. The deployed swagger has no such routes. POST /api/loyalty-programs/search {take:5} -> 200 totalCount 12 (items id/name/isActive/programType); POST /api/return/search {take:5} -> 200 totalCount 88 (items number/orderId/status). So a 404 on those GET paths is a wrong route, not evidence the module is absent.
