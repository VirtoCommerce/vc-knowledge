Matching stores by their catalog field (POST /api/stores/search) can return no store for a physical catalog whose products are nonetheless live on a storefront, because the store's catalog is a virtual catalog linking categories of the physical one. GET /api/catalog/products/{id} returns outlines[], one per catalog path reaching the product; an outline rooted in the virtual catalog shows the store exposure.
