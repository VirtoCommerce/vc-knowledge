Return 3.1005.0-pr-28-fb4f, 2026-10-12, Return.Status allowedValues [Completed, New, Canceled, Processing, Approved]. A buyer draft cancelled through xAPI cancelReturn stores status Cancelled. Opening it from the Admin Return list (/workspace/Return, row click) shows the Status select EMPTY (no value rendered), while the list column shows Cancelled; the blade issues GET /api/return/{id} and GET /api/return/{id}/available-statuses, which answers [Canceled]. PUT /api/return of a buyer submitted-then-cancelled return with status Canceled answers 200 and the stored status becomes Canceled (submittedDate kept); the holder's return(id) then reads Canceled. A comment-only PUT keeping status Cancelled also answers 200. PUT status New answers 400 "Status 'Cancelled' cannot be changed to 'New' by an edit." Root is the stand's stored dictionary (other stands hold Cancelled), see KB-18D61DE9.
