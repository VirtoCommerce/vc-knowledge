Signed-in B2B buyer, Chromium 1280, vc-frontend-next 3.3.0-pr-23-7be3 (carries vc-frontend 2.62.0). Edit layout shows Reset / Cancel / Save layout, a 'Visible stats' and a 'Hidden stats' group, and each stat card is a 'Reorder <card>' button. Dragging a card into Hidden stats hides it, dragging it back shows it; drag onto another card reorders. Keyboard: Space on a card grabs it (assertive live region 'X grabbed. Position n of 4. Use the left and right arrow keys to move it, up and down to hide or show it, space to drop it, escape to cancel.'), ArrowLeft moves, Space drops ('X dropped at position 3 of 4.'). ArrowDown on a grabbed card hides it and ends the grab ('X hidden.') - the VCST-6858 mismatch with the instruction text. Max rows of My recent orders is a spinbutton 'Max rows for My recent orders, between 1 and 20'. Save layout sends SaveLayout(command: scope accountDashboard, storeId, schemaVersion 1, regions statistics[ordered blocks with hidden flag], mainLeft[recent_orders with settings maxRows], mainRight[]) and gets 200 with the echo; a reload renders the saved order and row count (GetOrders first = maxRows). Cancel discards unsaved changes and restores the last saved layout without a request. Reset sets the default order WEEK, MTD, YTD, Avg order value with maxRows 5 (saved only after Save layout). With only Avg order value visible, GetOrderStatistics is sent with withWeek/withMtd/withMonthOverMonth/withYearOverYear false and withYtd + withAverageOrderValue true, and the card shows its value.
