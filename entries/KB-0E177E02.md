Yes on the Cart/XCart build carrying share targets (late Sep 2026): signed in as a member of the target organization, /shared-list/<key> renders the list with the caption 'Recommended by your sales representative', its items with Add to cart, and an order summary. sharedWishlist(sharingKey) returns no errors with sharingSetting { scope Customer, access Read, isOwner false, sharedWithId null }. The rep's message is not rendered on that page (the 2.59 client does not query it); the recipient sees it only in the push notification feed, as '<message>\n\n<link>'. The list does not appear on the recipient's /account/lists.
