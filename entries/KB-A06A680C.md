On a dev stand (Platform 3.1077.0-alpha, Seo module PR build), the Stages blade rows invoke openStageDetails through `ng-click` on `div.ui-grid-cell-contents` (cursor: pointer) with no tabindex, role or key handler. A real keyboard walk starting from the focused Debug button visits only the blade-nav maximize and close buttons (no accessible name), the Grid Menu and the two column header buttons (Stage, Items Count), then leaves the blade (no trap); the stage rows, including the new "Stage 0: Candidates" row that opens the Candidates blade, are never focusable, so the Candidates blade cannot be opened without a mouse. All stops resolve outline-style: none and box-shadow: none while :focus-visible matches. The handler is shared by Stages 1-6 (it only branches on stage === 'Candidates' to choose the controller/template), so the pattern predates the Candidates change; the Stage 0 label (110 chars) is also the only stage description truncated with an ellipsis at 1920 (679 px needed, 568 px available) and it has no title tooltip.
