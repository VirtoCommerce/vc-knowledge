Opening Orders, Menu Editor and Contacts inside the shell sent POST /api/admin-shell/menu/me/recent/{itemId} (204) each time, yet the Home panel's Recent kept showing the list from boot (Environments Comparison, Banners, Builder.io, Dynamic Associations, State Machines). After a full page reload the boot POST /api/admin-shell/menu returned recent starting orders, platform.menu, customers, and the panel showed them first. In-app hash navigation never re-requests the menu. Pinned items are excluded from Recent (Catalogs was visited and pinned and did not appear there).
