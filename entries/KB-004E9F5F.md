On the stand, the admin Settings > Search group and GET /api/platform/settings/modules/VirtoCommerce.Search list only the index partition size and the partial document update settings. There is no setting to enable scale-out indexing or to cap queued indexing jobs; older test cases written against an earlier Search module that name such a setting cannot be executed on this build.
