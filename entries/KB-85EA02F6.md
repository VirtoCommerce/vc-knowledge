Return 3.1005.0-pr-28-fb4f, theme 2.60.0-pr-2523-4263, 2026-10-12. Buyer created draft D (RET261012-00007, created 08:27:57), then created and submitted E (RET261012-00008, created 08:28:00, submitted 08:28:00), then submitted D (submitted 08:28:04). A holder's organizationReturns with no sort, with sort createdDate:desc and with sort submittedDate:desc all return E before D (submittedDate sort silently falls back to creation order, no error). The storefront organization tab shows E above D, its Date column carries the creation date (xAPI ReturnType exposes createdDate, not submittedDate), and the Filters panel labels its date range "Created date". So visibility is gated by submittedDate but ordering, the date shown and the date filter use createdDate.
