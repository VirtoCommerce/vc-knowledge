---
Theme 2.59.0-pr-2536, rep with 0 tasks. Only the 'Today 0' and 'All 0' scope chips render, both enabled. The Upcoming, Overdue and Completed status tabs are not rendered at all. Today and a picked calendar day show the header "<date> / 0 tasks" and the empty state "Nothing due on this day". All shows "All / 0 tasks" with "No tasks in this tab". Opening /company/tasks?filter=overdue lands on Today and the URL is cleaned to /company/tasks. New task stays available.
