Chromium, QA Storybook of theme build 2.63.0-pr-2617-a143, story components-organisms-vcpagination--page-6 (args pages=147 page=6), design classic, preset red, light, guest. Accessibility snapshot: the pages container holds button "1", a bare "...", buttons "4" "5", a bare generic "6" (the current page), buttons "7" "8", bare "...", button "147"; a second container after it holds buttons "Previous" and "Next". The current page carries no aria-current and the pager is not inside a nav landmark. Real Tab presses from the start of the document: the stops are 1, 4, 5, 7, 8, 147, then Previous (7th press), then Next — the current page and both ellipses are skipped. The Previous button is drawn before the page numbers (CSS order), so keyboard order differs from visual order; the same DOM exists on the dev base build per the exploratory pass of ticket VCST-6292. BL-A11Y-001 requires keyboard order to be logical, which is why this is marked.
