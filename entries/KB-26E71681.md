Delete (Enter) opens the Delete key dialog with focus on Cancel; Tab to OK, Enter: the dialog closes, the list shows the empty state, activeElement is BODY and the next Tab lands on the footer's first link. All requests succeed. Rename Save, by contrast, returns focus to the row's Edit button.
