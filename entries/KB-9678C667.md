Measured live on /sign-in after entering an email in the default email-code mode (code step, heading Check your email), Chrome, 1280x900, build 2.61.0-pr-2570, light and dark (header theme toggle). The six .sign-in-code-input__cell boxes have a 1px resting border #d4d4d4 on a #ffffff fill = 1.48:1 (1.42:1 against the #fafafa page container); in dark mode border #3f3f3f on #0a0a0a fill = 1.88:1 (1.78:1 against the #121212 page). The real input above them has a transparent background, so the boxes are the only visible cue. The sibling email field on the same page (VcInput container) is #a3a3a3 = 2.52:1 light and #6e6e6e = 3.88:1 dark. Source: the theme token values are ordinary (neutral-300 is #d4d4d4 light, #3f3f3f dark); the component picks the light token, border border-neutral-300 in client-app/shared/sign-in/components/sign-in-code-input.vue at line 148 of the PR 2570 head, while VcInput uses border-neutral-400. Using neutral-500 (#737373 light, #9e9e9e dark) would give 4.74:1 and 6.99:1.
