On ImageTools 3.1006.0 (ImageSharp build) with AllowedImageFormats value null / allowed values [PNG,Webp,JPEG,SVG], uploaded byte-identical jpeg-baseline.jpg and jpeg-baseline.jpeg into one folder with a FixedWidth task. Both POST /api/image/thumbnails/tasks/run (regenerate=true) and the event-based path (EventBasedThumbnailGeneration=true, upload) wrote jpeg-baseline_<sfx>.jpeg only; no thumbnail for the .jpg. Same for a 301x199 .jpg vs its .jpeg copy. The gate compares the literal file extension to the dictionary values, so 'jpg' is not matched by 'JPEG'. Pre-existing before the SkiaSharp rewrite (3.1007 PR build behaves the same).
