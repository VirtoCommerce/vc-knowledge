On a PDP whose template renders the Variations widget (seeded 60-variation parent), switched to the table view at 1920: axe-core reports button-name (critical) on the 38x38 icon-only button in the widget header (lucide 'arrows-expand' / 'delete-2' icon that toggles full view). It has no aria-label, title or text. The same button is unnamed in the default (list) view header. Keyboard can reach it, but a screen reader announces only 'button'.
