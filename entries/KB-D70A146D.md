Pre-existing data, read via admin POST /api/page-builder-pages/search. Two equally specific published en-US groups (same org, same user group, same dates) on one permalink: group A modifiedDate 07:26:12.93 with published page row modified 2026-04-15T15:58:00; group B modifiedDate 07:26:13.03 (later) with published page row modified 2026-04-15T15:56:06 (earlier). An org member's slugInfo returned group A's Pages id 5 of 5. Second permalink, two org-targeted groups: the group with the later group modifiedDate had the older published page row (2025-10-09 vs 2025-11-11); slugInfo returned the page with the newer row 5 of 5. So the winner is predicted by the published page row's modifiedDate (the Pages document), and the group modifiedDate (bumped by a bulk update on these groups) predicts the wrong page. pageDocuments returns both pages unranked.
