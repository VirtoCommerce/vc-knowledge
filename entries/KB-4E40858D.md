With a password-grant token of a Customer B2B buyer (no global role), GET /api/platform/security/currentuser/sign-in-methods returned 403, while the same call with a non-admin Manager token returned 200. For the Customer, xAPI POST /graphql { signInMethods { name keys { id } } } returned 200 with the method list (Passkey keys empty on a fresh account), and Mutation.deleteSignInKey(command:{signInMethodName, keyId}) is the matching delete. Test-data re-arm scripts must use xAPI for customers.
