Theme 2.60.0 with the SalesRep plugin built from vc-module-sales-rep PR #26 (unreleased), browser zone UTC-6. 'Edit task' on a type Other task shows Title, Type (editable), Due date, Priority and Notes, with no Customer, no Time and no 'Add to calendar'. A task stored at 2026-10-27T16:20:00Z (10:20 AM local, created through createSalesRepTask) moved to Oct 28 sent Mutation.updateSalesRepTask dueDate 2026-10-28T16:20:00.000Z, the same local time of day on the new day. A task created in the storefront, stored at local midnight (2026-10-27T06:00:00Z), moved to Oct 29 sent 2026-10-29T06:00:00.000Z. New task opens with the day selected in the page's Due dates calendar as its Due date (seen for three different days) and a non-call New task saves local midnight of that day.
