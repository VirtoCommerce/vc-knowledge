Published en-US landing holding one componentRef placement: GET /api/page-builder-shared-components/{id} usageCount 1. Convert to multilanguage: still 1. Create fr-FR version (POST /api/page-builder-multilanguage-pages/{id}/languages/fr-FR): the fr-FR draft content holds the same componentRef block, usageCount 2 (usagePages lists both languages, the fr-FR one as Draft). Publish all: 2, and /fr/<permalink> on the storefront renders the expanded shared sections. Clone root (POST .../{id}/clone): both cloned versions hold the componentRef, usageCount 4; after publishing the clone its fr-FR storefront render also shows the shared sections. Archiving all four pages (POST /api/page-builder-pages/grouped/archive) left usageCount at 4 (usagePages show Archived), so the component cannot be deleted; DELETE /api/page-builder-pages/grouped/{id} on each brought it to 0 and the component DELETE returned 204.
