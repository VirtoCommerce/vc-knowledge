As admin over REST: created a database page, saved content V1, published it. Anonymous slugInfo(permalink, storeId:B2B-store, cultureName:en-US) returned entityInfo {id:<pageId>, objectType:Pages}. Anonymous builderPage(storeId, pageId:<that id>) returned V1. Then unpublished (publish-status published:false, group status Draft, the same page id now Draft) and saved new content V3. slugInfo now returned entityInfo null and the storefront permalink route showed the 404 page, but anonymous builderPage with the harvested id returned permalink + V3, and opening the storefront /designer-preview?pageId=<id> with no session rendered the V3 text. So an id given out while a page was public stays a read handle on all its later unpublished content.
