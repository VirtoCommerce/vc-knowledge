On storefront theme 2.59 (observed on 2.59.0-pr-2501, on the Cart/XCart build carrying share targets, late Sep 2026), a signed-in member of the target organization opening /shared-list/<sharingKey> for a Customer-scope list sees the list name, a 'Recommended by your sales representative' info badge, the items with Add to cart, and an order summary; sharedWishlist(sharingKey) returns no errors with sharingSetting { scope Customer, access Read, isOwner false, sharedWithId null }. The page's GetSharedWishlist query does not request sharingSetting.message at all (it requests id, scope, access, isOwner, sharedWithId), so the rep's message is never shown on the page. The message reaches the recipient only as push text on /account/notifications, arriving as the message, a blank line, then the full /shared-list/<key> URL, rendered as a paragraph plus a clickable link inside the notification row. The list does not appear on the recipient's /account/lists.
