On storefront theme 2.59.0-pr-2501 the recipient's /shared-list/<sharingKey> page for a Customer-scope list renders the list name, a 'Recommended by your sales representative' info badge, the items and an order summary. Its GetSharedWishlist query does not request sharingSetting.message at all (it requests id, scope, access, isOwner, sharedWithId), so the rep's message is never shown on the page. The message reaches the recipient only as push text on /account/notifications, where it arrived as the message followed by a blank line and the full /shared-list/<key> URL, rendered as a paragraph plus a clickable link inside the notification row.
