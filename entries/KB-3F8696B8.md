On Stable 16 a users/create call with an already-existing userName returned HTTP 200 with body {"succeeded":false,"errors":["Username 'admin' is already taken."]}; the users search still showed exactly one row for that name. Source (vc-platform SecurityController.Create) always returns Ok(identityResult.ToSecurityResult()), so failures are reported in the body, never as 400; the message is ASP.NET Identity's DuplicateUserName text. The Admin SPA new-account wizard shows the same message.
