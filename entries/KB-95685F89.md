Guest, Chromium native accessibility tree (CDP Accessibility.getFullAXTree). For plain products the Availability row visibly shows a stock badge with the quantity (12, 340, 60...). The badge element carries the label "In stock", which overrides its text, so every Availability cell is exposed as cell "In stock" and the quantity is not in the accessible name. Same on a later 2.60 theme build that reworks the compare table. Also observed on the same page: each header "Remove from compare" button carries aria-pressed="false", so it is exposed as a toggle button although it is a one-shot action.
