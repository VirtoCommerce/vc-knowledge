Theme 2.59.0: applied the Processing status filter at 375x812 through the mobile Filters sidebar; the list showed the 3 Processing orders but no chip, count badge or Reset filters control appeared anywhere on the page. At 768px the same applied filter also showed no chips. Resizing the same session to 1920 showed the 'Processing' chip plus 'Reset filters'. Source 2.59.0 shared/account/components/orders.vue: .orders__chips is 'hidden' and becomes flex only at width >= screens.lg; identical in 2.58.0. Deliberate CSS, so this is a design choice, not a regression.
