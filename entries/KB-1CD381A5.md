On /account/lists, typing a 27-character name into the New List dialog shows 'This field must not contain more than 25 characters' and keeps Create list disabled. In the PDP 'Please select list' modal, Add new list quick-create accepted a 31-character typed name but the saved list was named with its first 25 characters (AGENT-TEST-W5 Summer Esse). Cases that name lists must use names of 25 characters or fewer.
