Created an organization via POST /api/members, attached it to an existing sales rep by appending it to organizations[] and PUT /api/sales-rep (the module created exactly one OrganizationMembership, the rep's own contact; organization-memberships search totalCount 1). As that rep (fresh password grant with storeId) on /graphql/sales-rep, Mutation.sendCustomerCommunication with organizationIds=[that org] returned HTTP 200, errors[] empty, succeeded:false, pushSent:false, emailSent:false, warnings[0]='NoRecipients'. The initiator is excluded from recipients, so a rep-only org is a reliable zero-recipient target. Reproduced twice (after a teardown and re-create of the org).
