On vcst_qa 2026-11-27 (platform 3.1101.0) Stores > B2B-store > White labeling > Logo, 'browse your files' under 'Choose logo' and picking a .webp file opened a modal titled 'Filetype error' with text 'Only PNG, GIF or SVG files are allowed' and an OK button. No upload/asset request was sent (network showed only the earlier GET /api/white-labeling/store/B2B-store), no new console error appeared, the Logo preview stayed as before and the Save/Reset toolbar buttons stayed inactive. GET /api/white-labeling/store/B2B-store returned the same logoUrl and modifiedDate before and after. So the type filter is client-side and fires before any upload.
