Signed in as the TechFlow organization maintainer on vcst, Firefox, 1024x768. After an organization membership was given two roles (Purchasing agent + Organization employee; restored afterwards), the unfiltered /company/members page that lists that member (only short names on it) measured: documentElement.scrollWidth 1073, card 740 px, table.vc-table__desktop 820 px, columns Name 182 / Roles 285 / Email 208 / Active 73 / actions 72; the actions column sat outside the card. The Roles text was 253 px; the cell is max-w-xs truncate, so in the auto-layout table it takes its full text up to 320 px. Before the second role the same page measured scrollWidth 1024 and table 738. Filtered to that member alone, the table still spilled 13 px past the card. A DOM-simulated 160 px Name cap did not remove it. Single roles always fit.
