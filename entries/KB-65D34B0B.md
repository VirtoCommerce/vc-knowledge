Signed in as a personal customer, navigating directly to /checkout/completed (no order placed, same empty in-memory state as a reload) reproduced twice: the page shows "Order completed / Order has been successfully submitted." with only a "Home page" button, no order number and no "Show order" button. App Insights recorded a vue-router Error 'Missing required param "orderId"' (stringify/resolve frames) each time, because the Show order link is built from in-memory placedOrder?.id (params {orderId: placedOrder?.id}) with no guard, so its render throws. The browser console shows nothing because the app's Vue error handler routes render errors to App Insights. The order itself is unaffected; the same message occurs about 10 times across 9 sessions since 2026-09-17.
