Platform 3.1076.0, admin language English, 2026-10-08. In Admin > Settings (global, route workspace/settings), each setting row's label comes from GET /api/platform/localization?lang=en at settings.<setting name>.title (nested JSON, e.g. settings.Cart.CronDeleteObsoleteCarts.title); if that key is absent the blade uses the schema's displayName from GET /api/platform/settings/v2/global/schema, and if that is null it shows the raw setting name. The '?' help icon toggles a line rendered from the key settings.<setting name>.description; when the key is absent the raw key string itself is displayed (e.g. 'settings.SalesRep.Statistics.CartInvalidateOnChange.description'), not an empty line. Control: Cart > General rows in the same blade show localized titles and descriptions. Example of the fallback: all eight SalesRep.Statistics.* settings (SalesRep 3.1013.0-pr-18), whose module en bundle defines only settings.SalesRep.Enabled and whose descriptors have displayName null. Matches vc-platform 3.1076.0 settings-unified.js (translateKey -> displayName -> name) and settings-unified.tpl.html (description via translate filter).
