Selecting assets in the Designer 'Choose from asset library' picker and saving stored image values like https://<backend>/cms-content/assets/stores/B2B-store/Page Builder/agent-test-060b-0812/agent-test%20hero%20banner.png and .../Page Builder/agent-test-060b-0812/%D0%B0...png: the folder path segment 'Page Builder' keeps a literal space while the file name is percent-encoded (spaces as %20, Cyrillic as UTF-8 %XX). Query.pageDocument content returns the same mixed string to the storefront. Browsers normalise it, so the image GET is .../Page%20Builder/... and returns 200; the stored src string itself is not a valid fully-encoded URL.
