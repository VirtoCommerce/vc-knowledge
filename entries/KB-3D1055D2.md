As admin: POST /api/site-builder/save?storeId=QA-STORE&theme=default&draft=false with files=[{path:"default/templates/x.json",type:"themes"}] -> 400 {"error":"Theme files are saved as drafts and published with theme/publish."}, nothing written (template GET 404 for draft and live). The body's files field is a JSON STRING holding the list ({path,type,content}); a non-list gives 400 "files must be a JSON list of files.". GET /api/site-builder/templates and GET /api/site-builder/sections -> 404. GET /api/pagebuilder/search?storeId=B2B-store&type=pages -> 200 with a body byte-identical to /api/site-builder/search; anonymous -> 401.
