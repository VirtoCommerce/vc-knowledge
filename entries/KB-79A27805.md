UCP 3.1011.0-pr-13 (served by the MCP module as the ucp scope), B2B-store. GET /ucp/v1/carts?store_id=B2B-store opened in a browser signed in to the storefront (its identity cookie was recognised by /connect/authorize moments earlier) returned 400 invalid_request 'buyer_id is required for anonymous continuation.' - the cookie is ignored and the call is anonymous, no buyer data. Same 400 with no auth header and with Authorization: Basic (garbage credentials); POST /ucp/v1/carts with Basic created an anonymous cart (buyer_id ucp-anonymous-..., no organization). Authorization: Bearer garbage, or a syntactically JWT-like bad token, on GET /ucp/v1/carts, GET /ucp/v1/orders?cart_id= and POST /ucp/v1/carts -> 401, WWW-Authenticate error="invalid_token" with resource_metadata pointing at /.well-known/oauth-protected-resource/ucp/mcp; the JSON body code is identity_required (not invalid_token). A token from the storefront OAuth code flow with resource={storefront}/ucp/mcp -> 200 with the buyer's storefront cart (buyer_id + organization_id) and orders. After logout_buyer the same token gets 401 with WWW-Authenticate error="invalid_token", error_description 'The AI agent was disconnected...' (no realm/resource_metadata, empty body) while /ucp/mcp says 'The OAuth session has ended'. API-key auth was not tested.
