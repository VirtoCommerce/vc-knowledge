Live 2026-11-04, permission holder on /company/info. CustomerChoice, org Off: "Off" / "Not required: each member decides for themselves." with "Turn on"; Turn on opens the inline code step (code emailed to the maintainer); confirmed → "On" / "Required for all company members: a code is sent to their email every time they sign in." with "Turn off", which also needs a fresh emailed code. Members then see "Your company requires it" on /account/security and are asked for the code at password sign-in; after the maintainer turns it off, a member whose own mode is Enabled is still asked. AdminManaged: read-only — "Off" / "Not required: each member decides for themselves." followed by "The store administrator manages two-factor authentication." and no button; the first line contradicts the second, since members cannot decide in AdminManaged.
