From /account/orders/{id} 'Request return' opens /account/returns/new/{orderId} (Select items to return: per-line Return qty, 'Items can be returned within 30 days of delivery'), Continue creates a draft return and opens /account/returns/{id}/edit ('Add details to return RET…') with a required 'Reason*' combobox per line, Serial number, 'What is wrong with it?', attachments, and autosave ('Saved automatically'). Submit return stays disabled with the note '1 line(s) still need a reason' until a reason is chosen. Offered reasons were shown as raw codes: DamagedInTransit, FaultyOnArrival, NoLongerNeeded, OrderedByMistake, WrongItemDelivered. UpdateReturn sends reasonCode per item. After submit, /account/returns/{id} shows Summary (Status Requested, Date, Order number), 'Cancel return', and an items table with Item / Requested / Approved only — the reason is not displayed. A partial quantity (1 of 3) is accepted and the order's Returnable count drops accordingly (3 -> 2); Cancel return restores it.
