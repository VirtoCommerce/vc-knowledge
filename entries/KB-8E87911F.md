As admin, POST /api/files/sales-rep-documents with a small PDF returned 200 [{succeeded:true, scope:'sales-rep-documents', ownerEntityId:null, id}]. Without calling POST /api/sales-rep/documents, an anonymous GET /api/files/{id} (no Authorization header) returned 403 with an empty body. A registered document's file is also 403 anonymously. An earlier observation on an older SalesRep build (Aug 2026) reported 200 with the full body for such orphans, so this behaviour is build-dependent.
