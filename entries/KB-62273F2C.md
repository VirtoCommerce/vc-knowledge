---
With an admin token, DELETE /api/task-management takes the task id as a single JSON string in the body (Content-Type application/json, body "\"<id>\""): that deleted the task (GET /api/task-management/{id} no longer returned it). The same call with a JSON array body (["<id>"]) answered 204 and the task stayed; so did an id in the query string (?ids=<id>, 415 without a Content-Type, 204 no-op with one), and an unknown id as a string also answered 204. DELETE /api/task-management/{id} answered 405. Source (TaskManagementController.Delete, [HttpDelete("")] with [FromBody] string id) explains it: a body that does not bind leaves id null, nothing is deleted, and NoContent is returned anyway. So a 204 from this endpoint does not prove a delete; read the task back.
