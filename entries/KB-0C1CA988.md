GET /api/platform/security/currentuser with a password-grant token for the built-in admin returns 200 with id, userName, isAdministrator=true, passwordExpired, daysTillPasswordExpiry, authenticationMethod, isSsoAuthenticationMethod, memberId, canAccessAdminUI and permissions. It never carries a roles key: UserDetail has no Roles property (vc-platform 3.1076.1 and 3.1078.0). permissions is only the union of the permissions of the roles assigned to the account (SecurityController.GetCurrentUser, L271 at 3.1078.0); isAdministrator is a flag and adds none. So it is empty where the admin has no roles (vcptcore_regression, 3.1076.1, 2026-10-12) and lists that stand's role permissions where it has some: on vcst (3.1078.0, 2026-10-13, 2 runs) the admin holds the roles 'Theme settings changer' and 'SQL queries' and currentuser lists builder:theme, builder:templates and sql-queries:access/create/read/update/delete/reports. Admin rights come from isAdministrator, so an assertion on roles or on a non-empty permissions list does not hold for this account.
