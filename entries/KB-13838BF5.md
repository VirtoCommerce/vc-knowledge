On theme 2.60.0-pr-2523-466f the organization tab's status filter offers no Draft option. A link with status=Draft, or status=Draft&status=Requested, has Draft removed client-side: GetOrganizationReturns is sent without statuses (or with ["Requested"]), only a Requested chip shows, rows are listed. Picking Draft on My returns and switching to the organization tab keeps status=Draft in the URL but does not apply it there. A hand-edited lower-case status=draft is not removed: a raw 'draft' chip shows, GetOrganizationReturns is sent with statuses ["draft"], and the list says 'No returns match your search' (no draft is exposed). On My returns the same lower-case value matches Draft returns server-side.
