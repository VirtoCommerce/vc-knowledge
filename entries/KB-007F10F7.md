On a multilanguage page (en-US default, fr-FR with custom permalink, both published, en-US visibility true), PUT /api/page-builder-pages/grouped on the fr-FR version with visibility:false and no user groups: anonymous slugInfo(fr permalink, fr-FR) returns the en-US version and pageDocument(fr id) is null, en-US alternates list en-US only; a signed-in buyer (bearer token) gets slugInfo(fr permalink, fr-FR) = the fr-FR version and alternates en-US + fr-FR. Note a new multilanguage root is created with visibility:false by default when the field is omitted, which makes its versions signed-in only.
