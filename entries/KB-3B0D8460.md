The operator list offered for a text field (Name, Email, Username) is VALUE-dependent, not type-dependent. While the value contains a comma the dropdown offers only is / is not / is any of; the three wildcard operators are removed from the list with no hint, no disabled state and no explanation, and the currently selected operator is not changed. Clearing the comma restores all six. Observed with Name + 'Elena Kutasina,Lena Mutti'.
