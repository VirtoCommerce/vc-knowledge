A storefront buyer contact (password grant with storeId B2B-store; token role __customer, no permissions) sent one request to /graphql/sales-rep with salesRepCustomers(storeId:"B2B-store", first:20){totalCount} and salesRepTasks(first:50){totalCount}. Response: HTTP 200; data.salesRepTasks = {totalCount:0, items:[]} with no error; data.salesRepCustomers null with errors[0].message "Error trying to resolve field 'salesRepCustomers'." and extensions.code "INVALID_OPERATION" (path salesRepCustomers). So the customers list query reports an unhandled-operation error instead of an authorization error or an empty result for a non-rep caller.
