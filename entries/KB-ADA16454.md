The read-only review step at /checkout/review is gated by the storefront theme setting checkout_multistep_enabled, not by any single feature change. With the flag off the storefront uses single-page cart-as-checkout and a visit to /checkout/review redirects back to /cart; with it on, the multi-step flow includes the review page. A redirect from /checkout/review is therefore a configuration state, not a removed page. The flag is the same family of theme toggle as checkout_coupon_enabled.
