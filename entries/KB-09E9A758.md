Edge 155, 1440x900, light mode, store serving the default preset. Signed out on /sign-in: the Remember me checkbox indicator (.vc-checkbox__indicator, 20x20) has border 2px #a3a3a3 on a #ffffff fill and a #ffffff surround = 2.52:1; the Email, Password and header Search wrappers (.vc-input__container) have border 1px #a3a3a3 = 2.52:1; the wrapper fill equals the page background (1:1), so the border is the only visual edge of the field. Signed in as a sales rep on /account/orders, the desktop Filters popover (nothing applied): Created date, Start date and End date wrappers and the order search box are 1px #a3a3a3 = 2.52:1. No hover change; keyboard focus adds a 2px accent outline (4.99:1 on the default preset). The tokens come from the UI kit (vc-checkbox.vue border-neutral-400, vc-input.vue border-neutral-400), so every page using these atoms carries the same boundary; the sibling VcRadioButton uses neutral-500 (#737373, 4.74:1) since VCST-4703. BL-A11Y-003 / WCAG 1.4.11 require at least 3:1 for UI component boundaries.
