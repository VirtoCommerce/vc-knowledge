A Manager account (isAdministrator=false) whose only role grants builder:access and builder:read obtained a token with a bare password grant at /connect/token (200). With that token POST /api/page-builder-multilanguage-pages/search {storeId} returned 200, while POST /api/page-builder-multilanguage-pages with an empty JSON body {} returned 403, not 400: the permission gate runs before body validation on this endpoint too.
