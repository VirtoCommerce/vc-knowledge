---
One rep owned 7 tasks typed "Call" and one typed "CALL" (written through createSalesRepTask, which stores the type verbatim). With an admin token, POST /api/task-management/search {responsibleIds:[rep], type:"Call"} returned the 7 "Call" tasks; type "CALL" and type "call" returned the same 7 "Call" tasks; the "CALL" task was returned by none of the three. A type outside the list ("AGENT-TEST unlisted") was found by its exact string. GET /api/task-management/tasks/types returned the 8 standard types plus Call. The storefront (/company/tasks) renders the "CALL" task as a call (time and customer on its line).
