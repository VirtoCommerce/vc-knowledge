I set a new images[0] (group=images, sortOrder 0) on 57 categories of the store's virtual catalog through POST /api/catalog/categories, keeping any existing hand-set image at sortOrder 1. 33 were the virtual catalog's own categories and 24 were physical categories linked in from other catalogs. I then requested POST /api/search/indexes/index with documentType=Category and those documentIds, because event-based indexation is off on this stand. Paging Query.categories(storeId, cultureName en-US) over all 433 categories returned the new sortOrder-0 URL as imgSrc for all 57, including the linked ones and the ones that still carry a second image. So imgSrc is the lowest-sortOrder image, and an image set on the source physical category shows through the link.
