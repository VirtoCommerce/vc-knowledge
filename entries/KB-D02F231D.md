2026-11-04, AGENT-TEST B2B buyer with 16 own quotes (statuses Proposal sent 11, Ordered 1, Declined 1, On hold 1, Processing 1, Draft 1). Query.quotes(storeId, userId, cultureName en-US, currencyCode USD, first 100, filter ...): filter "status:\"Proposal sent\"" returned totalCount 11, all Proposal sent; filter "status:Proposal sent" (unquoted) returned totalCount 0 and errors[] empty; "status:Proposal" returned 0; single-word "status:Declined" returned 1; "status:<value no quote carries>" returned 0, errors[] empty. So a single-word status needs no quotes, a multi-word one does, and a wrong form looks the same as no match.
