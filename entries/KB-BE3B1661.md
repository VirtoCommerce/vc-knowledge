Served CSS (vc.kit layer): .vc-add-to-cart is a container (container-type: inline-size); .vc-add-to-cart__text-button is display:none by default and display:block inside @container (width > 14rem); .vc-add-to-cart__icon-button gets display:none inside the same query. Measured on a list-details page (/account/lists/:listId, button mode, signed-in B2B user, Chromium) with the container set to exact widths: 223px and 224px -> icon button display block 32x32, text button none; 225px -> icon none, text block (87x31). Exactly one is displayed at each width, and the shown button's vertical centre matches the quantity input's (388.53 vs 388.52/388.53). Under print media both are display:none (vc.print layer is ordered after vc.kit). On the store observed, catalog cards and the PDP render VcQuantityStepper instead (stepper add-to-cart mode), so VcAddToCart was only present on list-details.
