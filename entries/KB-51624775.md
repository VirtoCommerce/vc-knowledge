Admin token. POST /api/platform/settings [{name:"Sanity.DocumentTypes",objectType:"Store",objectId:"B2B-store",value:"virtoPage,footerNavigation,siteSettings"}] -> 204. Polling GET /api/stores/B2B-store (default response group) every 5 s for 95 s still returned value null for that setting. A full Pages rebuild run right after nevertheless indexed the extra types (635 docs, footerNavigation doc present); after posting "" and rebuilding again it indexed 633 and the footer was gone. GET /api/stores/{id} is therefore not a reliable read-back of a just-posted store setting; judge the effect (index content) instead.
