Cold anonymous PDP loads, Firefox. vcst_qa storefront (theme 2.63.0-pr-2676, flag on): GetProduct query is 1617 chars (whitespace-collapsed) and selects outlines { items { id } }; vcst_dev storefront (theme 2.63.0-alpha.2663): GetProduct 1569 chars, no outlines. Same variables on both (storeId, cultureName, currencyCode, id, previousOutline). GetPageContext is 2763 chars on both and selects mainMenuLinks on both, so mainMenuLinks is not a difference against this dev build. Request count per page is equal (home 10, content page 9, PDP 13): the flag-on build adds ThemeSnapshot and drops the GetMenu call dev sends right after GetPageContext.
