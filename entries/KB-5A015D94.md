On vcptcore (2026-11-24) GET /api/currencies returned EUR with symbol null (USD "$", GBP "£"); the store B2B-store lists EUR, USD, GBP. Querying salesRepCustomerOrderStatistics on /graphql/sales-rep as a sales rep with currencyCode "EUR" echoed currencyCode EUR but period.total.formattedAmount was "¤126,815.86" — the generic .NET currency sign. On a stand where EUR has its symbol set the same query renders "€". So the sign in formattedAmount comes from the platform currency record's symbol; a null symbol is stand data, not a resolver defect. An assertion on "€" is stand-dependent.
