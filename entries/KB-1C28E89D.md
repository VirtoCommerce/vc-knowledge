promotionCoupons sort honours promotion properties such as endDate and name with field:asc or field:desc; nulls sort first ascending and last descending, and name sorting is case-insensitive. Multiple keys are separated by a semicolon only - after a comma everything past the first key is dropped. couponCode (a coupon field, not a promotion one), the space form 'endDate ASC' and unknown fields are silently ignored with no error. An ignored sort falls back to the search service's internal default order, which differs from omitting sort.
