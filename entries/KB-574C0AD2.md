Admin signed in; main menu More > Tasks > All tasks. The grid (default columns #, Type, Name, Assignee, Priority, Status, Due date) listed the rep's call with Type "Call", Assignee = the rep contact's name, Priority "Normal", an empty Status cell (the REST row carries status null; the task blade shows a "To Do" chip) and Due date as day-month in the browser zone. Searching by name returned it; Filters > Type filter > "Call" > Apply sent POST /api/task-management/search with {"type":"Call", ...} and listed only calls (the call included). No default column and no field of the task blade (Type, Summary, Description, Priority, Due, Assignee) names the linked customer. Turning on the optional columns "Object Id" and "Object Type" (Show/Hide Columns) shows the raw organization id and "SalesRepCustomer". The REST row's organizationId is the rep contact's own organization, not the linked customer (a call linked to organization X by a rep whose organization is Y carried organizationId Y, objectId X). Opening and closing the blade without changes sent no update.
