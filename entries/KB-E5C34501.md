Local production build of vc-frontend PR 2600 at a4f29534 with design soft, vcst backend, Firefox 1920. Switched the language to русский through the header language selector (route /ru/catalog, html lang ru-RU). FontFaceSet shows Inter and Geologica faces with unicode-range U+0400-045F (Cyrillic) status loaded besides the Latin faces; Cyrillic body text (e.g. the skip link) computes Inter, the h1 computes Geologica 700, document.fonts.check for Cyrillic text is true for both. No fallback face, no missing glyphs. The design stylesheet (Google Fonts css2, Inter ital+wght 400..900, Geologica wght 400..900) also declares greek and vietnamese subsets for both families; the el locale on vcst carries no Greek UI strings apart from the language name, so Greek was not observed in a heading.
