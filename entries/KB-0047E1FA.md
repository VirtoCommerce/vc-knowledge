Signed in as a rep holding Advanced Sales Representative (sales-rep:access + sales-rep-documents:read). On /company/documents the list (salesRepDocuments, totalCount 29) shows both the October 2026 documents and documents uploaded 2026-08-20/21. Clicking Download on an October document (GET /api/files/{id}) returned 200 and the file downloaded. Clicking Download on two August documents (a Latin-named PDF and a Cyrillic-named PDF) returned 403 and the SPA navigated to /403 'Access denied'. The rows are listed and readable via GraphQL, so the list and the file read gate disagree for the older documents. Consistent with the older documents carrying an owner-entity type the current file read gate does not recognise.
