Opening /apps/admin-shell/#/customers/customer-organization/{id} directly (as an administrator) shows the organization blade with a widget bar "Assets", "MFA: Required", "Index outdated" (the MFA entry sits in the main bar here, unlike the user blade where it is in the overflow). Clicking it opens "Multi-factor authentication of <org name>" with a Mode combobox (Off / Enabled / Required), the hint text, a "Preview of the selected mode. Save to apply it." line after a change, and an Effective status table (Store with the store setting under the name, Code at sign-in). Changing Required -> Enabled and Save sent PUT /api/mfa/modes/organizations/{id} 200; GET read-back returned Enabled and the widget then read "MFA: Enabled"; no 401 and no sign-out. A Manager holding only platform:security:access/read + mfa:read who opens the same URL is redirected to the Admin Shell home (no customer permission).
