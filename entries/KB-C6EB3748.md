Platform 3.1076.1. A Manager user whose only role holds platform:access + store:access sees the Stores item under More and the Stores blade opens, but the blade's POST /api/stores/search returns 403; the blade shows an 'Error 403' banner and 'You have no stores yet'. The same call with that user's password-grant token returns 403. After store:read is added to the role and the user signs in again, POST /api/stores/search returns 200 with all stores and the blade lists them. In both states the Admin SPA also logs 403s on GET api/platform/localizable-settings and api/platform/modules, which come from platform permissions the role lacks, not from store permissions.
