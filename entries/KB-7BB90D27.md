On PageBuilderModule 3.1032.2 (support/3.1032 line, cherry-pick of PR VirtoCommerce/vc-module-pagebuilder#172) with vc-shell 2.6.0, as administrator in /apps/page-builder-shell opened from the store's Page Builder widget, on fresh AGENT-TEST pages: Publish (POST /api/page-builder-pages/grouped/publishing/{groupId}?publish=true -> 200) showed 'Page published successfully' 4/4; Unpublish (?publish=false -> 200) showed 'Page unpublished successfully' 2/2; Archive (Confirmation -> Confirm -> POST /grouped/archive?ids= -> 204) showed 'Page archived successfully' 7/7 for both Draft and Published pages, still visible after the blade closed. Exactly one toast each time; it disappears after about 3 s. Save still shows 'Page saved successfully' once; Clone still shows 'Page cloned successfully' but it is short-lived around the blade swap, so a sampled snapshot caught it 1/3. Status chip, Publish/Unpublish button swap and the Draft/Active/Archived counters update after each action. The deployed shell bundle calls notification.success with PUBLISH_SUCCESS, UNPUBLISH_SUCCESS and the archive alert. The pre-fix 3.1032.0 showed no toast for these three actions.
