On SalesRep 3.1027.0-pr-46-883a, signed in as a sales rep, the call control on /company/my-customers (row, 375 px card) and the profile Phone row on /company/my-customers/{id} were read for owner phones edited via admin REST. Recognised and split into number,extension (a comma dialer pause): "+1-555-040-5060 x45" -> tel:+15550405060,45; "ext. 45", "#45", "EXT. 45", "ext:45", "extension 45", "x 45 " the same. Not recognised, digits glued: "x-45" -> tel:+1555040506045, "ext-45", "ext=45", "x.45", "Ext 45." (trailing dot) -> e.g. tel:+1555061000445. A number stored without '+' keeps no '+' ("(555) 010-2032" -> tel:5550102032). A value that is only an extension ("x45") yields no entry and the org's other numbers stay. The same number with and without an extension is listed twice, each with its own target. Before this build every extension was glued (see KB-1B3C8F12).
