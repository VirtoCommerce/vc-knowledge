On 2026-11-11, as a buyer on /graphql, Mutation.saveLayout(scope accountDashboard, storeId B2B-store) with a document containing a fullWidth region returned modifiedDate 2026-11-11T07:06:22.5054454Z, and Query.layout(scope accountDashboard) read immediately afterwards returned the identical string (7 fractional digits, UTC Z). Regions, blocks and hidden flags read back verbatim. So the save response is the persisted document and a client need not re-query; a test comparing the two must compare the captured value, not a field path written as text.
