In a fresh Firefox session, signing in as an administrator on the back-office login route and then navigating to /apps/tasks opened the Tasks app (All tasks view) already signed in, with no second login. In the app, the sidebar user button (user name + 'Administrator') opens a menu with Theme, Language, Change password and Log Out. Log Out sent the app to its own login route, and the push-notification hub connection closed. Navigating back to the back-office root then landed on the back-office login route (#!/login), with the usual pre-auth 401 for the WidgetColorMarkers setting, so the Admin SPA session had ended as well. Signing in there again restored access to both. For tests: one Log Out in the Tasks app is enough to clear the admin session for both surfaces.
