Signed-in B2B buyer, 4 orders (Manual and Skyflow, new card with and without save): after Mutation.createOrderFromCart returned the order, GetFullCart / GetShortCart (SPA and full page reload) returned the SAME cart id, emptied of the ordered (selected) lines, with shipments/payments cleared. Mutation.updateCartQuantity (operation UpdateShortCartItemQuantity) sent with that cart id answered 200 with the cart in 0.3-2.6 s on 7 occasions, the first ~15 s after /checkout/completed. Source agrees: XOrder CreateOrderFromCartCommandHandler.CleanupCart removes the selected line items, clears shipments/payments/coupons/comment, sets a new CheckoutId and saves the cart; the cart is not deleted. So reusing the cart id after an order is correct, not stale. No docs page states this (createOrderFromCart reference only says it creates an order from the cart).
