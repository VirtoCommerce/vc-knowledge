2026-11-13, vcst_qa. A Manager holding only return:access/read/update gets 200 from POST /api/catalog/search/products ({take:1} -> totalCount 4856, the full catalog) while GET /api/catalog/products/{id} returns 403 for the same token. Source (vc-module-catalog, CatalogModuleIndexedSearchController): the class carries [Authorize] only and SearchProducts / SearchCategories / products/suggestions have no permission attribute. Not marked as a defect: no doc read says the indexed search must be permission-gated; the onX docs only list Catalog Search among the permissions its API key needs.
