On PageBuilderModule 3.1035.0-pr-171-61df shell (/apps/page-builder-shell #/page-builder-assets): typing "p500" at the parent, then opening folder p500 sends /search {folderUrl:.../p500, keyword:"p500"} and shows "No assets in this folder yet" for a 500-file folder; breadcrumb back also keeps the keyword (page resets to 1). Any zero-hit search shows the same empty-folder copy, and in that state Next/Last pagination buttons stay enabled (clicking sends no request); an empty folder shows the same enabled Next/Last.
