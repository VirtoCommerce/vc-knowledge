On vcst_qa, a BuildRight invitation was sent from /company/members as the organization maintainer, and the invitee declined it from the dashboard's Organization invitations widget. The roster row then showed an 'Inactive' badge; the membership read back by REST had status Rejected. The row's Actions menu offered only Edit role, Block user, Delete and Login on behalf — no 'Resend invite'. Re-inviting the same user through the Invite members dialog worked. Observed in regression run REG-2026-11-12-1023-W5e (case B2C-MBR-033).
