Twice on vcst_qa (2026-11-04): a B2B buyer created an RFQ from /cart (status Processing); in the classic Admin SPA (Quotes) the admin lowered the proposed price on each line, clicked Save, then 'Submit proposal' and confirmed the 'Confirm proposal' dialog; the quote moved to 'Proposal sent' in admin and in /account/quotes. The buyer's storefront header notifications badge stayed at the same count (66) before and after, and the popup listed only older unrelated push messages; nothing about either quote appeared. So a real admin proposal, not just a REST status write (KB-E23CFAF6), raises no storefront push notification on this build. An email notification was not checked.
