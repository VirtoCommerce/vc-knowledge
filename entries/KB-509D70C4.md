On x-cart pr-141 / cart pr-194 with scope Customer: an id differing only in letter case from a present target is a no-op on add and removes that target on remove; duplicates within one addSharedWithIds (any case) collapse to one target; adding a present id or removing an absent id is a silent no-op. addSharedWithIds longer than 1000 entries (even 1001 copies of one served id) is refused INVALID_OPERATION; exactly 1000 is accepted. removeSharedWithIds of 1001 ids is accepted. An add of an id that is not an existing organization returns Access denied, the same as an unserved one.
