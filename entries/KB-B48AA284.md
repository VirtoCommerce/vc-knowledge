On PageBuilderModule 3.1035.0-pr-171-61df: searching a keyword in the picker, then clicking a breadcrumb or a folder found by the search, sends the next POST /api/page-builder-assets/search with the SAME keyword for the new folderUrl (skip reset to 0). A folder found by name (tpl-{{...}}) therefore opened showing "No assets found" / "0 of 0" although it holds tpl-marker.png, which appears only after clearing the search box. The keyword is sent as a literal string (template syntax not evaluated).
