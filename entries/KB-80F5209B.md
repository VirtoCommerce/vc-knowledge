A custom section type with an en-US and a de-DE name and default text was saved over MCP and the theme published (approval by a second user). Anonymous Query.themeSnapshot for cultureName en-US and de-DE both returned the type under customSections with the matching language's name and default; the /de/ page rendered the German text and the en page the English one. The storefront (theme with Site Builder on) registers each custom-* type from the snapshot and lazy-loads the renderer chunk only on pages that place one.
