ProductSubscription build pr-1-8177 adds store settings ProductSubscription.Customer.AllowSkip, AllowOrderNow, AllowChangePaymentMethod, AllowPause, AllowChangeFrequency (readable via Query.store settings). With AllowSkip/AllowOrderNow/AllowChangePaymentMethod false (observed state before an admin turned them on), Query.productSubscriptions returned canSkip/canOrderNow/canChangePaymentMethod false on an Active subscription, the delivery card's Subscription settings menu offered only Pause/Cancel, and Mutation.skipProductSubscription answered SUBSCRIPTION_ACTION_DISABLED "This store doesn't let customers do this. Please contact the store." After the settings were set true, the flags became true and the menu offered Skip delivery, Order now, Change card, Pause, Cancel. Meanwhile the checkout terms text and PDP bullets still promise skip any time.
