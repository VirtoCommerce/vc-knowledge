On vcptcore_regression via xAPI: updateMemberAddresses with <script>alert(1)</script> or <img src=x onerror=alert(1)> in line1, the same script in city, firstName or description, and "><svg onload=alert(1)> in line2 each answered errors[0].extensions.code VALIDATION with data null and saved nothing; an address with apostrophe, ampersand and # ('5 O'Brien & Sons Rd, Apt #4') was saved verbatim. In contrast changeComment on the cart accepted <script>alert(1)</script>, <img src=x onerror=alert(1)> and <b>back</b> and returned them verbatim, so for the cart comment only output encoding protects the page. Which setting causes the address rejection (EnableScriptInjectionValidation) was not readable and VirtoOZ has no page for it.
