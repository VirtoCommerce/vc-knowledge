Classic (AngularJS) Admin, Catalog > Import > VirtoCommerce CSV import, comma CSV Sku,Name,CategoryPath,Vendor,AltName. In Map columns I cleared CategoryPath and Vendor with the x, mapped Name to AltName, OK. Reopening Map columns showed Name=AltName with CategoryPath and Vendor empty, 3 of 3 runs with a fresh wizard each time. Start import POSTed propertyMaps Name->AltName, CategoryPath and Vendor csvColumnName null; products were created at the catalog root with the AltName value as name, no vendor, and no category. Changing a field and closing the blade with X instead of OK left the saved mapping unchanged on reopen. Switching the delimiter to Semicolon and back to Comma, or uploading a file with a different header, reset the mapping to the server auto-mapping. Opening Map columns and pressing OK without edits imported with the auto-mapping (category created from CategoryPath, Vendor filled). Re-importing the same SKUs updated the existing products (same ids, new names) without duplicates. Start import stays disabled until Map columns has been opened at least once.
