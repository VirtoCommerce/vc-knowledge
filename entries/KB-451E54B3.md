On vcst_qa (2026-11-11, product AGENT-TEST-Config-FileUpload, optional section 'Design Upload', product-configuration scope configured: DOC RTF DOCX TXT PDF XLS XLSX JPG PNG ODT, 9.5MB, 5 files): a 5 MiB PNG uploaded with POST /api/files/product-configuration -> 200 and was listed '(5MB)'. A 24 MiB PNG (an accepted type) was rejected client-side: no POST was sent, the file stayed listed as 'oversize_test.png — File size exceeds the allowed 9.5MB (24MB)' with 'Fix file upload errors to continue.' under the drop zone, until 'Remove file' was clicked. The section value stayed on 'None' (checked) and Add to cart stayed enabled (disabled=false) because the section is optional. A 24 MiB MP4 is rejected by the type check first ('File format is not allowed'), so it cannot test the size limit. No console errors.
