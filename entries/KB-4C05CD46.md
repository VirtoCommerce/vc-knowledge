On /company/dashboard (theme 2.60.0-alpha.2579) the 'My customers' KPI card renders the assigned-customer count as its value (equal to the left-rail My customers badge and to salesRepCustomerCounts.assignedCustomers), then 'N ordered this month' and 'N new customer(s)'. No change/delta indicator is rendered. The SalesRepCustomerCounts request carries storeId, mtdFrom and mtdTo and selects only assignedCustomers and thisMonth { orderingCustomers newCustomers } — no comparison block. The KPI row has six cards in default order: Orders in “New” status, Active carts, Orders placed · WEEK, · MTD, · YTD, My customers. The order-statistics query asks for countChangePercent comparisons, but with no previous-period orders they return null and no delta is shown on any card.
