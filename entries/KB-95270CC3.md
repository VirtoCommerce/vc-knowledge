On vcst_qa (2026-10-07, theme 2.59.0-alpha.2548) on /account/quotes/:id/edit for a Draft quote request, clearing a line's quantity stepper to 0 shows "Value must be a positive number" under the field (aria-invalid=true) but Save changes stays ENABLED. Clicking it sends ChangeQuoteItemQuantity {quoteId, lineItemId, quantity: 0}; the refetched quote no longer contains that line — the server removes the line rather than storing quantity 0. So a quote row whose tier quantity is 0 cannot be produced from the storefront. Same Save-enabled behaviour observed on the PR build of VCST-5990.
