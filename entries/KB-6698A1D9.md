On Stable 16 Admin > Dynamic properties > Add new property: choosing Integer disables the Multilingual and Dictionary switches; choosing Long text disables Multivalue and Dictionary. The REST API (POST /api/platform/dynamic/properties) still accepts LongText+isArray and Integer+isMultilingual; such properties render in the member widget with no editor, and the console logs 404 for dLongText-multivalue.html / dInteger-multilang.html (saving then writes null values per locale for Integer multilingual). On the member widget a Required property keeps OK disabled until filled; for Required+Multilingual every listed language (10 here) must be filled. Integer inputs reject non-numeric text and accept 2147483647. Properties are listed in ascending displayOrder; dictionary+multilingual shows per-locale item names.
