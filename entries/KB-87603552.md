2026-10-13, admin token. For a product priced in four price lists (two USD, one EUR, one PTS), GET /api/products/{id}/prices returned only the EUR and one USD row; GET /api/catalog/products/{id}/pricelists returned all four lists with their rows (incl. the second USD list and the PTS row). For a product whose only price is a PTS row, /api/products/{id}/prices returned [] while xAPI product(currencyCode:"PTS") resolved that price. A seeder that checks idempotency against /api/products/{id}/prices never sees such a row and re-PUTs it every run; read through /pricelists instead. DELETE /api/pricing/pricelists/{plId}/products/prices?productIds={id} removed only that list's row for that product.
