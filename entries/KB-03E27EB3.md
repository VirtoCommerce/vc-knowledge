2026-10-14, on ImageTools 3.1006.1 and 3.1003.1. A user whose only role grants platform:access + thumbnail:access + thumbnail:read gets 200 from POST /api/image/thumbnails/tasks/search, 403 from create (POST), update (PUT) and delete (DELETE) tasks, but 200 from POST /api/image/thumbnails/tasks/run (a job is enqueued and the task's lastRun is set) and 200 from POST /api/image/thumbnails/tasks/{jobId}/cancel. Source: ThumbnailsTasksController puts [Authorize(Permission.Read)] on Run and Cancel; the module defines only access/create/update/delete/read, with no separate execute permission. The Admin task-list Run toolbar command has no permission gate either.
