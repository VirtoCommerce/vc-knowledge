On a vc-frontend 2.60 build (PR build of the scope-slot fix, API on a QA stand), SPA-click a breadcrumb to a parent category, then click the header Cart link (or submit a header search) before the GetCategory query returns (~0.5 s, no throttling needed). Cart (or /search?q=...) renders, then when GetCategory resolves the URL is replaced with the left category slug (e.g. /printers/multifunction-printers or ...?q=laser) while the content stays Cart / global search. Source: shared/catalog/components/category.vue watcher calls updateLocalizedUrl(data?.category?.slug) after the awaited fetchCategory with no unmounted/cancel guard; same code on dev. Reload or Back then shows a different page than the one on screen.
