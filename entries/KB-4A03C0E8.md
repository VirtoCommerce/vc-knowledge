Theme 2.60.0 with the SalesRep plugin built from vc-module-sales-rep PR #26 (unreleased). The New task Type select lists Registration Review, Order Review, Order Processing, Product Catalog Management, Pricing and Promotions, Content Management, Customer Support, Other, Call (the salesRepTaskTypes order). Choosing Call keeps the 'New task' heading and adds a Customer picker (empty, optional; it offered exactly the rep's two served organizations), Time (9:00 AM) and 'Add to calendar'. Switching the type back to Other removes all three, and Save sent Mutation.createSalesRepTask with type 'Other', dueDate at local midnight and no customerId key; the response returned customerId and customerName null and the row reads 'Due <date> · Other'.
