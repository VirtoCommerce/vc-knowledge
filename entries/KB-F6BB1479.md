GET /api/platform/modules with an admin token: the VirtoCommerce.SalesRep entry lists VirtoCommerce.TaskManagement 3.1005.0 in dependencies with optional=true, on both SalesRep 3.1015.0 (vcst_qa, vcptcore_qa1) and 3.1016.0-pr-26-92d4 (vcptcore). An unsatisfied optional dependency does not skip the module, so SalesRep-without-TaskManagement is a supported install shape (PR #26 also ships a WithoutTaskManagement storefront E2E).
