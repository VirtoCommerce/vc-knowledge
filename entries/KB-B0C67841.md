Signed in as a rep with sales-rep-documents:read (theme 2.60.0-alpha.2579). The Document library widget on /company/dashboard (mainRight rail, query SalesRepDocuments first:5 sort 'isPinned:desc;createdDate:desc') renders per row: a file-type icon (PDF), the displayName (truncated), a line 'Published Oct 5, 2026 · 12 pages', and an Open button. It renders no category and no size, although the query returns category and size for every item. 'Browse all' opens /company/documents: a featured 'Latest publication' card (type, page count, size rendered as '569 byte', published date, Open/Download), category chips with counts (All 21, per-category), a 'Search by name' box, and a card grid where each card shows a type badge (PDF/PNG/JPG/ZIP/XLSX), display name, category and 'Published <date> · <n> pages' — no per-card size. PNG and JPG documents, whose previewUrl is null in the API, render the same generic PNG/JPG file icon as non-image types; no inline thumbnail. A no-match keyword shows 'No documents match your search' with a 'Reset search' button.
