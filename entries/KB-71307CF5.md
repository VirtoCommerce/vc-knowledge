On Catalog 3.1048, POSTing [product] (an array holding one product, even the unmodified GET /api/catalog/products/{id} body or a minimal id/name/code/catalogId/categoryId body) to POST /api/catalog/products returned 500 {"message":"Object reference not set to an instance of an object."} for three different products, while POSTing the same product as a bare object returned 200. The route binds a single CatalogProduct; an array is not bound and fails with a NullReference rather than a 400. Distinct from KB-969D7E09 (variations duplicate key).
