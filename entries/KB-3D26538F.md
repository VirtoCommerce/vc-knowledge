On vcptcore_regression a password grant on the storefront host /connect/token (scope offline_access, storeId B2B-store) returned an access_token with header alg RS256 typ at+jwt, payload aud resource_server, exp minus iat 1800, role __customer and claims iss, exp, iat, aud, scope, jti, sub, name, email, role, memberId, oi_au_id, oi_tkn_id (no password or hash); the refresh_token is opaque (not a JWT). On storefront /graphql the valid token resolved me to the user; the payload-edited token, an alg=none token, a token with exp edited into the past and 'abc.def.ghi' each resolved me as Anonymous with HTTP 200 (a mutation with such a token returns extensions.code Unauthorized). GET /api/platform/security/users on the platform host answered 401 for the valid storefront token and for the forged ones.
