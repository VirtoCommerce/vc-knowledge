On vcst_qa 2026-11-27 (theme 2.63.0, store B2B-store preset Mercury) document.documentElement.dataset.preset was "mercury" and getComputedStyle(:root).getPropertyValue('--color-primary-500') was #f99e24, equal to color_primary_500 of the served preset file mercury.json. Source (useThemeContext.ts addPresetToThemeContext, setPresetAttribute) writes the lower-cased hyphenated resolved file name to dataset.preset, and falls back to the theme's bundled default (settings_data.json current) when the name does not resolve. A case can therefore compare the applied palette with the preset FILE instead of a literal.
