On theme 2.60.0-pr-2523 (Return 3.1005.0-pr-28), a buyer's own submitted return created through xAPI createReturn without customerReference opens at /account/returns/{id} with Summary rows Status, Date, Order number and Comment only — no 'Purchase order reference' row. Another return of the same buyer created with customerReference set shows the row labelled 'Purchase order reference' with the value, between Order number and Comment. A Cancelled own return shows the 'Cancel return' button disabled.
