Three Node processes each sent POST /connect/token grant_type=password for the same admin account within a few milliseconds; two got 200 with tokens, one got HTTP 500 with no error/error_description in the body. Re-sent alone a minute later it answered 200. Single observation, cause not isolated (likely a concurrent write on the same user during sign-in); scripts that mint the admin token in parallel should stagger or share one token.
