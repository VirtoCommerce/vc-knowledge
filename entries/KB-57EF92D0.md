On admin shell 3.1095 / Platform 3.1099.0, the category blade's personalization widget opens a "Tags" blade (toolbar Save, Reset, Edit tags) instead of the older "AVAILABLE USER GROUPS" panel. Ticking a user group and saving moves that row to the top of the list; unticking and saving moves it back. The assignment and the removal both persist after reopening the blade. No "N direct / N inherited" summary line is shown on this blade.
