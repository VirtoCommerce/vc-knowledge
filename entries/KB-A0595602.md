Created a USD price list in Admin Pricing > Price lists (POST /api/pricing/pricelists 200), confirmed GET /api/pricing/pricelists/{id} 200 with its name, deleted it from the grid via the 'Confirm delete' dialog (type 'yes' > Confirm); the row disappeared. GET /api/pricing/pricelists/{id} then returned HTTP 200 with the literal body null rather than 404. In the same session GET /api/catalog/products/{id} for a just-deleted product returned 404, so deletion checks must treat a null body as 'gone' for price lists.
