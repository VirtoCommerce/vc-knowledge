Admin, B2B-store, Draft list Load content: empty.json, a truncated JSON and a plain-text file each create no page; the Draft pages blade shows an alert with the raw parser message ('Unexpected end of JSON input', "Expected ',' or '}' after property value in JSON at position 46", "Unexpected token 'T' ... is not valid JSON") plus an expandable stack trace (JSON.parse at index96294.js), logged as '[@vc-shell/framework#use-error-handler] Captured Error: SyntaxError'. A file holding a top-level array of two text sections shows 'Content loaded successfully' and a New page blade, but Save sends POST /api/site-builder-pages/grouped with only {name, permalink, storeId} and the stored draft content is {settings:{...}, content:[]} - the sections are lost. An object file is saved through POST /api/site-builder-pages/create-group-page with the content; the import blade saves the page with Visibility off and no language unless they are set. The Save content export format is an object {name, permalink, ..., content:{settings, content[]}}.
