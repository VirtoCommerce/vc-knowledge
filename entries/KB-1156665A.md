As a signed-in B2B buyer, POST /api/files/quote-attachments returned HTTP 200 with [{succeeded:false, errorCode:INVALID_SCOPE, errorMessage:"Unknown scope 'quote-attachments'", errorParameter:"quote-attachments", name:null}], and Query.quoteAttachmentOptions and Query.fileUploadOptions(scope:"quote-attachments") both returned null. The Quote module setting Quotes.FileUploadScopeName is the default quote-attachments. Upload scopes are not registered by the Quote module: FileExperienceApi binds them only from the appsettings section FileUpload (FileUpload:Scopes), as the developer docs show for quote-attachments. So this is deployment configuration, not a code defect. The theme 2.59.0 storefront shows the message as "Unknown scope ''." (empty parameter, the VCST-6281 message bug fixed in a later theme) and keeps Submit disabled.
