With an admin bearer token, GET /api/assets?folderUrl=/ answered HTTP 500 with body {"message":"length ('-1') must be a non-negative value. (Parameter 'length')\nActual value was -1.","stackTrace":null}. GET /api/assets and GET /api/assets?folderUrl= (empty) both returned 200 with the 49 root entries. A folder path with a trailing slash such as folderUrl=/name/ works. The Admin Asset management blade lists the root without sending '/', so the UI is not affected; tests that pass folderUrl=/ for the root get a 500.
