VCST-6974 hotfix delivery check (scenarios 8/9), vcptcore-regression (ProfileExperienceApiModule 3.1020.4, Stable-16, store B2B-store). Caller = storefront buyer USER (org 105c2c4e, token permissions only storefront:organization:view + storefront:user:view, i.e. NO xapi:my_organization:edit). (a) updateContact targeting a contact in a DIFFERENT org (ORG_USER, org 96f109a7) returned HTTP 200, errors[0].extensions.code=Forbidden, "Access denied.", data.updateContact=null. (b) updateContact targeting a SAME-org colleague (USER2, org 105c2c4e) without org-edit permission returned the identical Forbidden/null. Pre-fix any org member could rewrite a colleague's contact PII and cross-org edits matched on any shared org. Org scope is the caller's CURRENT organization. The positive case (same-org WITH xapi:my_organization:edit succeeds) was not exercised — no pooled account holds that org-scoped permission. updateContact bodies (firstName/lastName/id only) reach the app; createUser/updateUser bodies are edge-WAF-blocked on this stand.
