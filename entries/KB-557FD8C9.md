On vcst_qa with a random change id: the mcp:approve user's authorization-code agent token (client claude-admin-qa) got 403 {"message":"An AI agent cannot review pending changes here. The user reviews them in the back office (MCP > Pending changes)."} from POST /api/mcp/pending-changes/{id}/approve and /reject. A platform password-grant bearer of a user without mcp:approve got 403 {"message":"Pending change '<id>' was not found, or you may not review it."}. Anonymous: 401 with an empty body and no Location. The Admin Shell screen for reviewing is titled "Agent approvals" (#/mcp-approvals); no "MCP > Pending changes" menu was seen.
