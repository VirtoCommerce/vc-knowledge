Signed in as a sales rep (Edge 1920x1080, theme 2.60.0, hub from the SalesRep plugin). On every /company/* hub page (Dashboard, My customers, customer profile, customer orders, Customer orders, Tasks) and on /account/dashboard, the left rail ('Sidebar') shows exactly one 'Sales Rep hub' section with Dashboard, My customers (badge) and Tasks. Opening an order from the hub's customer orders grid went to /account/orders/{orderId}; that page rendered breadcrumbs Home / Account / Orders / Order #<number>, the H1 'Order #<number>' and a right-hand sidebar (Order data, Order summary, Billing address, Shipping method), but no left account rail at all, so there were zero 'Sales Rep hub' rail sections on it. The storefront source explains it: the ':orderId' route group under account orders carries meta { hideLeftSidebar: true } (client-app/router/routes/account.ts), so the rail is hidden for every user on that page, not only for reps. A test that counts the rail section 'on every screen' of a hub journey must exclude this page.
