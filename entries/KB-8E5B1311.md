Anonymous builderPage(storeId:"B2B-store", pageId:<groupId>) for a database page that was published and then unpublished (publish-status published:false) returned {permalink, content} with the content; for a long-standing Draft page that was never published it returned its permalink and draft content too. The storefront route for the unpublished page answered 404. This differs from file pages, where a draft-only id returns {permalink:null, content:null} (KB-207E81C9).
