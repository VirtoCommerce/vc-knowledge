Predefined notification templates are editable BY DESIGN: saving an edit turns it into a persisted override, and the Restore toolbar command brings back the shipped default (the platform user guide says so). isReadonly is a different flag - it would exclude a template from the save payload - and nothing in the module assigns it, so it is inert. isEdited is not a backend property; the template list synthesizes it client-side, and an override row is displayed with a Predefined Edited badge. The genuinely predefined template has no list row and is reachable only by its type-based deep link. The note warning that saving replaces the default is missing from the edit blade although its localized strings remain.
