A "text" block whose text is raw HTML (div elements with data-vc-track, data-list-id, data-product-id/-sku/-name/-price attributes and an a href) was saved with POST /api/page-builder-pages/grouped/{groupId}/content and published. The storefront read path (Query.slugInfo(permalink) then Query.pageDocument(id).content) returned the HTML byte-for-byte with every data-* attribute present, so the module stores it unsanitised. The storefront renders the text block through v-html-safe (vue-html-secure safeHTML), which strips only script/noscript/noembed, on* attributes and javascript:/data: src|href, so data-* attributes also survive rendering (from source; browser render not observed in this run).
