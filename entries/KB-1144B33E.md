The xAPI runtime endpoint is POST /graphql on the platform host, the path the storefront client uses, and the interactive GraphiQL editor is at /ui/graphiql. /xapi/graphql is not a valid path; older documents that show it are stale. Some modules add a separately scoped schema under /graphql, for example /graphql/sales-rep.
