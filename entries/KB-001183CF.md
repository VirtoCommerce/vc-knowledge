Coupon validation and application through xAPI are case-insensitive: a code typed in another case applies the same coupon. That means two distinct coupons whose codes differ only by case collide, and the promotion policy picks between them. The coupon card on /account/coupons forces the code to uppercase in JavaScript, both in the display and in the copied clipboard value - a presentation-only issue, since the uppercased code still applies.
