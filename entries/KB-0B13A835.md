In the admin SPA, Stores > B2B-store > Search configuration > Facets: adding a Range facet and clicking Save sent PUT /api/catalog/aggregationproperties/B2B-store/properties (204, saved correctly). From then on the browser repeated GET /api/stores/B2B-store + GET /api/seoinfos/duplicates?objectId=B2B-store&objectType=Store + POST /api/platform/dynamic/properties/search about three times a second, 80+ cycles within 30 s, with no user action, until the blade was left. Reproduced on a second Save (removing the facet). No console error is logged; the data is saved correctly. Looks like a blade refresh that re-triggers itself.
