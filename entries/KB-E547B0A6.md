Guest, Firefox, store B2B-store with design classic and preset paprika. The only preset/design chunk requested is assets/paprika-<hash>.css (classic has no design chunk, so no design chunk can be slowed). Held via network interception on / and on a category page: no delay -> #app content at ~0.9-1.0 s; held 6 s -> first #app content at ~6.7-7.0 s; held 12 s -> heading at ~12.8 s; never answered -> #app still empty and body text empty after 25 s (no spinner, no fallback). Aborted (network error) -> the app mounts normally at ~0.7 s with no console error and no visible difference (--vc-widget-bg-color resolves to the same value), html keeps data-design="classic" data-preset="paprika". So the loaders never reject (a failure is swallowed) but the mount awaits them with no timeout: a slow or stalled preset chunk is a blank page for as long as it lasts.
