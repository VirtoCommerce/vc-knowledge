On CatalogPersonalization 3.1006.1, GET /api/personalization/taggeditem/{id}/tags/count returns a single integer computed as Tags ∪ InheritedTags, distinct. Observed: untagged 0, direct-only 1, inherited-only 1, one direct plus a different inherited group 2. It never reports the two separately. TaggedItemSearchCriteria has EntityId, EntityIds, EntityType, Ids, ChangedFrom and Label, but no tags field. A body of {tags:[g]} is ignored, and the search returns every tagged item (15 on the stand) for any group.
