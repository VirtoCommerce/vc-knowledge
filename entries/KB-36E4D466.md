A signed-in user built a named cart with one line, a FixedRate/Ground shipment and DefaultManualPaymentMethod payment; cart validationErrors(ruleSet:"*") was empty, so the cart was orderable. createOrderFromCart(command:{cartId}) for that cart sent with no Authorization header returned HTTP 200 with data.createOrderFromCart null and errors[0].extensions.code Unauthorized. The owner's cart(cartName) read back the same cart id with itemsCount 1, so no order consumed it. Regression case CRX-GQL-055.
