Signed-in B2B-store buyer, desktop 1920x1080, theme vc-frontend-next 3.3.0, category page /cables-docks-adapters. Wheel-scrolled to window.scrollY 800, clicked the header 'USD · EN' button: the preferences popover opened, focus moved into .vc-popover__body, and scrollY became 260. Reproduced twice, and the same 800 -> 260 jump happens with the 'Account menu' popover. Pressing Escape to close then sets scrollY to 0. Upstream vc-frontend fixed this in VCST-6197 (#2608) with floating.value.focus({ preventScroll: true }) in vc-popover.vue, so on this Next build the page still scrolls when a popover takes focus.
