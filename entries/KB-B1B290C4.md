On vcst_qa (2026-11-03), a buyer placed orders through xAPI. Selecting `coupons` on the returned CustomerOrderType — both in the `createOrderFromCart` mutation response and in a later `order(id)` query — returned errors[] with code INVALID_OPERATION ("Error trying to resolve field 'coupons'"), for an order that carried a coupon discount and for one without. The other order fields resolved. The storefront's own order page does not select this field, so the UI is unaffected; only API consumers that ask for the field hit it. A client that needs the coupons used on an order cannot get them from this field on this build.
