On vcptcore, anonymous POSTs to the storefront host: /connect/token grant_type=passkey with no credential answers the platform JSON 400 missing_parameters (same as the back-office host); /connect/token grant_type=mfa and /api/mfa/resend answer the platform JSON invalid_two_factor_token; POST /api/platform/security/sign-in answers an nginx HTML 405 Not Allowed, while the same call on the back-office host answers JSON 400 unsupported_grant_type. The storefront passkey grant posts to /connect/token, so it does not need the cookie endpoint; the cookie endpoint is the back-office passkey door.
