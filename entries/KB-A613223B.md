The xAPI addItem mutation can return an empty items list in its own response even though the add succeeded, and an immediate cart query can lag too. A follow-up cart-state mutation that returns items - unSelectAllCartItems, selectAllCartItems, changeCartItemQuantity, removeCartItem - returns the settled line items with their ids. So do not read a new line item id from addItem's items.
