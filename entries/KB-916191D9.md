SalesRep built from vc-module-sales-rep PR #26 (unreleased), theme 2.60.0, a freshly created Sales Representative serving two sample orgs, 1920 px. On /company/my-customers/{organizationId} the Quick actions widget shows Order on behalf and Create quote disabled, Send email enabled (opens 'Send a message'), and Schedule call enabled once the customer has loaded. Schedule call opens a dialog titled 'Schedule call' with Title 'Call', Customer = the page's organization (clearable picker), Due date empty (placeholder MM/DD/YYYY), Time 9:00 AM (required asterisk; 96 options from 12:00 AM to 11:45 PM in 15-minute steps; no clear control, Backspace/Delete do not empty it), Priority Normal, Notes (0 / 1000) and an 'Add to calendar' group with Google Calendar and Apple Calendar unticked; there is no Type field. Save stays disabled while no day is picked, whatever the Time shows, and enables once a day is picked; Cancel or Escape closes it without a request. Save sends Mutation.createSalesRepTask {name 'Call', type 'Call', priority 'Normal', customerId = that organization id, dueDate = the picked local day and time as a UTC instant with milliseconds, description = Notes}, closes the dialog and toasts 'Task saved'; the response returns the saved task with customerId and customerName. Each reopening starts fresh (Time back to 9:00 AM).
