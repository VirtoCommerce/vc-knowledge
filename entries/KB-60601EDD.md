On Stable 16 (platform 3.1076.1) a successful users/create for a Customer account returned HTTP 200 with a body whose only keys were succeeded and errors - no id. To obtain the userId for follow-up calls (users/{userId}/locked, organization-memberships, users/id/{userId}), read it with GET /api/platform/security/users/{userName}, which returns the full user record including id.
