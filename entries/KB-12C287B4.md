2026-11-10, vcst_qa, platform 3.1096.0, public client claude-admin-qa, user signed in on the platform host ~7 minutes earlier. GET /connect/authorize?...&code_challenge_method=S256&max_age=1 -> 302 to {BACK_URL}/?ReturnUrl=/connect/authorize?...max_age=1 (Admin login page). The Admin SPA finds the user still signed in (GET /api/platform/security/currentuser 200) and navigates back to the ReturnUrl, which again exceeds max_age and redirects to the login page. The lane HAR shows 38 authorize requests in 55 seconds (about one every 1.4 s) until the tab was closed; no login form is ever usable and no code or error reaches the client. Source (AuthorizationController.ChallengeLogin at the 3.1096.0 tag) challenges with RedirectUri = the unchanged returnUrl and does not sign the stale cookie out.
