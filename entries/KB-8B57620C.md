Anonymous products(storeId: B2B-store, currencyCode: USD, productIds: [4 product ids], filter: "agenttest_length_mm:[5 TO 20]") returned all 4 products although only one has a value in that range; the same with [30 TO 60]. The same filters WITHOUT productIds returned exactly the matching product (agenttest_length_mm:[5 TO 20] → the product with value 9; [30 TO 60] → the one with 45; agenttest_length_mm:45 → the one with 45), so the range filter on a Number property works and the field-name match is case-insensitive (AgentTest_Length_mm:[5 TO 20] gave the same). With productIds the products are loaded by id and filter is not applied — scope a filter check with a query keyword or the category instead.
