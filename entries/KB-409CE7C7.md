Stock counts for a store only on the store's own main fulfillment center. Stock written to another fulfillment center - for example the first result of the fulfillment-center search, whose order is arbitrary - leaves the product at zero for that store. The fulfillment-center search projection does not include code, so matching on code there never succeeds.
