On vcst_qa, signed in, on /cart 'select a shipping address' opened a 'New address' modal; with Address = <script>alert(1)</script> and all other fields valid, Create was accepted: the page showed the address line as plain text (no element injected, title unchanged) and Query.cart.shipments[0].deliveryAddress.line1 returned the raw payload. The same payload on /account/addresses 'Add new address' was refused with field message 'HTML tags are not allowed', and Mutation.updateMemberAddresses answers VALIDATION ''Line1' must not contain HTML tags.' So the cart shipment address path does not apply the member-address HTML validation; output is encoded on the storefront.
