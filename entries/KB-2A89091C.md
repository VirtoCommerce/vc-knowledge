B2B-store: header Icons menu set to a store link list and published (publication 7). The list had been created with language null: Query.themeSnapshot(cultureName en-US).menus and Query.menus(keyword) both returned [] and the header kept the default five icons. Setting the list's language to en-US through POST /api/cms/B2B-store/menu, with no republish, made themeSnapshot.menus return it and the storefront header showed its links; adding a third link likewise appeared on the next page load while the publication stayed 7. All other store link lists carry a language (en-US, de-DE, fr-FR, en-GB).
