In XCart 3.1042.0 the cart line field showPlacedPrice resolves to LineItem.IsDiscountAmountRounded (LineItemType.cs:131-133). RewardExtensions.ApplyRewards(LineItem) resets it to true on every recalculation (line 58) and ANDs in reward.RoundAmountPerItem for each applied catalog-item promotion reward (line 84). So it is true for a line with no promotion discount (a catalog sale price alone keeps it true) and false as soon as any applied item reward has 'Round amount per item' unchecked. The session channel is not an input: the same cart read with a password-grant token and a punchout-grant token (channelId=punchout, same role __customer) returned identical showPlacedPrice values per line. No B2B-store setting controls it (only Stores.EnablePriceRoundingForTotalsCalculation exists in that area).
