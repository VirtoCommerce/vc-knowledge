On vcptcore_qa1 (Punchout 3.1000.0-pr-1-fbb9) anonymous POST /api/punchout/cxml (text/xml) returned HTTP 200 text/xml for every rejection: non-XML or empty body -> Status 400 not well-formed; no Request -> 400; ProfileRequest -> 450; wrong or missing SharedSecret, and an unmapped Sender Identity -> 401 with an empty message (indistinguishable); configuration without StoreId -> 500; return URL outside AllowedReturnUrls (prefix match, case-insensitive, 'https://host' without the trailing slash fails a 'https://host/*' entry) or missing BrowserFormPost -> 400. A configuration pointing at a nonexistent store returned 401 (not 500) for an unmapped identity because the mapping check precedes the store checks in source. GET -> 405. Success path not exercised (it writes a session).
