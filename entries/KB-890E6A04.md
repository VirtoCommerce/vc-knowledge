On Return 3.1005.0-pr-28-62f9 an admin-created return on the organization's order with storeId=Electronics was returned by return(id) to a holder whose token was issued for B2B-store, and the storefront page /account/returns/{id} on the B2B-store storefront rendered it with "Requested by". organizationReturns(storeId:"B2B-store") did not list it, but organizationReturns(storeId:"Electronics") with the same B2B-store token did. storeId matching is case-insensitive (b2b-store lists the same rows). Whether a holder should see other stores' returns is not documented.
