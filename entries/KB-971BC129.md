Created 100 orders via POST /api/order/customerOrders with an admin token, each body carrying a createdDate spread over the previous 400 days. Every response and every later search result carried createdDate = the moment of the POST; 0 of 100 kept the sent value. Consequence: past statistics windows (previous month, last year) cannot be populated through the REST API; any period-over-period baseline built from API-created orders is zero.
