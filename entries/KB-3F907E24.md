Chrome 155, Sales Representative with a call on Oct 23, 2026 selected in the widget calendar. The row is a li with the name 'Call' (title attribute 'Call') and a span .sales-rep-tasks__meta (12 px, color #525252, white-space nowrap, overflow hidden, text-overflow ellipsis, no title or aria-label) reading 'Due Oct 23, 2026, 3:45 PM · Contoso Ltd. · Call' next to an 'Upcoming' status chip. Measured clientWidth vs scrollWidth of the span: 375 px viewport 200 vs 245 (45 px hidden, reads 'Due Oct 23, 2026, 3:45 PM · Contos…'); 600 px 425/425, 768 px 337/337, 900 px 469/469, 1023 px 592/592, 1024 px 577/577 (fits); 1280, 1440 and 1920 px 204 vs 245 (41 px hidden) because the widget sits in a 352 px right rail. The full text is in the accessibility tree (one generic node), but a sighted user has no tooltip, no focusable row and no expansion, so the customer name is only partly readable; the Tasks page shows the same string wrapped in full. No horizontal document scroll at any width tested (375 to 1920).
