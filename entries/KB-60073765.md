On vcst_qa (theme 2.62.0-pr-2596) the store-wide salesRepCoupons total was set to 31 (4 pages of 10, one coupon on page 4). With the rep on page 4, that coupon's promotion was deleted through the admin API (rep total 30). Clicking Previous sent SalesRepCoupons {first:10, after:"20"}, which returned totalCount 30; the pager immediately read 1-3 with 3 current and Next disabled, 10 cards shown. The rep never saw an empty page and no cached total was served: the smaller total arrives with the first page change, not by time.
