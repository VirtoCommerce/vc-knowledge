Read in source at the versions deployed on Stable 16 and the dev line. vc-module-catalog CatalogModuleConfigurationsController.CreateOrUpdateConfiguration runs `case ConfigurationSectionTypeVariation: section.Options = [];` with the comment "Variation type uses product variations as options, not predefined options". PR #869 (2026-03-12) added this together with the Variation type. In vc-module-x-cart, GetProductConfigurationQueryHandler builds options only in AddProductOptions (type Product) and AddTextOptions (type Text), so a Variation section always returns options []. The choices are the parent's product.variations, and a pick is sent as ConfigurationSectionKeyInput {type:"Variation", option:{productId}}. vc-frontend 2.59.0 product-configuration.vue renders only the product, text and file section types and has no Variation branch. A test that expects predefined Variation options, or a rendered Variation picker on this theme, tests something that was not built. The Platform User Guide documents only the Product, Text and File section types.
