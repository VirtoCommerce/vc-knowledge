On vcst_qa 2026-11-27 (platform 3.1101.0, VirtoCommerce.WhiteLabeling 3.1008.0) Query.whiteLabelingSettings(organizationId, storeId: B2B-store, cultureName: en-US) for an organization with main-menu list AGENT-TEST-main-menu-electronics returned top-level mainMenuLinks as Support(4), Company(3), Brands(2), Home(1) and Brands.childItems as Tablets(3), Phones(2), Laptops(1); footerLinks as Help(2), Legal(1) with children Warranty(2), Support(1) and Terms of Service(2), Privacy Policy(1). Two calls gave the identical order. So the array order is descending by priority, and the docs describe priority as the field that determines the menu order, so a consumer sorts by it. A case that asserts array positions in priority order (Home first) fails on the response order alone; assert the title-to-priority mapping or sort first.
