As admin on Electronics (theme folder default): POST /api/site-builder/save?storeId=Electronics&theme=default&draft=false with files=[{path:"default/templates/agent-test-sb008-<6 chars>.json",type:"themes",content:{a:1}}] answered 400 {"error":"\"<path>\" is not a theme file the builder saves (templates, custom section types, header and footer groups, settings, rules, brand, palettes)."}. The same call with path default/templates/product.json or default/templates/product.agent-test-<key>.json answered 400 {"error":"Theme files are saved as drafts and published with theme/publish."}, and a read of the builder-named path with draft=false and draft=true answered 404, theme/status listed no draft. A template key must be product, category or page, optionally followed by .<lowercase-key>, so a free-named templates/<name>.json is not a builder file. Earlier builds (SiteBuilder 3.1000.0-pr-1-28d0) answered the drafts message for default/templates/x.json (KB-3D1055D2); the allow-list of VCST-6963 now answers first.
