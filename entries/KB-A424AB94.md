On vcptcore_qa1 (theme 2.59.0-pr-2477-ff59, OtpSignIn enabled, 2026-10-01): typing an email in the code view and clicking "Sign in with a password instead" opens the password form with an EMPTY email field; "Sign in with a one-time code instead" returns to the code view, again empty. Choosing the password view and reloading /sign-in lands on the code view. The password view (email + password + Remember me + Forgot your password? + Sign up) still honours returnUrl: /sign-in?returnUrl=/account/orders then a successful password sign-in lands on /account/orders. A signed-in user opening /sign-in is redirected to /catalog.
