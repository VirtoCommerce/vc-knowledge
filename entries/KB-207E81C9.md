Anonymous builderPage(storeId, pageId) with the content-file id that Query.pages returns (base64 of '<store>::pages::/<file>.page'): published page -> content = the published document, permalink null even though the document has one. Published page with a saved draft -> still the published document. Draft-only page (never published) and the '.page-draft' path id -> {permalink:null, content:null} (an object, not null). Plain file path, the zero GUID or 'abc' as pageId -> errors[] code FORMAT "Error trying to resolve field 'builderPage'", data null. Query.pages and pageContext list only the published page, not the draft-only one.
