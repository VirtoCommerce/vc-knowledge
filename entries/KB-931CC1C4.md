Started a Product Build (POST /api/search/indexes/index, deleteExistingIndex false) and, once its push notification showed totalCount > 0, started a ContentFile Build. The second run's notification was finished within about 0.3 s with description "Indexation completed with errors", errorCount 1, errors ["Indexation is already in progress."], and 0/0 processed. The first run completed normally ("Indexation completed successfully", 413/413). A ContentFile Build started right after the first run finished completed successfully (3/3), so the lock was released. Only one indexation runs at a time; a concurrent one is skipped, not queued. Read the notification through POST /api/platform/pushnotifications {ids:[id]}.
