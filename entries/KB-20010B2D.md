On SiteBuilder 3.1003.0-pr-5-01b3, create_page with kind multilanguage_page_copy creates the copy, but its change result carries object_name = the SOURCE page's name and object_id / multilanguage_page_id = the NEW page's id. The new page's own name (e.g. "<name> (copy)") is not returned. In source (PageCreateTools), the change is built with ObjectName = the source root's name and is not updated after the create. The language_version kind builds its own name "{name} ({language})" correctly.
