With GET /api/seoinfos/explain and the Admin Candidates blade: a category whose only record is assigned to another store got StoreMismatch + NoSeoPath; a category whose only record is in a language the store lacks got LanguageMismatch + NoSeoPath; a category whose only record is inactive got Inactive alone (the store still builds its link from an inactive record); an inactive category with an active record got ObjectInactive alone; a category outside the store's catalog got NotInStoreCatalog. Activating the inactive record in the category's SEO widget and saving made the next Debug resolve it (Stages 1-6 = 1, Final = the category). A request in a store language with no record (de-DE vs an en-US record) resolves the default-language record with no LanguageMismatch.
