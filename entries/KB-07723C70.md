In a regression run, a rep's cold full-page navigation to /company/customer-orders fetched /assets/plugin-route-placeholder-<hash>.js from the storefront host (theme 2.60.0-alpha.2579). All hub page chunks, the manifest and remoteEntry.js came from /modules/$(VirtoCommerce.SalesRep)/plugins/vc-frontend/. The placeholder chunk is the host's generic route hand-over component that renders while the plugin settles, so an assertion that every script of a hub page comes from the plugin folder must exempt it, together with the host's own federation runtime (/assets/remoteEntry-*.js).
