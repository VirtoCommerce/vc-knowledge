On 3.1006.0 with a system option fileSuffix 'sm' present (not in the task), uploaded shoe_smooth.jpeg and jpeg-baseline.jpeg (byte-identical) into a folder with an AGENT-TEST FixedWidth task. Regenerate via POST /api/image/thumbnails/tasks/run and the event-based upload path both produced jpeg-baseline_<sfx>.jpeg only; shoe_smooth.jpeg got nothing. The 'is already a thumbnail' filter matches _<suffix> substrings from all options, not only the task's.
