On a stand whose store Assets folder holds no exported sitemap files (the Sitemaps 'Export to store assets' action has never been run), the sitemap admin API returns 200 with the configured sitemaps, but the storefront answers 404 for /sitemap.xml, /sitemap/sitemap.xml and /sitemap/{store}.xml. The storefront serves the sitemap from exported asset files, so it is absent until an export is run.
