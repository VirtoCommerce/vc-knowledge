B2B-store, admin: POST /api/content/themes/B2B-store?folderUrl=/default/custom-sections multipart file named X.json-draft (an unsafe type that designer/save refuses with 400) answered 200. Afterwards the folder search lists the file as X.json (published true, hasChanges false), GET /cms-content/Themes/B2B-store/default/custom-sections/X.json-draft is 404 and X.json is 200, theme/status lists no draft, and a page draft placing the type renders in the designer preview with the unsafe markup left out. DELETE /api/content/themes/B2B-store?urls=/default/custom-sections/X.json-draft answers 204 and removes it; a following DELETE of X.json answers 500 (file not found).
