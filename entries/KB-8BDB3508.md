2026-11-13, vcst_qa. Back-office Manager holding only return:access/read/update (alias RETURNS_AGENT_NO_AUTHORIZE), signed in through the vc-mcp-onx authorization-code flow: get-orders, get-customers and get-inventory return result.isError true with the text "Unknown error" (no mention of access); create-sales-order and update-order return success:false, error.code FORBIDDEN, "Request failed with status code 403"; get-returns succeeds; get-products succeeds (platform catalog search is not permission-gated, KB-384B6F79). The same calls as admin succeed. An update-order through onX by admin sets the order's modifiedBy to admin. Platform REST answers the restricted token with 403 on GET /api/order/customerOrders/{id} and /api/catalog/products/{id}. The user guide attached to the ticket says a missing permission makes the tool return a refusal Claude can explain; for reads it does not.
