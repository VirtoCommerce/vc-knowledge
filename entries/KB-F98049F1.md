Query.returnReasons(storeId, cultureName) reads the localizable Return.Reasons dictionary for the given culture and returns the entered text, falling back to the code when no entry exists. Observed with one en-US and one ru-RU entry on FaultyOnArrival: en-US reads "Faulty on arrival", ru-RU reads the Russian text, de-DE, fr-FR and a call with no cultureName all read the bare code; the four codes with no entries read their code in every culture. An earlier observation of localizedName == code was therefore a no-culture or untranslated-culture read, not proof that translation does not work.
