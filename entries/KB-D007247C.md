The Designer image-control picker (Choose from asset library) lists GET /api/assets?folderUrl=/stores/{storeId}/Page Builder as its root; the breadcrumb root is labelled "Page Builder" and folders at the platform asset root are not reachable from it. The Page Builder Office "Assets Library" tab uses the same root. In the stock B2B theme every images control (Image, Slider slide, Features column, Call to Action with Image) declares multiple:false, so the picker runs in single-select mode there.
