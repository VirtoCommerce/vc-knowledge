Home page, guest, Chromium, fresh context per run, CLS observer installed before first paint (layout runner). The desktop header logo is an img with a fixed CSS height and no width, aspect-ratio or width/height attributes. At 1280x900 and 1920x1080 with fast-3G or slow-3G throttling, the logo rect goes from width 0 to 182 px while it loads, and the header search bar's left edge moves right by exactly 182 px. Layout-shift attribution names div.search-bar (impact about 0.003 to 0.005) and the right-hand header link list (about 0.0005 to 0.0014). It is a visible horizontal jump, but a small CLS share: the home CLS of 0.17 at 1280 comes from the footer (0.166). Without throttling the same shift entries appear, but the logo has loaded before the first rect sample. At 375x812 the mobile header puts the logo last in a justify-between left group, so nothing sits to its right and no header element appears among the shift sources. The logo src is the logoUrl of whiteLabelingSettings when one is set, otherwise the theme's logo_image setting, so the theme cannot know the aspect ratio when it builds.
