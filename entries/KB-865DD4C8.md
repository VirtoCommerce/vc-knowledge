On vcst_qa, a GET /api/catalog/products/{id} body was POSTed back (variations[] removed) with one inline property (no propertyId) changed: (a) name and the values' propertyName Size → AgentTestSize; (b) on another product valueType ShortText → Boolean and value "True" → true. Read back with POST /api/catalog/products/plenty?respGroup=ItemProperties, each product had exactly one value for the property, under the new name / type, carrying the SAME property value id as before; no value remained under the old name. Done on 9 products, all identical. The next Product index build indexed them under the new field name (and wireless as boolean).
