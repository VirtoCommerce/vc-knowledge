Electronics, theme 2.64.0-pr-2698, new draft page in the Admin Shell designer. HEADER group starts empty: Add section -> Header adds the section; its Content panel has Logo width, Category menu (switch + Menu picker) and Icons -> Menu, a searchable 'Choose a store menu' select listing the store's link lists with their languages (Electronics: Camcorders, footer, main-menu, Televisions); picking one and clearing it both change the preview header at once (cleared = Bulk order, Lists, Orders, Cart). FOOTER group has a Footer section with zero blocks; its panel says 'Add Menu blocks for the link columns. Without any, the footer shows the store's footer links'. Expanding the row -> Add block -> Menu adds a 'Quick links' block with Heading (translatable), Menu picker ('Empty: the links below') and a Links list with + Add; each row has Label (translatable) and URL plus move/remove. Adding the block replaces the store footer columns in the preview with one QUICK LINKS column, and the typed label appears in it while typing. Nothing was saved (Discard all).
