On first (uncached) calls of Query.salesRepActivities, salesRepCustomerInsights and salesRepCustomerActivitySummary for the year-to-date period, response times were 17-83 s; repeat calls with the same arguments returned in 0.2-2 s (60-minute cache). Three of roughly twenty cold calls ended at about 60.5 s with isAnalyticsAvailable:false and the GA-backed parts empty (searches badge 0 where it is 1, searchTerms [] while browsedProducts in the same response was populated), with no GraphQL errors. The DB-backed orders and customers counts were still correct. An immediate retry returned the correct data with isAnalyticsAvailable:true, so the failed read is not cached. The analytics-diagnostics endpoint reported every stage Passed at the same time.
