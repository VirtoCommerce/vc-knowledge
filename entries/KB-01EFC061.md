Anonymous POST /graphql, products(storeId: B2B-store, first: 3) with no currencyCode/cultureName: HTTP 200, no errors[], totalCount 4655. store.defaultCurrency was USD (nine available currencies incl. EUR). Two of the three items returned price.actual in EUR (e.g. EUR 78.00 although a USD list price of 189 exists, shown in prices[]); the third, which has only a USD price, returned USD. So one page mixed EUR and USD. With currencyCode: "USD" all three returned USD. Docs consulted (VirtoOZ general) did not state the fallback rule, so this is recorded as observed, not marked a defect. A test asserting price currency must pass currencyCode explicitly.
