On a store whose store URL is an unreachable host, the designer preview iframe fails (GET <storeUrl>/designer-preview -> unknown host), the Add section list shows "No sections match" with an empty search, and Save of a theme field (logo URL) shows "The page couldn't be saved. Theme changes are saved once the storefront preview has loaded: it names the schemas they are checked against." without sending a request. POST /api/site-builder/theme/publish?storeId=<store> with no catalogHash -> 400 {"error":"The theme is not valid: the publication names no schema catalog: preview the storefront first"}; the publication number stays the same. A page publish (POST /api/site-builder/git/publish, flow blob) works without the preview.
