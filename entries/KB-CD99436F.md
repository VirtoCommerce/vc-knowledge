On x-cart 3.1037.0-pr-141 / cart 3.1011.0-pr-194, addWishlistItem(listId of a list the caller does not own, productId already in it, quantity 1) returns data null with errors[] Access denied (Forbidden) for a Read-only target reader and for a user with no access, and Unauthorized for an anonymous caller, yet the existing line quantity increases by 1 each time. The increase shows on the owner's wishlist(listId) and the reader's sharedWishlist, including through a never-used cache key (different cultureName), so it is persisted, not only cached. removeWishlistItem, a rename via changeWishlist, and removeWishlist by the same reader are refused with nothing changed.
