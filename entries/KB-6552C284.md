BackupRestore 3.1007.0 (vcptcore_regression) and 3.1001.2 (vcptcore_stable), 2026-10-13. Select all > Start backup > Cancel (POST /api/platform/exortimport/tasks/{id}/cancel 200): the panel turned to 'Backup finished' with Start/End and a Download backup link, and the toolbar stayed Select all (disabled), Unselect all (disabled), Cancel (disabled) with no Start backup, observed 40+ seconds after End. A NORMAL completed run (only Dynamic properties selected, 17 KB archive) left exactly the same toolbar. Clicking the Backup row again reopens the blade with Select all enabled and Start backup back. Identical on both module versions, so it is the blade's post-run state, not a cancel defect and not new in 3.1007.0. The cancelled run leaves a partial archive in Backup storage (17 MB here).
