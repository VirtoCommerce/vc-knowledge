On both POST /graphql and POST /graphql/sales-rep, a sales rep whose salesRepCustomers totalCount is 0 got salesRepTaskTypes = [] (HTTP 200, no errors), while a rep serving 7 organizations got ["Customer Support","Product Catalog Management","Order Processing","Order Review","Pricing and Promotions","Content Management","Registration Review","Other","Call"]. Source: SalesRepTaskTypesQueryHandler returns [] unless CanReadAsync, which requires TaskManagement present AND IsSalesRepAsync = at least one granting organization membership (SalesRepQueryHandlerBase). That code is identical on dev and on PR 26 head 92d48e1 and was introduced by VCST-5732 (#16, commit 630919c2); PR 26 did not change it. The storefront New task dialog therefore shows no Type select for such a rep.
