On theme 2.59 the Request return button (request-return-button.vue) renders only when the store allows returns for the order status and returnableItems has an item with isReturnable true. Otherwise the button is not rendered and no message is shown. The ineligibilityReason text (for example OUTSIDE_RETURN_WINDOW, Outside the return window) appears only per item in the return wizard select-items step.
