Read in vc-module-pricing (sha 18ebee70): PricingModuleController.UpdateProductsPrices (PUT api/products/prices) runs ProductPriceValidator, which applies PriceValidator to every Price: List must be greater than 0, Sale must be >= 0 and <= List, MinQuantity > 0. A configuration option is an existing catalog product (Platform user guide, Manage Product Configurations: options are selected from existing catalog items) priced through the Pricing module, and its contribution to the line is unit price times option quantity (KB-4B47D094). So no option can add a negative amount; the total can only fall by choosing a cheaper option or an option with a sale price below list. Not observed live by this session; the stand's fixture AGENT-TEST-CFG-013 has options priced 0..250 and the executed math matched base plus the sum of option prices.
