Signed in as a sales rep with a saved default customerProfile layout, opened /company/my-customers/{orgId}. Outside edit mode no Max rows input (spinbutton) is rendered on My recent orders, Top sellers or Available coupons. Clicking Edit layout shows an edit bar (Reset, Cancel, Save layout) and exactly three Max rows spinbuttons: My recent orders (1-20), Top sellers (1-10), Available coupons (1-20); the five stat cards show only a Reorder handle and no settings control. Clicking Cancel removed the edit bar and all three spinbuttons, and no SaveSalesRepLayout request was sent between entering edit mode and Cancel. A screen-reader instruction paragraph ('Editing layout. Keyboard: press space on a block to pick it up...') remained in the accessibility tree after Cancel.
