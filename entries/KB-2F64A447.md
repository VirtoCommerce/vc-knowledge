Only sharedWishlist(sharingKey), where the key is the list's SharingSettingType.id: it returns the list with access Read, isOwner false, the current sharingSetting.message, and targets empty (targets are visible to the owner only). The same member gets Access denied (Forbidden, data null) from wishlist(listId), and the list is absent from that member's wishlists() roster. A member of an organization that is not a target gets Access denied from sharedWishlist as well, with no message text in the response. Observed on x-cart 3.1037.0-pr-141 / cart 3.1011.0-pr-194.
