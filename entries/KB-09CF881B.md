On theme 2.60.0-pr-2523-466f, an organization maintainer holding xapi:my_organization:return:view opened /account/returns?scope=Organization&status=draft. The page showed 'My returns' pressed and the maintainer's own list (their own Draft return listed), i.e. the capitalised value falls back to the own scope like any unknown scope value; nothing about other buyers was requested or shown. The client compares the scope query value to the exact string 'organization' (useReturns.ts scope computed). Lower-case ?scope=organization opens the organization tab as usual.
