Signed in as a personal user with two saved addresses, /cart > Shipping address change button opens a Select address dialog with table 'available addresses'. Only the Address header has a sort button (class vc-table__title--sortable). On open all five th have aria-sort=none (including the non-sortable Recipient name, Phone, Email, Active). First click on Address: aria-sort=descending (rows 456 Oak Avenue before 1 Zed Road); second click: aria-sort=ascending (rows reorder). Sort state persists when the dialog is closed and reopened in the same page load. Regression cases A11Y-SORT-001/002/003 expect none -> ascending -> descending and no aria-sort on non-sortable headers, so they fail on this build.
