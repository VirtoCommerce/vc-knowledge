B2B-store, theme default, no product template file: GET /api/site-builder/template?path=default/templates/product.json&draft=true answers 404 and designer/theme-file for default/templates/product.json and default/content/templates/product.json answer content null. The schema catalog the designer holds (GET /api/site-builder/catalog?storeId=B2B-store&hash=96e0af86) has templates.product with previewMessage.templateKey product and default: true (a flag, not a document); sections.product-info allows product-properties, product-description, product-variations, product-assets and product-options, and its only field default is variationsLayout b2b. Opening Product templates > Default in the designer shows a single Product section with no blocks and the banner that the site shows its built-in layout until the template is saved; Create template (copy of default) saves exactly that (product-info, blocks []). The storefront's real default (product-info with properties, description, assets and variations blocks plus related-products, recommended-products and product-reviews) is in the storefront bundle only; in source the protocol 2 loaded message lists builtInTemplates as keys (vc-frontend preview-v2.ts) and the designer accepts only a theme file or a templates[*].default object with content (site-builder vue templates.ts startingTemplate).
