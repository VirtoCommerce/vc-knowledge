On vcst_qa 2026-11-27 (platform 3.1101.0, AdminShell 3.1101.0, WhiteLabeling 3.1008.0) in /apps/admin-shell/: Stores > B2B-store, the primary widget strip shows Settings, SEO, Dynamic properties, Authentication, Notifications; the chevron "More widgets" lists White labeling. It opens one blade (no Logo/Favicon sub-blades) with Enabled switch, Theme preset select (with clear x, no dictionary pencil), Main menu link list, Footer link list, and Logo, Secondary logo and Favicon upload zones each with a free-text URL box beneath. Toolbar is Save and Reset (revert unsaved); there is no Clear. The Shell's global search for "white labeling" returns only the two settings "White labeling enabled" and "Theme preset name" (group WhiteLabeling > General), no menu entry; the Shell Home dashboard's 11 widgets include no white-labeling widget. The same widget is registered in source for the organization detail blade (CustomerOrganizationDetails); that blade was not opened. Nothing was saved.
