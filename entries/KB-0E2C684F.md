Signed in as a sales rep (/company/dashboard) and separately as an organization buyer (/company/sales-reps). Rendered body text was sampled every ~20 ms from navigation start. On 15 of 15 unthrottled loads (5 with the browser cache disabled, 5 with it enabled, 5 as the buyer), the Corporate link text read "Sales_rep.navigation.link" for 44-75 ms from first paint, then "Sales reps". No other plugin key appeared unthrottled. In runs where the plugin's en locale chunk was held, this key appeared at ~926 ms, which is before the chunk was requested (~1095 ms). So the link comes from the plugin's declared menu contribution, which the host renders before plugin code runs. Host labels (Quote requests, Back-in-stock list) were translated in the same frames. The settled state is fully translated.
