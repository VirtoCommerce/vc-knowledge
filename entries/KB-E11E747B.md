On /bulk-order (Copy&Paste tab) a signed-in shopper pasted 'validSku,1' and 'NONEXISTENT,1' and clicked Add to cart. Mutation.addBulkItemsCart returned the cart with the valid line added (no top-level GraphQL errors) and a payload errors[] entry {errorCode: CART_INVALID_PRODUCT, objectType: CatalogProduct, objectId: <the sku>, errorMessage: 'Product with SKU <sku> was not added to cart. This SKU doesn't exist.'}. The storefront opened a dialog titled 'Add to cart SKU errors' with a SKU/Products table listing the bad SKU as 'Invalid product'; the cart badge updated to the valid quantity. No crash, no console error.
