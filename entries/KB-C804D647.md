On Stable 16 (Platform 3.1076.1) PUT /api/members with a ShortText dynamic property value of 512 chars returned 204; 513, 1000, 1023, 1024, 1025 chars returned 500 'String or binary data would be truncated in table ...MemberDynamicPropertyObjectValue, column ShortTextValue'. The Admin dynamic-properties widget accepts any length (no maxlength, OK enabled), and member Save shows '500: Internal server error' whose details show the same SQL text. The Admin value-type picker describes Short text as 'Text values under 1024 characters' (same label on Stable 15). Source: DynamicPropertyObjectValueEntity.ShortTextValue [StringLength(512)].
