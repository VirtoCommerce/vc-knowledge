Uploaded a pdf then a png into one optional File section and added to cart, five times. The configuration-items file links rendered png-first in the cart on one run and pdf-first on others; for the same order the cart showed png-first while Order details showed pdf-first; across three placed orders Order details was pdf-first twice and png-first once; a quote created from a pdf-first cart listed png-first. xAPI Query.orders configurationItems.files returned upload order (pdf, png) for the order whose cart showed png-first. So the display order is neither upload order nor stable; tests must not bind file names to row position.
