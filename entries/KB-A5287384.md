Signed-in buyer, B2B-store, cart with items. With SUPER applied (Custom code) and a never-validated preset code (agenttestlc062) applied via its preset card, the network shows POST /graphql ValidateCoupon(agenttestlc062) -> RemoveCoupon(SUPER) -> AddCoupon(agenttestlc062), all 200 with no errors, only one coupon left applied (discount 5%). When the new code (FREE) had already been validated earlier in the same page session, no ValidateCoupon request was sent: only RemoveCoupon(old) -> AddCoupon(new), consistent with an apollo-cached validate result. The live region announces 'Coupon SUPER removed. Coupon FREE applied.' An invalid code (BOGUS123) sends ValidateCoupon returning false and no AddCoupon, and the Custom code card shows 'This code is not valid'.
