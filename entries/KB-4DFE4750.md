The vc-uk-htmleditor directive (vc-module-core) initialises UIkit htmleditor with mode split and maxsplitsize 1000: the editor renders in split view (code + preview side by side) when the editor element itself is at least 1000px wide and in tab view (Markdown / Preview tabs) below that. Observed on Core 3.1011 PR-264 build: editor 996px = tab, 1000px = split; a normal-width Notification layout blade (editor 760px) is tab, the maximized blade at a 1920 viewport (editor 1630px) is split. With the PR-264 ResizeObserver the mode re-evaluates on blade maximize/restore and on window resize; preview strips script tags and on* attributes (enablescripts false).
