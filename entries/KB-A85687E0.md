On /company/activities and /company/my-customers/{id}/activities an order row reads 'Order placed #<number> $<total> <status chip>' with an exact timestamp. In the dashboard My activity widget the same order renders as 'Order placed #<number>', the organization name and a relative time only (also seen in the 2026-10-20 regression run on vcptcore_qa). Source: the widget renders ActivityRow with the compact prop, and activity-row.vue gates both the total and the status chip on !compact (comment: 'Compact rows (dashboard widget): relative time, no status/total'), so the omission is deliberate, not a missing field. The widget also has no 'Based on tracked activity only' footer; that footer belongs to the customer profile's Customer activity widget.
