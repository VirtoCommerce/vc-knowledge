B2B-store, theme 2.63.0-pr-2602-6507, store setting ProductSubscription.Enabled set explicitly to false through the store settings API, checked ~30 s later in new browser sessions. /how-subscriptions-work rendered the storefront 404 page (title 'Page not found') both as guest and as a signed-in buyer. /account/orders listed the buyer's renewal orders with an empty badge cell (no 'Subscription' badge on any row), and a renewal order's page showed its lines with no subscription row, no SUB link and no 'Placed automatically' alert; the only trace was the order's own stored comment text ('Subscription renewal REN…'), which is order data, not a feature mark. HAR of both walks: no subscription GraphQL operation sent, no errors[] in any GraphQL response, no 4xx/5xx from storefront or platform. Setting the value back to true restored the PDP purchase options in a new session within ~2 min.
