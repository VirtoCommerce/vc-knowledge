A Landing Page (database page) details blade shows, after the first Save, a "Search engine listing" group with Page title (placeholder = page name), Meta description and Meta keywords; values saved and re-read on reopening the blade. The designer's Page settings panel (file or database page) holds only Page Header / H1, Hide Breadcrumbs, Template and Layout. In the schema catalog the designer PUTs for B2B-store (storefront 2.63.0-pr-2676), the only select with searchable:true and a request is sections.category.categoryId (typing "print" narrowed the list to Printers / Inkjet / Laser; the choice saved and rendered); product sections take plain SKU strings or a keyword, and no product- or page-picker field type exists. The image control's "Choose a file" dialog lists folders, opens one with a breadcrumb, and the picked file saves as its full cms-content URL including the folder.
