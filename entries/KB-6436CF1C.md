On a local docker stand (platform 3.1097.0, PageBuilderModule 3.1041.0-pr-182, storefront served by a plain nginx container), opening any page in the Page Builder designer (admin /Modules/$(VirtoCommerce.PageBuilderModule)/Content/page-builder-designer/index.html) shows the preview iframe as "localhost refused to connect". The frame request GET {storefront}/designer-preview?ep={admin origin} fails in the browser with net::ERR_BLOCKED_BY_RESPONSE. The designer document is served by the platform with Cross-Origin-Embedder-Policy: credentialless, Cross-Origin-Opener-Policy: same-origin, CORP same-site, X-Frame-Options DENY and CSP frame-ancestors 'self'; the storefront document (nginx) sends no COEP, no CORP and no CSP. A COEP parent requires its nested document to opt in to COEP, so the browser refuses the preview frame. Editing, saving and publishing in the designer still work; only the preview pane is empty, and the designer logs postMessage target-origin warnings because the frame has origin null. Opening the same /designer-preview URL in its own tab loads normally.
