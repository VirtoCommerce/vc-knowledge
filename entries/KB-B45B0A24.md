On B2B-store and Electronics: Content > store > Pages > page > Design opens /apps/site-builder-shell/?storeId=..&designType=pages&designPath=..; Stores > store > Site Builder widget opens /apps/site-builder-shell/?storeId=..; Admin Shell Marketing > Sites > site > page opens #/content/site-builder-designer/{groupId}. All show the same Vue designer (Sections/Theme/Shared tabs). No NewSiteBuilder store setting exists (store settings list only GitContentEnabled, GitContentRepository, PreviewUserIds). With module SiteBuilder.General.StoreUrl null, GET /api/site-builder/designer/storefront returns the store's own url and previewPath /designer-preview and the iframe loads <storeUrl>/designer-preview?ep=<platform>&protocol=2. A store with no URL shows "No preview: the site has no storefront URL...". With PreviewUserIds empty there is no Preview as control; set to one user id it offers "Anonymous visitor" plus that user's userName; emptied again it disappears.
