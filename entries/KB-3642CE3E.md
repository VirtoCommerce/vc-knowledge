Body {storeId, name, permalink, cultureName} without content returned 400 with a text/plain body "StoreId, Name and Content are required.". Adding content as a JSON STRING '{"settings":{},"content":[]}' returned 200 application/json: a GroupedPageBuilderPage {id, storeId, cultureName, name, permalink, status:"Draft", hasChanges:true, visibility:false, organizationId:null, pages:[{id, groupId:null, status:"Draft", content:<echoed>}]} - pages[0].groupId is null in the create response but equals the group id on GET /api/page-builder-pages/grouped/{groupId} (where page content is null). The page was immediately returned by POST /api/page-builder-pages/search {storeId, keyword}. GET /api/page-builder-pages/languages without storeId returned a fixed ["en-US","fr-FR","de-DE","ja-JP"]; with ?storeId= it returned that store's languages.
