Theme 2.61.0-alpha.2605, Firefox, /agent-test-ga4-html-product-lists. The first [data-vc-track=product-link] in [data-list-id=agent_test_html_full] is <a href="/printers/.../hp-officejet-pro-8610-..."> with no target. A plain click performed a full page load (title reset to 'Virto Commerce', dataLayer restarted with gtm.js), so window.dataLayer on the PDP held no select_item. Ctrl-click on the same link opened a new tab and the source page's dataLayer gained exactly one select_item {item_list_id agent_test_html_full, items[0] item_id 565705636 (= data-product-sku), item_name = data-product-name, price 279.98}. So the tracker fires; dataLayer-based checks of plain-HTML links must use a modifier click or read /g/collect.
