Fulfillment center description stored as indented HTML (a Branch Hours table) where the SAT hours cell contains a blank line followed by ~44 spaces of indentation before CLOSED. Admin Shell fulfillment center blade: the table shows MON-FRI rows normally, then the SAT hours cell contains a code block with the literal text 'CLOSED </td> </tr> <tr> <td>SUN</td> <td>CLOSED</td> </tr> </tbody> </table>'; no SUN row. Classic admin Inventory blade, description editor Preview tab: the same rendering (raw HTML inside SAT, no SUN row); its Markdown tab shows the source intact. Opening the Admin Shell blade did not mark it dirty (Save disabled, no unsaved banner). Editing only Short description and saving sent PUT /api/inventory/fulfillmentcenters with the description byte-identical to what GET returned, so the stored HTML was not altered by that save.
