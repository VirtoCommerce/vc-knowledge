The Admin orders list calls POST /api/order/customerOrders/search (or /indexed/search with a filter) with responseGroup=WithPrices; the detail blade uses GET /api/order/customerOrders/{id}. For an order whose shipments include one in a different currency than the order (EUR shipment on a USD order), search returned total 909 / shippingTotal 55 / taxTotal 139 while GET-by-id returned 903 / 50 / 138, so the grid and the detail blade disagree. Orders module 3.1018.0, Platform 3.1076.1. The mixed-currency shipment was seeded/recurring-order data.
