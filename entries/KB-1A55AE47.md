On vcst_qa, a storefront buyer token (and an unsigned probe with the same arguments) called Query.properties(storeId B2B-store, first 100, cultureName en-US). With types [CATALOG, CATEGORY, PRODUCT, VARIATION] it returned totalCount 19 and 19 items (16 PRODUCT, 3 VARIATION). With types [PRODUCT] it returned 16 items, all PRODUCT, but totalCount 19. Observed 3 times on 2026-11-04. So the items honour the types argument while totalCount does not: an assertion comparing the PRODUCT totalCount with the all-types totalCount cannot show that types was applied; count the items instead.
