With the store loyalty setting loyaltyEnabled=false (loyaltyMode and loyaltyCurrency null) and an active ProductPoints program whose factor covers the ordered product, an order placed through xAPI createOrderFromCart wrote no operation-log row and the user balance stayed 0 for at least 2 minutes. Earning requires the store loyalty setting to be enabled.
