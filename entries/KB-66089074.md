A saved-for-later card shows only the product name, price and Move to cart - no configuration detail - because the saved-for-later item projection does not select configurationItems. Rendering configuration on saved cards is not implemented yet; it is a gap, not data loss. After moveFromSavedForLater the restored active-cart line carries configurationItems again (a Text section comes back as name null plus customText), and its Components list shows the chosen values. There is no selectedConfiguration field; configurationItems is the field to read. The guest-to-signed-in cart merge happens server-side during sign-in, so no explicit mergeCart call need appear in the network log.
