MFA 3.1003.0-pr-6-2da2, global MFA off, CustomerChoice run store. An org maintainer (org role with xapi:my_organization:mfa:manage) whose user mode the administrator set to Required (PUT /api/mfa/modes/users/{id}) requested a code with organizationId and confirmed updateMfaOrganizationMode(enabled true). The mutation answered succeeded true with settings {isRequired true, requiredBy "Organization", organizationMode "Enabled", canChangeOrganizationMode true}; GET /api/mfa/modes/users/{id} still read Required. Just before, mfaSettings(storeId, organizationId) with the org Off reported requiredBy "User". So the organization-scoped result reports Organization as the requirer when both apply; it does not mean the user's own lock was lifted. Observed once; not asserted by any case.
