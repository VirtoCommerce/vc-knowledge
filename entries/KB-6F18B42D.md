As admin: .exe -> HTTP 200 [{succeeded:false, errorCode:'INVALID_EXTENSION', id:null}] listing the allowed extensions (.pdf .doc .docx .xls .xlsx .ppt .pptx .txt .csv .zip .png .jpg .jpeg .gif .webp). A 52,429,824-byte .pdf -> HTTP 200 [{succeeded:false, errorCode:'INVALID_SIZE', 'Maximum allowed file size: 52428800', id:null}]. A 0-byte .pdf -> HTTP 200 [{succeeded:true, size:0, id}]; registering that id via POST /api/sales-rep/documents -> 400 "File '<id>' is empty." A status-code-only check therefore cannot detect upload refusals; read succeeded/errorCode.
