A runner-native GraphQL case with no [AUTH] (anonymous) sent Query.categories(storeId=B2B-store, cultureName en-US / fr-FR) to vcptcore-qa: both responses were HTTP 200 with errors[] "Unauthorized" — "Anonymous access denied or access token has expired or is invalid." — and data.categories null. The same storefront redirects anonymous visitors to /sign-in. So catalog discovery on this store needs a buyer token; anonymous catalog rows fail by store configuration, not by a resolver defect. Admin-token queries in the same run resolved product/category slugs normally.
