On Pages 3.1011.0-pr-23 + XCMS 3.1009.0-pr-27 + PageBuilderModule 3.1036.0-pr-175, for a Multilanguage Page in B2B-store with en-US (default), fr-FR (custom permalink) and de-DE published: Query.slugInfo(permalink=<fr permalink>, cultureName=en-US) returns the en-US page document; (permalink=<en permalink>, cultureName=fr-FR) returns the fr-FR document; (fr permalink, de-DE) returns the de-DE one. pageDocument(id).cultureName matches the resolved version. pageDocument.alternates { id cultureName permalink } lists exactly the Published versions in store languages, one per language: a Draft pt-PT version and Archived versions are excluded (after Archive all, alternates is []); a version whose StartDate is in the future leaves alternates within ~3 s of the save, without republishing. Unknown slug → entityInfo null at HTTP 200.
