Firefox 1920, vc-frontend-next build. (1) Anonymous on /sign-in?returnUrl=/company/tasks → password sign-in as a sales rep: the browser issued a new document GET for /company/tasks (304) and booted again (second mf-manifest.json + remoteEntry.js fetch); the Tasks page and the Sales Rep hub rail/account-menu section rendered. (2) Logout from the account menu: another document GET of the current URL, then /sign-in?returnUrl=…, no hub section. (3) Two tabs as the rep, Logout in tab B: tab A reloaded by itself and landed on /sign-in?returnUrl=<its URL> within a second. (4) Sign-in in tab B: tab A (on /sign-in) reloaded to its returnUrl /company/tasks signed in. No UI path changed auth without a reload, so the boot-time 'authenticated' snapshot is always retaken.
