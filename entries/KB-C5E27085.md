Guest, 4 products in one compare tab, Firefox 151, viewport 1280 x (document height - 300) = 1280x1336, max scrollY 300. Wheel steps of 40px down advance 0,40,...,200; the next step snaps back to 164, then 204, 164, 204 indefinitely — the page never passes ~240, so the bottom 60px are unreachable by wheel. requestAnimationFrame keeps ticking (~31 per 500ms), so the page is not frozen; it is a scroll oscillation around the compact-header threshold. Same values reproduced on a local build of the compare-table restructure, so it is not introduced by that change.
