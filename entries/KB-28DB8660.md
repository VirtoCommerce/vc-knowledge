A fresh non-admin Manager (no contact, storeId B2B-store) with one global role carrying only platform:security:loginOnBehalf got a password-grant token with storeId=B2B-store, then POST /connect/token grant_type=impersonate user_id=<buyer> with that bearer returned 200; GET /api/platform/security/currentuser with the new token returned the buyer's userName. The buyer was a Customer in an organization the operator has no membership in. So a global loginOnBehalf permission is sufficient; no organization relation is checked.
