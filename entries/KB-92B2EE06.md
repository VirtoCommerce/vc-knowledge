The host's navigation resolver switches only on target.type (vue -> route, legacy -> {name:Legacy, query:{url}}, app -> EmbeddedApp); the item's `fallback` is read only by the Menu Editor's AngularJS-screens tab to decide which classic screens are already in the menu. Live: no menu item opens an AngularJS screen; typing /apps/admin-shell/#/legacy?url=/workspace/orders loads the classic Customer orders blade in the persistent iframe inside the shell, an opened order blade is still open after going to Home and pressing Back, and the rail does not highlight any section for it. The Menu Editor 'Find AngularJS screens' reported "37 screens, 2 not in the menu yet" (User profile, Webhooks — although a Vue Webhooks item exists).
