Signed in as two sales reps serving the same organization, opened /company/my-customers/{orgId}. For the rep with 7 orders in that org, SalesRepOrderFilterRules(organizationId) returned Cancelled, New, Payment required, Processing, and edit mode showed exactly those four status checkboxes, all checked. For the rep with no orders there (SalesRepOrders totalCount 0), the same query returned [], the widget showed 'No orders yet', and edit mode showed the Max rows input but no status checkboxes. So the tab set depends on the rep's orders for that organization, not on a fixed catalog. A test about status tabs needs the rep to have orders in the org first.
