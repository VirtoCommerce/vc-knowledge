On vcptcore_regression (2026-10-28), with an admin token, PUT /api/products/prices with [{productId, prices:[{pricelistId, productId, list: 0, currency: "USD", minQuantity: 1}]}] returned 400 {"[0].Prices[0].List":["List price must be greater than 0"]}; the same call with list > 0 returned 2xx. Price rows with list 0 that were saved on this stand earlier (2026-10-14) were still present, so the validation blocks new writes, not existing rows. A seeder that declares a $0 option product must not write its price row (or must use a positive price).
