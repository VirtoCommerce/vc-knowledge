Chromium 1920x1080, theme 2.63.0-pr-2617-a143, design classic, signed-in org member, /account/orders (My orders, 2 pages). After Tab from the Orders heading the page-number buttons ("2" on page 1; "1" on page 2) and Next/Previous receive :focus-visible = true with computed outline-style solid, outline-width 2px, outline-color rgb(27, 120, 155), outline-offset 2px, box-shadow none; contrast of that colour against the white pager background is about 4.99:1 (>= 3:1). The current page is a plain generic element in the accessibility tree (no button, never a Tab stop); with 2 pages no ellipsis is drawn. On page 1 Previous is disabled and is not a Tab stop (stops: "2", Next), on page 2 Next is disabled (stops: "1", Previous).
