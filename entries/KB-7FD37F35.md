On B2B-store a custom section type created with MCP create_section_type (theme draft, not published) was listed in the designer's Add section panel under a separate group 'Custom sections' with its en-US name, and the page preview frame (designer-preview) rendered it with its count-up numbers while the toolbar showed 'Publish theme (1)'. Changing the section's Heading setting in the right-hand settings panel updated the preview immediately ('Has unsaved changes'). The agent's publish_theme request appeared in Admin Shell Agent approvals as Pending with a field-by-field Now/After table (default/custom-sections/<type>.json draft -> published, name, schema settings); a second user's Approve + Confirm set it Applied and the type rendered on the storefront page with no storefront release. In the settings panel the list items of a list setting were titled by their first filled text field (the suffix '+' / '%'), not by the label field.
