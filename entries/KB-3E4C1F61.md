Signed in as a sales rep, loaded /it/company/my-customers/{orgId} directly. SalesRepOrders was sent with cultureName it-IT and returned ISO createdDate values plus formattedAmount "247,00 $". The My recent orders widget rendered the dates as "Oct 13, 2026" (English), while the money cells showed "247,00 $" and the Customer information card's Created on / Last web login dates showed 14/07/2026 and 09/10/2026. Status labels also stayed English because statusDisplayValue came back in English. In the plugin bundle the widget formats the date with the named vue-i18n datetime format $d(date, "short"), whereas the Customer information card uses $d(date) with no named format; the likely cause is that the named format is not defined for the active locale and vue-i18n falls back to the en format. The same widget code ships in SalesRep 3.1014.0's plugin bundle, so this is not new in 3.1015.0.
