Two-org B2B buyer, one non-active membership locked permanently via REST (isLocked=true, lockoutEnd null, server isCurrentlyLocked=true). At an exact 375x812 viewport, /account/dashboard > hamburger 'Main menu' > Corporate > My organizations lists both organizations as radios: the active one checked and enabled, the locked one disabled, greyed, with a padlock icon and title 'This organization is locked. Contact your administrator for access.'. A real tap on the locked row is refused (element not enabled): no POST /connect/token, no navigation, session and active organization unchanged. Same treatment at 640x450 and 320x225. Earlier builds (theme 2.58.0-pr-2469) rendered this row enabled and a tap signed the user out; on this build the mobile list carries the guard.
