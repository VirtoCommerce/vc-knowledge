Chrome 155, 1440x900, Time currently 9:00 AM. The input is role=combobox, readonly, aria-required=true, aria-haspopup=listbox, label 'Time*' and aria-label 'Time'; its list is teleported to body (id select-N-listbox, aria-label 'Time', 96 role=option items of 36 px, first '12:00 AM', last '11:45 PM', max-height 192 px so five rows show). Opening it (click, focus by Tab, or ArrowDown) leaves scrollTop at 0, so the selected 9:00 AM (option 36) is not in view; ArrowDown from the input puts focus on the FIRST option (12:00 AM), not the selected one, and each further ArrowDown moves one row, so 3:45 PM (option 63) needs 64 presses. End scrolls the list container to the bottom (scrollTop 3359) and Home back to 0, PageDown scrolls 168 px, but focus stays on option 0 and scrolls out of view; typing '3:45' does nothing. Enter on an option selects it, closes the list and returns focus to the input; Escape on an option or on the input closes only the list (the dialog stays open). The Priority select (5 options) uses the same component, so this is VcSelect's keyboard model made noticeable by 96 options.
