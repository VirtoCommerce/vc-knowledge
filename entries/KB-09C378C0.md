On Return 3.1005.0-pr-28-62f9 the Admin Return list shows an Organization column (blank for returns without an organization), sortable both ways, and its keyword also matches the customer name. POST /api/return/search accepts organizationId and excludeDrafts and then returns the same set, by id, as organizationReturns for a holder; without excludeDrafts drafts are included. At the default blade width the nine columns are about 100 px each and the headers truncate.
