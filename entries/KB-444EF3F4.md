Stable 16. Customer user locked from Admin Security > Users > Lock account (lockoutEnd 9999-12-31, GET users/{id}/locked = {locked:true}). POST /connect/token grant_type=password with the CORRECT password and storeId=B2B-store returned HTTP 400, error=invalid_grant, code=user_is_locked_out, errorDescription "Your account has been locked. Please contact support for assistance.", no access_token. The storefront sign-in page received the same 400 body and displayed "You have been blocked. You can not reach any information or create the order. For more details please contact the site administrator." Caveat: when the storefront resolves to a store the user is not bound to, the store check wins first and the answer is user_cannot_login_in_store ("Access denied. You cannot sign in to the current store") even for a locked user.
