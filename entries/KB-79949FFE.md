On the deployed storefront (theme 2.59.0-pr-2476, B2B-store) I opened a configurable product whose root section is a REQUIRED Text section with a dependent optional Product section (dependsOnSectionId → the Text section), and typed three spaces into the Text input. The dependent section appeared on the page, while the Text section itself was still treated as empty: it stayed marked required and Add to cart stayed disabled. So section visibility treats a whitespace-only value as a value, but the required-section gate does not. Reproduced identically on a newer theme build (vc-frontend PR #2527), where the configuration checklist also lists the revealed section as an optional row. A blank-trimmed value would keep the child hidden.
