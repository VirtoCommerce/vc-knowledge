Where a list's share link lives depends on whether the storefront has the list-sharing rework (vc-frontend #2476, vc-module-x-cart #141, vc-module-cart #194, vc-module-sales-rep #21; released 2026-10-06/07 as theme 2.59.0, XCart 3.1039.0, Cart 3.1012.0, SalesRep 3.1012.0).

Before the rework (observed live 2026-10-08 on theme 2.51.2): the list card's menu offers Edit and Delete only, and Edit opens the editable "List settings" dialog (List name, Description, Sharing options). The list detail page has a "List settings" button that opens the same dialog view-only. There is no Share button anywhere; the share URL ({FRONT_URL}/shared-list/<sharingSetting.id>) with an icon-only copy button appears inside List settings (and in New List) only when the scope is not Private.

From the rework (observed live 2026-10-08 on theme 2.59.0): the owner's card Actions menu offers Rename, Share and Remove list, and the detail page offers Rename and Share. Share opens a dedicated "Share <list>" dialog whose "Who can access" group holds the Link field with a Copy button as soon as a shared option is selected. A non-owner organization member sees only Rename on someone else's Organization list, on the card and on the detail page.
