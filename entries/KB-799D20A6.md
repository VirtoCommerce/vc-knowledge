The list Settings dialog is one shared component: opened from the list card's menu it is editable, opened from the button on the list detail page it is view-only with its fields disabled. There is no Share button on the list card or detail page; the share URL with its copy icon lives only inside the Settings dialog, shown when the list's sharing scope supports a link and the user is a corporate member.
