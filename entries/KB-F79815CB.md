2026-10-15 vcptcore_regression, theme 2.59.0, signed-in B2B buyer. A configurable parent (base 200) with one optional Variation-type section was added to the cart via xAPI addItem with variation Red/M (sale 45). /cart line shows price 245.00 (list 260.00) and Components list row '1. Color and Size:' with an EMPTY value cell and '+$45.00'. After placing the order, /account/orders/{id} Components list row also has an empty Value cell. The order (GET /api/order/customerOrders/{id}) holds configurationItems[{type:Variation, sectionName:'Color and Size', name:'<parent> Red / M', salePrice 45}]. On the PDP the Variation section radiogroup itself renders with no options (variations are only listed in the separate 'Product variations' block), so a buyer cannot pick a variation inside the configuration UI. Product-type items on the same pages show their option name.
