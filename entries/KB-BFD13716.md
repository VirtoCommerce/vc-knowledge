Return 3.1005.0-pr-28-fb4f, 2026-10-09, AGENT-TEST order of an organization buyer. PUT /api/return creating status New: submittedDate set at creation; a holder's organizationReturns lists it and return(id) reads it. Admin PUT of that return to Cancelled, or to the legacy spelling Canceled (accepted with 200 although available-statuses offers only Cancelled): submittedDate unchanged, still listed (as Cancelled / Canceled) and readable; statuses:[Cancelled] and statuses:[Canceled] both match the Canceled row. PUT /api/return creating a return already Canceled: submittedDate null, absent and return(id) null for the holder. PUT /api/return creating Requested: 400 "Status '' cannot be changed to 'Requested' by an edit." Buyer Draft: available-statuses [Draft]; PUT to New or Requested -> 400; stays private. Buyer draft cancelled before submit: available-statuses [Cancelled]; PUT to New or Requested -> 400; submitReturn and updateReturn -> WRONG_STATUS "only a draft can be changed"; stays private (submittedDate null). PUT /api/return without lines -> 400 "A return needs at least one line."; an empty storeId is filled from the order.
