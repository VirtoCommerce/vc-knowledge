Own store with StoreMode=Enabled: the right code on grant_type=mfa succeeded at 3, 5, 7 and 8.5 minutes after the code email was created (fresh account each). At 9:01 the right code answered invalid_code (not an expiry-specific code), and at 10:40 the right code answered invalid_two_factor_token (ticket expired). So the usable window is the code's TOTP window (~9 min), shorter than the 10-minute ticket, and an expired code is indistinguishable from a wrong one.
