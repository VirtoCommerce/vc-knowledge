A Product index Build on an Elasticsearch 8 stand completed and swapped but ended with the push notification "Indexation completed with errors" and 14 errors: Elasticsearch rejected individual documents on field-type conflicts (a property mapped integer receiving "L" / "27-inch", double receiving text, boolean receiving "True"), and four error rows had an empty message. Over the same window the backend App Insights resource held no exception, trace or failed-request row for them (the only failed dependency was an unrelated HEAD 404 index-exists check on a backup index). So per-document rejections are read from the build's notification errors[] (POST /api/platform/pushnotifications by id), not from telemetry; the build itself does not fail and the swap still happens.
