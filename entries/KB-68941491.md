A B2B-store customer account read passwordExpired=true (storefront sent it to change password). Admin POST /api/platform/security/users/{userName}/resetpassword {newPassword, forcePasswordChangeOnNextSignIn:false} answered succeeded; GET the user then read passwordExpired=false, and a /connect/token password grant (storeId=B2B-store) with the new password succeeded, with me.passwordExpired=false. So this endpoint is the way to clear the protected passwordExpired flag that PUT /api/platform/security/users keeps.
