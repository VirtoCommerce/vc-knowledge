On Return 3.1005.0-pr-28-62f9 with theme 2.60.0-pr-2523-9e4e, both the My returns list and the organization tab build the Filters > Status checkboxes from Query.returnStatuses, which answered Approved, Canceled (shown as Cancelled), Completed, New, Processing. Submitted returns display as Requested and drafts as Draft, neither of which is offered. Selecting New returned 'No returns match your search' while four Requested returns existed; pasting ?status=Requested into the URL listed them (the server filters by it). ?status=Draft on the organization tab listed nothing. The option list is the store's status dictionary, so it differs per environment.
