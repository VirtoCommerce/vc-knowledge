Punchout session on store B2B-store. The mutation is sent with storeId, cultureName and currencyCode only. The handler resolves the cart the same way Query.cart without a cart name does (the newest-created cart whose type is empty), which is the cart /cart displays: with default = 3 lines and a named cart created later through xAPI addItem with cartName, only the named cart was sent; with no default cart and only a named cart, the named cart was sent. A SavedForLater list or a wishlist created after the shopping cart is never sent, and a saved-for-later line is not in the cXML. Only selected lines are sent. A buyer with no cart at all gets errorCode CartNotFound, nothing is created, and the session stays Active. The cart is not cleared after a successful return, and carts belong to the user, not to the punchout session: a new punchout session for the same buyer opens the same cart with the lines already sent.
