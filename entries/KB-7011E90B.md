In the Admin SPA Companies and contacts blade, sorting by Modified Date ascending sends sort=modifiedDate:asc. Entering the keyword MemberType:Contact then sends POST /api/members/search with sort "" and the column header returns to no sort; later header clicks restart at asc then desc instead of continuing to desc. Observed on Customer 3.1029.1 / Platform 3.1076.13 in a stable-16 regression run (case CUST-172, screenshot evidence). Whether the earlier VCST-4884 fix is in this module version was not checked.
