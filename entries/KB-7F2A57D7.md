Clone on the Multilanguage Page blade (POST /api/page-builder-multilanguage-pages/{id}/clone) of a root with en-US, fr-FR (custom permalink), de-DE and pt-PT versions created a new root '<name> (copy)' with permalink '<p>-copy' and every version as Draft with copied content and '-copy' permalinks (the fr-FR custom permalink became '<fr>-copy', OverriddenFields kept). Cloning the same original again created a second root with the identical name and identical '-copy' permalinks in every language; POST /api/page-builder-pages/permalink-usage for that permalink in en-US then lists both roots' en-US versions. No warning, no error. Both are Drafts, so nothing collides on the storefront until both are published.
