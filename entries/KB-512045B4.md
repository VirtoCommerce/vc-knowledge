On ImageTools 3.1007.0-pr-130 (SkiaSharp build), an 80x40 PNG/JPEG run through FixedWidth 160 and FixedHeight 80 produced 80x40 thumbnails (no upscale: the resizer fits within (width, sourceHeight) / (sourceWidth, height)). FixedSize 160x80 produced 160x80 with the image scaled up, and FixedSize 120x120 produced a 120x120 canvas with the content scaled to 120x60. A sibling run on 3.1006.0 (ImageSharp) reported FixedWidth 160 on 80x40 -> 80x40 too, so this is unchanged behaviour. A checklist oracle "160 wide" for a small source is therefore wrong.
