On Loyalty 3.1009.0, GET /api/loyalty-mission-goal-items?missionId=<id> returned 405. POST /api/loyalty-mission-goal-items/search with {"missionId":"<id>","take":50} returned {totalCount, results[]}; each result has productCode, productName, missionId, productId, quantity. The Admin Goal SKUs sub-blade of a PerSku mission showed the same quantities as this search.
