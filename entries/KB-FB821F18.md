Storefront served by the Vite dev server (theme 2.60.0), hub from the SalesRep plugin 3.1015.0. After a cold load of /account (which redirected to /account/dashboard), a click on 'Dashboard' under 'Sales Rep hub' went to /company/dashboard. The first script requested was the host's /client-app/pages/company/index.vue, then the plugin's dashboard-*.js and its widget chunks from /modules/$(VirtoCommerce.SalesRep)/plugins/vc-frontend/assets/. The plugin's GetStorePlugins contributions declare every hub route with parent 'Company', and the host router lazy-imports @/pages/company/index.vue for that route (it renders AccountShell), so the host Company shell is a routing chunk that loads on the first /company/* navigation of a document. No host sales-rep page (client-app/modules/sales-rep/pages/*) was requested at any point. An assertion that every new script of the hub comes from the plugin folder must exempt this host Company route chunk as well as the federation runtime and the plugin-route placeholder.
