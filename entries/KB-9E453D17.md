Admin bearer token, platform 3.1085.0, Pricing 3.1009.0. GET /api/catalog/products/prices/search?pricelistIds=<id>&keyword=EXTRA&take=5 (with or without groupByProducts=true) returned 500 {"message":"Object reference not set to an instance of an object."}. The same request without keyword returned 200, and with productIds instead of keyword returned 200. The Admin price list Prices blade search box sends groupByProducts=true&keyword=EXTRA&pricelistIds=<id>&skip=0&sort=product.name:asc&take=20 and gets 200 with the filtered rows, so a real Admin user does not hit the 500; it is reachable only by a REST client that omits sort. Pass sort (e.g. product.name:asc) whenever keyword is set.
