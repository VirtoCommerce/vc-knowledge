The storefront order details page renders the shipping method name, logo, price and (for pickup) the pickup location, and never a tracking number or tracking link - the storefront has no tracking string at all. The data exists: trackingNumber and trackingUrl are in the xAPI schema and the platform stores them, so this is a storefront UI gap, not an API gap. Status chips are styled from the theme's orders_statuses list, which holds New, Processing, Pending, Cancelled, Completed, Payment required and Ready for pickup; a Shipped order still shows its word but with neutral default styling and no icon, so it is not a first-class storefront status.
