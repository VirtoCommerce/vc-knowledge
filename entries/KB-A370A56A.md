As a personal user on /cart, Select address > Add new with Country United States, State Texas, ZIP 'ABCDE' and phone '123' enables Create and is accepted: AddOrUpdateCartPayment returns 200 with postalCode ABCDE and phone 123, and the address becomes the cart billing address; with empty required fields Create stays disabled and no per-field inline errors render on blur. An address created this way inside the cart popup is not added to the saved address book (the popup still lists the original addresses). In the Select address popup the search box does not filter while typing or after clearing: results change only after pressing Enter or the magnifier (GetCurrentUserAddresses keyword variable); submitting an empty search restores the full list; a no-match search shows 'You do not have any addresses yet'. Facets Country/State/City show names with counts and are sent as countryCodes/regionIds/cities.
