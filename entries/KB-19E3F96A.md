In client-app/shared/catalog/components/category.vue, changeProductsPage() awaits fetchMoreProducts() and then calls analytics("viewItemList", products.value, categoryListProperties.value). useProducts.fetchMoreProducts() concatenates the new page onto products.value, so the event carries pages 1..N while item_list_id/item_list_name name page N. The identical call is present in vc-frontend 2.40.0, 2.50.0, 2.59.0 and 2.60.0 and in vc-frontend-next dev and PR #11 head d67b0e0a, so the behaviour predates the 2.60.0 merge. The dom-analytics engine (vc-frontend #2543) does not send this event: the category grid has no data-vc-track="product-list" container, which its viewItemList appear rule requires.
