On Return 3.1004.0, Query.returnableItems computes returnableQuantity as max(0, deliveredQuantity - held) independently of eligibility. A line delivered 40 days ago with a 30-day window reads isReturnable=false, ineligibilityReason=OUTSIDE_RETURN_WINDOW, deliveredQuantity=5 and returnableQuantity=5; an ORDER_STATUS_NOT_ALLOWED line likewise keeps returnableQuantity=5. Only a line with no delivery (NOT_DELIVERED) or a fully held line reads 0 because delivered is 0 or held equals delivered. Consumers must read isReturnable, never infer eligibility from returnableQuantity.
