Theme 2.60.0 with the SalesRep plugin built from vc-module-sales-rep PR #26 (unreleased), en-US, at 1920 and 1440 px. The widget shows a month calendar with a dot per due date and, for the selected day (today by default), '<date> N task(s)' and up to 5 rows from Query.salesRepTasks (first: 5, that day's local-midnight window): the task name (it carries a title tooltip), a status pill, and the same sub-line text as /company/tasks. The sub-line is a single truncated line in a rail about 350 px wide with no title tooltip, so 'Due Oct 23, 2026, 3:45 PM · Contoso Ltd. · Call' renders as 'Due Oct 23, 2026, 3:45 PM · Contos…' and an 11:45 PM call for Contoso Bank as '… · Conto…': the customer cannot be read in the widget, and two served customers sharing a prefix look the same, while the DOM text and the API response carry the full name (on /company/tasks the same line wraps and is readable). The PR states the widget shows a call's time and customer; truncation with an ellipsis is allowed by the storefront layout rules, so this is recorded as observed, without a defect marker.
