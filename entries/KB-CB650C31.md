2026-10-14, Catalog 3.1048.0 (platform 3.1076.1). Product owned by catalog Owner (no category) was linked via POST /api/catalog/listentrylinks into category MovingCat of catalog Src. Admin Cut on MovingCat, Paste into catalog Dst root. Afterwards GET /api/catalog/products/{linked} shows catalogId = Dst (was Owner), categoryId null; the Owner catalog lists 0 products; the product's link row still points at Src/MovingCat although MovingCat now lives in Dst. Owned descendants/products cascade correctly and an intra-catalog move leaves CatalogId unchanged. Source: CategoryMover.CascadeProductsAsync searches products by CategoryIds (which includes linked products) and rewrites every hit whose CatalogId differs from the target - no owned-only filter; same code in tag 3.1029.6.
