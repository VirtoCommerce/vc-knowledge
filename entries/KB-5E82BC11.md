Guest, desktop 1280, Edge. The /compare page-header "Clear all" button is a VcButton variant=outline color=primary; its text computes to rgb(249,158,36) (#f99e24) on #ffffff, 14px/700 = 2.11:1, below WCAG 1.4.3 AA 4.5:1 and below the 3:1 large-text bar. The value comes from --vc-button-outline-primary-text, which falls back to --color-primary-500 (#f99e24 in the shipped default/mercury presets). The same colour pair is measured on other surfaces: the catalog card "N variations" outline button (#f99e24 on white), and the inverse pair white on #f99e24 (2.11:1) on solid-primary buttons such as the empty-cart "Continue shopping" / "Add with bulk order", the compact compare header "Add to cart" and the header compare-count badge. Other outline variants use darker shades for text (outline secondary -600, outline warning -700), and outline badges/chips use primary-800 — the button outline-primary text token is the outlier.
