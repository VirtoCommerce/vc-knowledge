2026-10-05, theme 2.59.0-pr-2476-0abb, store B2B-store: GetPageContext returned store.settings.anonymousUsersAllowed=false. A fresh (signed-out) browser context opening /shared-list/<key> of a list whose scope was saved as Anyone with link was redirected client-side to /sign-in?returnUrl=/shared-list/<key>; no sharedWishlist query was sent. /catalog redirected the same way, so the redirect is store-wide and not list-specific. After signing in, an org member opened the same link normally. The Share dialog still offers 'Anyone with link' without any hint that anonymous visitors will be asked to sign in. On an earlier date the same stand let anonymous visitors open such links, so this store setting changes over time; check pageContext before reading an anonymous denial as a sharing defect.
