2026-10-06, x-cart 3.1038.0-pr-141-b404: a sales rep created a Customer-scoped list shared to two served orgs, then an admin deleted one org (DELETE /api/members, 204). Afterwards wishlist(listId), wishlists() and the response of a listName-only changeWishlist all return the deleted org's target with its id kept and name null, still in id-ascending order, with sharedWithId == targets[0]. A legacy changeWishlist scope Customer sharedWithId = the deleted org's id is a no-op (HTTP 200, no errors), and removeWishlist still succeeds.
