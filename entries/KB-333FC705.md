On B2B-store, opening a page in /apps/site-builder-shell and clicking Add section while the preview still shows 'Loading the site…' lists the shared components but 'No sections match' under Sections (reproduced by holding a storefront asset so the preview's loaded message is late). Once the preview has loaded, the same page lists 15 sections (Call to Action … Title) — identical for a plain landing page and for en-US, de-DE and fr-FR versions of a multilanguage page, with any page layout. The list is built from the schema catalog the preview posts, not from GET /api/site-builder/catalog (the designer only checks that hash 96e0af86 is stored, and uploads it if not). Database pages use the catalog's 'page' entry, which names no sections, so every section without targetTemplates is offered; product-info, related-products, product-reviews, recommended-products, category-listing and page-content are excluded by their targetTemplates. The empty state during loading reads like 'nothing matches' rather than 'still loading'.
