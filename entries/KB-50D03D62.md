Access follows the active organization of the token (the organization_id chosen at /connect/token), not any membership. A contact in AcmeCorp and TechFlow, for a list shared with TechFlow only, gets Access denied (Forbidden, errors[] at HTTP 200) from sharedWishlist(sharingKey) with an AcmeCorp-scoped token and access Read with a TechFlow-scoped token. A list shared with both orgs in one save notifies that contact once: one push and one SalesRepMessageEmailNotification for sendCustomerCommunication(organizationIds:[both]); the sending rep, a member of both, receives none. Observed on x-cart 3.1037.0-pr-141 / sales-rep 3.1012.0-pr-21.
