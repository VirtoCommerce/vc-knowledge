Read in vc-frontend (local checkout a6ee5ce, 2026-11-12; not verified equal to the deployed build): vc-header renders the logo through VcImage with src=logoUrl (whiteLabelingSettings.logoUrl ?? theme logo_image). On an img error VcImage switches to its fallbackSrc, which defaults to no-image.svg, so a broken org logo URL yields the generic no-image placeholder, no broken-image icon, and the theme's default logo or org-name text is never substituted. The Admin accepts any logo URL string (no URL validation in WhiteLabelingSettingValidator, which only checks the store/organization binding); the Vue ImageField takes a free-text URL. Not observed live (saving an invalid URL was out of scope).
