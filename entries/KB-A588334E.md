On Return 3.1005.0-pr-28 (platform 3.1079.0-alpha), as an administrator: More > Returns > Add new return > pick a Completed order > the Line items blade (create mode; toolbar Refresh + Make return; columns Item name, Return reason, Quantity, Price). Clicking the row's Item name cell, or the checkbox cell 3.5 px outside the box, only highlights the row (light blue): the checkbox stays empty and Make return stays disabled (3/3 attempts). Clicking the 13 x 13 px checkbox ticks the line and enables Make return; unticking disables it again. No request is sent by any of these clicks. This is the Admin SPA's general pattern, not specific to returns: the Orders module's Add item to order picker (shipment line items > Add item) and the shipment line items blade highlight on row click and select only via the checkbox (Add item / Remove stay disabled until a box is ticked), and ui-grid lists such as Customer orders open the record on row click while only the row-header checkbox enables Delete. The user guide's create-return steps say to check the items to return. The custom checkbox's native input is visibility-hidden, so the line checkbox does not appear in the accessibility tree.
