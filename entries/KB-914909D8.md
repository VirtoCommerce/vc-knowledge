On theme 2.60.0-pr-2523-466f (Firefox 151), opening 'Cancel return' on one's own Requested return at /account/returns/:id shows div[role=dialog][aria-modal=true] labelled by its h2 'Cancel return'. The textarea (maxlength 1000, placeholder 'Enter a value') has a visible label 'Reason (optional)' linked by label for = textarea id, so its accessible name is 'Reason (optional)' (getByRole textbox resolves exactly one) and it is focused on open. Real Tab presses cycle textarea, Keep return, Cancel return, Close (the X, last in the cycle) and back to the textarea; Shift+Tab from the textarea wraps to Close; all stops stay inside the dialog and show a 2 px #447d9c outline. Escape and the Keep return button both close the dialog without cancelling (status stays Requested) and focus returns to the Cancel return button that opened it. axe-core 4.12.1 with the dialog open: 0 violations, one incomplete aria-hidden-focus on the two headlessui focus-guard sentinel buttons. The textarea border is #d4d4d4 (neutral-300) on white, about 1.48:1.
