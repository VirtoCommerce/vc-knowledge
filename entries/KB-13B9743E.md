Theme 3.1.0-pr-11-d67b-d67b0e0a, B2B org admin, a Draft quote created with 'Add cart items to quote'. On the AGENT-TEST-Low-Stock-Fixture line (stock 5), quantities 6 and 999999999 (the field truncates to 999999) showed no message under the line, and Increase stayed enabled. The same product's /cart line shows 'You can order maximum 5 item(s)'. Quantity 0 showed 'Value must be a positive number'. The Files field reads 'CSV, DOCX, JPG, PDF, PNG, TXT, XLSX ... should not exceed 10MB. Maximum 5 files allowed.', matching GetFileUploadOptions(scope quote-attachments) = maxFileSize 10485760 and those 7 extensions. An 11 MB .txt was listed with 'File size exceeds the allowed 10MB (11MB)', a .zip with 'File format is not allowed (21B)', and a 6-file selection with 'You tried to upload more than maximum number of files allowed.', attaching none of them. No POST /api/files request was sent for any of the three, so the rejection is client-side.
