Signed-in buyer, store B2B-store (default en-US), Firefox. After switching the language selector to Deutsch on another page, a direct navigation to /soft-drinks/softdrinks/coca-cola-regular-6x330ml (product 8b7282ad, de-DE slug de-cola) ended at /de/soft-drinks/softdrinks/coca-cola-regular-6x330ml with the 404 view ('404 Seite nicht gefunden'). The same /de/<en slug> URL reached through the language selector itself (from the English PDP) does resolve and moves on to /de/soft-drinks/softdrinks/de-cola, so the selector path carries state that a direct load does not. Effect: an English product link (shared, emailed, bookmarked) is a 404 for a user whose session language is German.
