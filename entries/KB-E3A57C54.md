On vcst_qa 2026-11-27 (platform 3.1101.0) the White labeling blade opened from Stores > B2B-store (the White labeling widget) shows a toolbar with only Save, and the one opened from Contacts > organization three-dots menu > Manage > White labeling widget also shows only Save (the organization blade behind it has Save and Reset for the whole contact, not for white labeling). Fields in both: Enabled toggle, Logo and Favicon widgets, Theme preset name picker, Main menu link list, Footer link list. No Reset to defaults and no Clear action exists, so a case that clicks them cannot run; clearing is done by emptying each field and saving. The Admin dashboard (Home) has no White Labeling tile either.
