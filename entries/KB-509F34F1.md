On vcptcore_qa1 a buyer whose last switched org was A signed in by code typing the email lowercase: POST /connect/token grant_type=otp_email carried organization_id=A. After setting CurrentOrganizationId to B and signing in typing the email with capitals, the request carried no organization_id and the header showed B. The storefront reads localStorage key organization-id-<typed email> verbatim. After a fallback to B and a reload, the next lowercase code sign-in still sent A, and once A was unlocked the buyer landed in A.
