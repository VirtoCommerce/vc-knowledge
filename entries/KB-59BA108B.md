Created an order via POST /api/order/customerOrders with isPrototype=true; GET by id reads back isPrototype=true. POST /api/order/customerOrders/search {keyword:<number>} returned 0 hits for it; the same search with withPrototypes=true returned it. A teardown that finds orders by search without that flag leaves prototype orders behind, and an idempotent seeder recreates them.
