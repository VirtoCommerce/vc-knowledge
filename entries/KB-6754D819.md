Without a token: GET /api/site-builder/git/site, /git/connection, /git/app/setup, /history, /history/status, /designer/storefront, /settings, /search, POST /save and /theme/publish -> 401. GET /api/site-builder/git/app/new and /git/app/created (with or without code/state, also with a script tag in state) -> 400 text/plain "GitHub setup did not finish: This setup link has expired or is not valid. Start the setup again from the site." (the input is not echoed). GET /git/app/installed with an invalid or missing state -> 302 Location "/", also when a returnUrl to another host is added. Routes /api/site-builder/templates, /sections, /git-content/* -> 404.
