A configurable product File section uses a platform-fixed accept list rather than a per-section one: DOC, RTF, DOCX, TXT, PDF, XLS, XLSX, JPG, PNG and ODT, up to 9.5 MB per file and 5 files. An unlisted type (for example .exe, .svg or no extension) is rejected with 'File format is not allowed' and 'Fix file upload errors to continue', and Add to cart stays disabled. In the cart and order the chosen values show under each line's Components list as Section: Value, and the Admin order line item's Configuration widget lists them as configuration texts and configuration files (name, type and size).
