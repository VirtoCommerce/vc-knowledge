A configurable product File section uses a platform-fixed accept list rather than a per-section one: DOC, RTF, DOCX, TXT, PDF, XLS, XLSX, JPG, PNG and ODT, up to 9.5 MB per file and 5 files. An unlisted type (for example .exe, .svg or no extension) is rejected with 'File format is not allowed' and 'Fix file upload errors to continue', and Add to cart stays disabled. In the cart and order the chosen values show under each line's Components list as Section: Value, and the Admin order line item's Configuration widget lists them as configuration texts and configuration files (name, type and size). Those limits are the product-configuration FileUpload scope of the stand, not platform-fixed: Query.fileUploadOptions(scope:"product-configuration") returned maxFileSize 10000000 and exactly that extension list on vcptcore on 2026-10-13. Where the scope is not configured the query returns null (vcst, 2026-10-13, anonymous and admin, 2 runs) and the storefront keeps its built-in fallback (vc-frontend useFiles.ts: maxFileSize 1 MB, maxFileCount 5, allowedExtensions empty; option-file.vue scope product-configuration), so the hint reads 'Each file should not exceed 1MB. Maximum 5 files allowed.' and no client-side type check applies at all. The 5-file count always comes from the storefront default.
