Read in vc-frontend client-app/shared/account/components/add-or-update-address-modal.vue (tag 2.63.0, HEAD a6ee5ce36): the submit button is bound `:disabled="!dirty || !valid"` from AddressForm's append slot, with required-email and required-city set. So with the dialog empty (not dirty) or any required value missing or invalid, Create cannot be clicked; a case that clicks Create on an empty form to provoke per-field errors has nothing to click. The same modal is used by /account/addresses and by the /cart shipping-address selector. Not observed live by this session; a regression probe of the same dialog (REG-2026-11-19-1857, CHK-026 notes) saw Create disabled with all fields empty and an inline error only for an invalid Email value.
