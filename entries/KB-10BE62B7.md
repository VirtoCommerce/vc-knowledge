Anonymous xAPI calls only (no token), store B2B-store, USD, en-US, a fresh random userId. Query.cart for a userId with no cart returns null (it does not create one); Mutation.clearCart creates it (isAnonymous=true, 0 items, no addresses). That EMPTY cart already returns availableShippingMethods = BuyOnlinePickupInStore/Pickup ($0.00), FixedRate/Ground ($150.00), FixedRate/Air ($250.00), all priority 0, and availablePaymentMethods = AuthorizeNetPaymentMethod (PreparedForm, priority 1), CyberSourcePaymentMethod (Standard, 0), DatatransPaymentMethod (Standard, 0), DefaultManualPaymentMethod (name "Test payment method", Unknown, 1), LoyaltyPaymentMethod (Unknown, 0), SkyflowPaymentMethod (PreparedForm, 0) — the same six a signed-in buyer gets. After addItemsCart (one physical product) and then addOrUpdateCartAddress (US/NY shipping address) both lists and the shipping prices were identical, so on this stand neither an item nor an address is needed and neither filters the lists; FixedRate is a flat rate, not weight/country-based. In availableShippingMethods, priceWithTax reads $0.00 for every option even where price is $150/$250; after addOrUpdateCartShipment with FixedRate/Ground the cart's shipment priceWithTax is $180.00 (20% tax), so priceWithTax on the available-methods list is not the taxed price and should not be asserted. addOrUpdateCartShipment without cartId/price returned a VALIDATION error; with cartId, price and deliveryAddress it succeeded. Cart removed afterwards with removeCart.
