The B2B store's FilteredBrowsing JSON had four attributes with "Values": null. After any Save in Admin Store > Search configuration > Facets, those four came back as "Values": [] (the string got 8 characters shorter). Facets, xAPI and storefront output were unchanged. So a UI round-trip is functionally identical but not byte-identical. A byte-exact restore needs the original string written back through a full-store GET-then-PUT /api/stores.
