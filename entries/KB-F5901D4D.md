On /company/dashboard (theme 2.59.0 PR build 2536) the dashboard issues SalesRepCustomerCartStatistics with cartFilter 'active-carts', the store currency, and weekFrom/weekTo bounding the current calendar week (Sunday start in the browser's local zone). The response carries activeCarts {selectedItemQuantity, unselectedItemQuantity} and itemsThisWeek {selectedItemQuantity}; the Active carts tile renders them as '<n> items', '<n> not for checkout' and '<n> items this week' (absolute quantities, not a percentage). Observed with all three at 0 for a rep whose served organizations had no active carts.
