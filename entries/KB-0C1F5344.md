On vcptcore_regression (Platform 3.1076.13, Customer 3.1029.1), admin bearer. Revoke on an Invited membership -> 200 {succeeded:true,errors:[]}; the row stays and its status becomes Deleted (a full-row PUT with status Invited restores it). Resend on an Invited membership -> 200 succeeded:true, status stays Invited, journal shows OrganizationInviteExistingUserEmailNotification for a seeded (password-holding) invitee; a urlSuffix/message sent in the request body is not used, and the email link is FRONT_URL/account/dashboard. Resend or revoke on a Rejected or Deleted membership, or an unknown id -> HTTP 200 succeeded:false with one error {code:InviteNotFound, description:"Pending invite not found", parameter:<the id>}, status unchanged. A storefront buyer token (org-maintainer, no customer:invite) -> 403 on both. POST /api/customer/organization-memberships/search without userId/userIds/organizationId/organizationIds -> 400 "At least one scoping filter ... is required."
