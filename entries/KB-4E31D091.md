A Sales Representative serving two organizations created a call with createSalesRepTask(customerId = organization X); salesRepTask and salesRepTasks returned customerId X and its name, and /company/tasks (All) showed the row line "Due <date>, <time> · <X name> · Call". The admin then sent PUT /api/sales-rep without X in organizations[] (GET /api/sales-rep/{id} then listed one organization). With a freshly minted rep token, salesRepCustomers returned only the remaining organization, and salesRepTask / salesRepTasks returned the call with customerId null and customerName null; the storefront SalesRepTasks response carried the same nulls and the row read "Due <date>, <time> · Customer not assigned · Call". The admin GET /api/task-management/{id} still showed objectType "SalesRepCustomer" and objectId X with an unchanged modifiedDate: the link is kept, only hidden on read. After a PUT /api/sales-rep that added X back (a new membershipId was issued), salesRepTask and salesRepTasks returned customerId X and its name again, and the storefront row named X again.
