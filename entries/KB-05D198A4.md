Admin as administrator, Edge. Opening user menu > Manage profile (#!/workspace/userProfile) issued GET /api/platform/profiles/currentuser (RegionalFormat 'en', Language 'en'), GET /api/platform/localization/locales (15 locales) and GET /api/platform/localization/regionalformats, which returned 200 with an empty array []. Every open (5 of 5) logged 'TypeError: Cannot read properties of undefined (reading 'name')' from platform dist/app.js inside a $digest, followed by 'Possibly unhandled rejection: {}'. The Regional format select rendered empty. In 3 of 5 opens the blade stayed in its loading state (striped header bar, greyed form) and the blade wrapper intercepted every click, so Language could not be changed until the blade was closed and reopened. A REST read with an admin token also returned [] for regionalformats.
