With an authenticated admin session, GET /api/members/search?memberType=Contact&take=10 returned HTTP 200 with content-length 0 (no JSON). The Admin Customers blade itself searches with POST /api/members/search {keyword, deepSearch:true, skip, take, objectType:'Member'} which returns {totalCount, results}. A GET-based cross-layer check on this path therefore can never see results.
