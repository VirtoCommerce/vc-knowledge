On theme 2.60.0-pr-2523-9e4e with Return 3.1005.0-pr-28-62f9, opening /account/returns?scope=organization&page=-1 sent GetOrganizationReturns with after "-20"; the response was errors[0].extensions.code SQL ("Error trying to resolve field 'organizationReturns'") with data null. The page showed the toast 'Something went wrong. Please try again later.' and the empty state 'There are no returns yet'. The own list (/account/returns?page=-1) behaves the same. A page past the end (page=5 with 11 rows) is clamped to the last page, and an unknown sort value is ignored.
