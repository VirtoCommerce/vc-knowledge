On /graphql/sales-rep, a product whose catalog record has imgSrc and 4 images, and whose newest order line (a cart-placed order) had an imageUrl, appeared in salesRepTopSellers with that image. Then a newer order for the same product and organization was created via REST POST /api/order/customerOrders with a line that had imageUrl null and a custom name. After the statistics cache expired (about 60 s), all 6 cookie-less reads across both replicas returned units incremented by 1, imageUrl null and name equal to the REST line's name. So the row's display fields come from the newest line with no fallback to older lines or to the catalog image. This is tracked as bug VCST-6154.
