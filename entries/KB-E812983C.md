Build platform PR #3182 + AdminAngularJs PR #7 (AngularJS admin, not Admin Shell). #!/workspace/security > Users > user without a key > 'API key' widget opens a blade: 'is active' switch, 'API key' input with placeholder 'Generated on save' (readonly attribute; clicking it and typing changes nothing), note 'The key is generated when you save.'. OK sent POST /api/platform/security/users/apikeys {userId,userName,isActive:true} (no apiKey); the response carried the full vc_ key once; the blade then showed label 'New API key', the value in a read-only input with a copy icon (title 'Copy', no visible text; no toast observed), and the warning 'Copy the key now. It is not stored and will not be shown again.'. The copied value authenticated as the owner. Pressing OK on that blade sent a second POST users/apikeys carrying apiKey = hint and the key id; the server kept the key (no second row, same key still works). Reopening the widget shows only the 4…4 hint. Toggling 'is active' off + OK sends POST with the hint and isActive:false → key 401 on GET /api/platform/modules; on + OK → the same key works again. Legacy keys of other users open showing their 4…4 hint; Cancel sends nothing.
