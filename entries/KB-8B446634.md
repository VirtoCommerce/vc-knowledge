On the Image carousel section (theme schema images control, multiple:true), clicking tiles in 'Choose from asset library' toggles them. Each selected tile shows a check icon, which is aria-hidden, and the footer button reads 'Select (N)' once 2 or more are picked. Space and Enter on a focused tile both toggle it. The pending selection survives navigating to another folder and creating a folder with New folder (the picker enters the new folder and the count is unchanged). Files uploaded while a selection is pending join it, appended after the existing picks. Select applies the whole set in click order; a double-click on Select applies it once. Cancel, the close (X) button and Esc leave the control unchanged. Save writes content[].images as an array of absolute asset URL strings in click order. Re-opening the picker starts with nothing selected; Select then APPENDS the new picks to the existing list, and the same asset can appear twice. Single-value image controls (multiple:false) stay single: no check icons, the second click replaces the first, and the value is saved as a scalar string.
