On the storefront /graphql, signed in as a personal customer (Bearer token), Query.cart(storeId B2B-store, userId = a random guest GUID that owns an AGENT-TEST named cart, cartName, currency, culture) returned HTTP 200 with data.cart null and errors[0] {message "Access denied.", extensions.code "Forbidden"}. The same query sent anonymously (no Authorization, credentials omitted) returned data.cart null with no error after the guest cart had been merged and deleted. Query.cart by cartId of that deleted guest cart, sent signed in, returned null with no error. So a test that verifies a guest's named cart by name must send that read anonymously; signed in, the error does not mean the cart exists.
