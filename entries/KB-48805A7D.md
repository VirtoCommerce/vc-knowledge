On B2B-store (which already has a live announcement bar), edit_theme_draft part=header added an announcement-bar (background color_primary_500) plus an announcement block with text; the draft listed it. Moved before the live bar and set home_only=false, then reloaded the designer on an existing page: the preview frame showed only the live 'Spring sale' bar (neutral_900); the new bar's text was absent from the preview accessibility tree. So the colour of a newly added bar cannot be read in the preview on this stand.
