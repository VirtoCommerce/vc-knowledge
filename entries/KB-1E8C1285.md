Measured live in the vc-frontend dev Storybook (built from dev 9277b0eec; the UI-kit files involved are identical to theme 2.60.0 at 80e49d1e4), Edge 155, light mode, preset chosen with the Storybook URL global themePreset (no store setting). Red (live --color-primary-500 #e52121): VcCheckbox 2.52:1, VcInput 2.52:1. Control: VcRadioButton basic under Coffee is 2px #737373 (neutral-500) = 4.74:1, changed from neutral-400 by VCST-4703. neutral-400 is #a3a3a3 and neutral-300 #d4d4d4 in default, coffee, red and mercury, and lighter still in black-gold, purple-pink and watermelon, so no light preset reaches 3:1. axe-core 4.12.0 (as loaded in the Storybook page) has no rule tagged wcag1411 (its only contrast rules are color-contrast for 1.4.3 and color-contrast-enhanced for 1.4.6), and an axe run with the WCAG 2.x A/AA tags on the Coffee VcCheckbox story returned 0 violations and 0 incomplete. An axe-only gate therefore passes these boundaries.
