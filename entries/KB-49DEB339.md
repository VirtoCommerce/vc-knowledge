Signed in as a corporate storefront user on the quote edit page, the Select address modal (server-paginated, 6 per page) was opened at 375px width. The accessibility snapshot showed one overlay button per address row (6 on page 1) with no accessible name, and a pointer click on the row text was intercepted by that overlay. At 1280px the same modal is a table with a labelled "Select" button per row. Separately, when the last page held fewer rows than page 1, the pager moved up (about 158px in the quote modal at 1280px, with the modal re-centring) and in the header Ship to popover by about 284px. Values were read from screenshots, not rect measurements. Whether the overlay buttons predate theme 2.62.0-pr-2424 was not checked.
