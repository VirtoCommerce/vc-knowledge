On Stable 16 (theme 2.59.0) /account/profile renders First name, Last name editable and Email as a disabled textbox. The vc-frontend source client-app/pages/account/profile.vue hardcodes `disabled` on the email VcInput at tags 2.35.0, 2.51.2 and 2.59.0, so this is by design, not configuration. The Storefront User Guide account/profile page still says the user can edit name, last name and email, so the doc is out of date. Test cases that change email via the profile page cannot be executed.
