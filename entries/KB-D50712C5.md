A personal user with exactly one saved address (shown pre-selected as the cart shipping address) opened the cart change-address button, which showed an 'Edit address' dialog; saving new name/street there replaced the saved address: /account/addresses afterwards listed only the edited one. Once the user has a saved address, the button opens a 'Select address' dialog with 'Add new' instead; an address created through 'Add new' from there did not appear in /account/addresses afterwards (cart-only). Checkout flows that edit the cart address therefore leave the saved address changed.
