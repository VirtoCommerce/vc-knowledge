On theme 2.59 pr-2500 at 375 and 768 wide, with 70-71 unread push messages, the header bell badge shows '7' above '1' (or '7'/'0') inside an enlarged circle overlapping the bell icon. The accessibility tree names the button '71' (desktop header names it 'Notifications'). Tapping it opens the Notifications popup listing return events ('Return RET... received/approved/partly approved/declined'); tapping an entry marks it read but does not navigate.
