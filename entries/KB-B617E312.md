client-app/app-runner.ts: permalink = getPermalink(globalThis.location.pathname) (raw, still percent-encoded) is sent to GetPageContext and used as the key for seedSlugInfoCache (apolloClient.writeQuery GetSlugInfoDocument). client-app/pages/matcher/slug-content.vue: seoUrl = props.pathMatch.filter(Boolean).join('/') from route '/:pathMatch(.*)*' (router/routes/main.ts), which vue-router has already decoded; useSlugInfo(seoUrl) queries GetSlugInfo with it. The two keys differ whenever the path holds an escape, so the seeded result is never used and the decoded lookup decides. Same code on tags 2.40.0, 2.50.0, 2.55.0, 2.60.0.
