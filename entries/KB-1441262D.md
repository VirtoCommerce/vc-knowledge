On Return 3.1005.0-pr-28-fb4f, returns(storeId, scope: ORGANIZATION) and scope: "Organization" both fail validation with "Unknown argument 'scope' on field 'returns' of type 'Query'." (code KNOWN_ARGUMENT_NAMES, data null). Introspection lists returns(after, first, keyword, sort, storeId, statuses, startDate, endDate) and a separate organizationReturns with the same arguments plus organizationId; there is no ReturnScope type. The organization view is organizationReturns(storeId, organizationId), which answered rows for a holder of xapi:my_organization:return:view and Forbidden for everyone else.
