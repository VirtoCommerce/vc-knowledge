Observed on Return module 3.1003 (PR build). GET /api/return/{id}/available-statuses returned: New -> [New, Completed, Canceled, Processing, Cancelled]; Requested -> [Requested]; Draft -> [Draft]; Approved -> [Approved, Completed, Processing]; PartiallyApproved -> [Completed, Processing, PartiallyApproved]; Rejected -> [Rejected]; Cancelled -> [Canceled, Cancelled]; a legacy Completed return without decided lines -> [New, Completed, Canceled, Processing, Cancelled]. The admin status dropdown shows the same list. On a cancelled return the Status dropdown and the Returns 'All statuses' filter show both values, and in translation they are indistinguishable (de Storniert twice, ru Отменён twice). Saving Completed -> New and New -> Completed in the admin UI both persisted.
