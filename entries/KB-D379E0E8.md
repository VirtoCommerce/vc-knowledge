With an admin token, GET api/product-subscription/customers/{customerId}/saved-payment-methods for a storefront customer returned the customer's saved cards with storeId, customerId, organizationId, paymentMethodCode, brand, last4, expiry, cardholderName, fingerprint, networkTransactionId, initialTransactionRef and also the provider token and providerCustomerRef. The path parameter is the user (account) id: the same call with the customer's contact (member) id returned []. The payment module PR states token and provider customer reference must be kept out of storefront and public API responses; the storefront xAPI SavedPaymentMethod type does not expose them, but this admin REST endpoint does.
