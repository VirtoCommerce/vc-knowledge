Admin SPA 3.1076.0 Return list columns: Return number, Order number, Customer, Organization, Return status, Create date, Modify date, Created by, Item count. Sortable (send POST /api/return/search sort=): number, organizationName (empties first on asc), status, createdDate, modifiedDate, createdBy; Order number, Customer and Item count send no request. Header clicks cycle asc -> desc -> none (sort ""). At 1920x1080 the 'Item count' header renders 'Item cou' under the grid-options button. Organization cell is empty for a return whose order has no organization (REST organizationId null). The nine visible columns and the clipping hold up to Return 3.1005.0-pr-28-62f9 (unreleased PR VirtoCommerce/vc-module-return#28; released 3.1004.0 has eight columns, no Organization). Commit 9bcdf23a (2026-10-08, return-list.tpl.html columnDefs) hid Modify date and Created by by default and gave every column a minWidth: on Return 3.1005.0-pr-28-fb4f (platform 3.1078.0, vcst, 2026-10-12, fresh context) the list opens with seven columns, every header is whole at 1920x1080 and 1366x768 in the fixed 940 px blade, and with all nine switched on the grid scrolls horizontally and the grid-options button covers the Created by header at scrollLeft 0, not Item count. Sorting, the asc -> desc -> none cycle (sort ""), organizationName empties first on asc, and the blank Organization cell are unchanged on that build.
