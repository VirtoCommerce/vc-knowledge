Admin SPA 3.1076.0 Return list columns: Return number, Order number, Customer, Organization, Return status, Create date, Modify date, Created by, Item count. Sortable (send POST /api/return/search sort=): number, organizationName (empties first on asc), status, createdDate, modifiedDate, createdBy; Order number, Customer and Item count send no request. Header clicks cycle asc -> desc -> none (sort ""). At 1920x1080 the 'Item count' header renders 'Item cou' under the grid-options button. Organization cell is empty for a return whose order has no organization (REST organizationId null).
