Theme 2.59.0-pr-2519, desktop split layout, sales rep signed in. Filters drawer -> Tab to 'Open calendar: Start date' -> Enter opens calendar with focus on today; ArrowRight/ArrowDown move, Enter selects, the calendar closes and focus lands on the Start date input (combobox), not on the button that opened it; same for End date. Footer Clear via keyboard empties only the open field, keeps the calendar open, sends no request. Escape closes the calendar (focus to input), second Escape closes the drawer (focus to Filters button). Tab to the chip-row 'Reset filters' button and Enter: one SalesRepCustomerOrders request with filter "" is sent, chips disappear, and no element matches :focus afterwards (focus fell to the document body). Apply via keyboard returns focus to the Filters button.
