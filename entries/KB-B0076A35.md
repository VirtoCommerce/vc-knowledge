As administrator over REST, POST /api/assets/folder {name:'empty', parentUrl:'/stores/B2B-store/Page Builder/<fixture>'} succeeded; an immediate GET /api/assets?folderUrl=<that folder> returned exactly one child: name '.keep', type 'blob', size 0, contentType application/octet-stream. POST /api/page-builder-assets/search on the same folderUrl returned totalCount 1, fileCount 1 — the placeholder is counted as a file. So on a blob-storage backend an "empty folder" fixture is never empty through either API; a test expecting zero children/empty-state must either tolerate the .keep entry or the UI must filter it (not checked here).
