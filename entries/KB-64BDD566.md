On vcptcore_dev, slugInfo(permalink:"seed-books", storeId:"B2B-store", cultureName:"en-US") returned byte-identical entityInfo (id, objectId, objectType Category, semanticUrl, storeId, pageTitle, outline) for an anonymous caller, a personal account, an organization account and an administrator. Requesting cultureName de-DE or fr-FR for the same permalink returned the en-US record (entityInfo.languageCode en-US), because the category has only an en-US SEO record and the Catalog resolver accepts the store default language. Source agrees: CatalogSeoResolver filters by store, language and active state only (the catalog SEO table has no OrganizationId column; the criteria's UserId and OrganizationId are ignored by it). The language column on a catalog SEO record is limited to 5 characters.
