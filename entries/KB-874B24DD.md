The xAPI quotes query searches QuoteRequests with CustomerId = the signed-in ApplicationUser id (the login id, NOT the contact/member id) AND OrganizationId = the token's current organization (organization_id claim). A quote whose organizationId is null, or whose customerId is another login, is not listed for the buyer; opening it by id passes QuoteAuthorizationHandler only if quote.CustomerId equals the login id or the user has xapi:my_organization:edit and belongs to quote.OrganizationId. Observed on vcst: two API-seeded quotes with organizationId null were absent from the buyer's list; re-created with customerId = login id and organizationId = the buyer's org, both were listed. Source: vc-module-quote ExperienceApi QuotesQueryHandler.GetSearchCriteria + QuoteAuthorizationHandler (dev).
