On the QA Storybook built from vc-frontend PR #2568 @ 3f8af63a, opening story components-organisms-vcstatwidget--basic with URL args color:purple;deltaColor:purple logged the console warning "Received illegal value for 'color'. Supported options: …" and the story kept its defaults (info / success). The Controls panel offers only the 8 MAIN_COLORS options (primary, secondary, neutral, accent, info, success, warning, danger). So the component's unknown-colour fallback cannot be exercised through Storybook args or Controls; it needs a direct mount or a class-level stand-in. Source reading (method source, same commit): an unknown value yields an unstyled vc-stat-widget--color--<value> modifier and keeps the base neutral-500 / neutral-700 vars, the same path as neutral.
