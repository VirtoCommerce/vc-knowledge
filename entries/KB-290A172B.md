On a Completed order blade in the Admin SPA (Orders module), clicking the toolbar command 'Get invoice PDF' sends no XHR from the blade; it opens a new browser tab at GET /api/order/customerOrders/invoice/{orderNumber}. The tab stays blank until the response arrives, then the browser PDF viewer shows 'Invoice Details <number>' with line items, totals and status. The response was 200, Content-Type application/pdf, Content-Length 21921, with no Content-Disposition header, so the browser renders it inline rather than downloading a .pdf file. The origin took ~61 s for the first request (x-response-time 60.885); two further requests for the same order issued while it ran each took ~120 s, i.e. concurrent invoice generations queued. The order blade itself is not navigated away from.
