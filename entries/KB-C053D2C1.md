2026-11-26: a token-less POST to the backend /graphql with query store(storeId: "B2B-store", cultureName: "en-US") { storeId defaultLanguage { cultureName } availableLanguages { cultureName } defaultCurrency { code } availableCurrencies { code } } returned data without errors. defaultLanguage.cultureName = en-US; availableLanguages (15, in response order) = pl-PL, sv-SE, no-NO, de-DE, fr-FR, it-IT, en-GB, zh-CN, pt-PT, ja-JP, el-GR, fi-FI, en-US, ru-RU, es-ES; defaultCurrency.code = USD; availableCurrencies (9, in response order) = USD, AUD, CNY, CZK, EUR, GBP, GHS, PTS, XPT. The store query itself is answered anonymously (no Unauthorized error), so it can be used without sign-in to read store currency/language settings. The list order is not alphabetical and should not be asserted.
