The storefront xAPI mutation removeWishlist(command: InputRemoveWishlistType!) returns a Boolean scalar. A query that adds a sub-selection such as removeWishlist(command:$c){ id } is rejected at validation with SCALAR_LEAFS ('Field removeWishlist of type Boolean must not have a sub selection') and nothing is removed; call it without a selection set.
