On vcptcore_regression (Platform 3.1076.13, Customer 3.1029.1, ProfileExperienceApiModule 3.1020.0) the contact ORG_USER has no global security roles and one Approved organization membership whose role is org-maintainer (POST /api/customer/organization-memberships/search). GET /api/platform/security/roles/Organization%20maintainer returns 11 permissions including xapi:my_organization:edit, xapi:my_organization:user:invite and xapi:my_organization:order:view. Yet POST /connect/token (password grant, storeId=B2B-store) returns a token for that organization whose permission claim holds only storefront:organization:view and storefront:user:view. Consequences seen in the same run: xAPI changeOrganizationContactRole / lockOrganizationContact answer Forbidden "User doesn't have the required permission 'xapi:my_organization:edit'", and /company/members shows no Invite members button or row actions. The store setting Customer.MembershipRolesWhitelist on B2B-store and the platform setting are null; the same null is present on stands running Customer 3.1032-3.1033, where it was not established whether maintainer tokens carry the role. Cause not established.
