Deployed storefront 2.59.0 (before the Tasks redesign), sales rep, Edge 1920, self-created task due today. Shift+Tab to the row checkbox ('Mark "<task>" as completed') and Space: the task completes, the list refetches and document.activeElement is BODY. A mouse click on the checkbox to reopen it gives BODY too. Edit task opened from the title, Save via keyboard: BODY. Delete then OK in the 'Delete task' confirmation: BODY. In source the task table renders a skeleton tbody while loading, and the row controls are disabled while the write runs, so the focused control is unmounted.
