Theme 2.59.0-pr-2536 against SalesRep 3.1012.0. A dateless open task (dueDate null) is shown under All with an Upcoming chip and a Mark as complete action, and it is absent from every dated tab. Mark as complete sends Mutation.changeSalesRepTaskStatus {completed:true}. The Completed badge goes 4 to 5 and the Completed tab lists it first ("5 tasks"), with no due line. Reopen sends {completed:false}, and the response returns dueDate:null, isActive:true, completed:false. The task goes back to All only, and the counts return to the previous values. The Edit task modal on a dateless task opens with an empty Due date and Save disabled before any field is touched.
