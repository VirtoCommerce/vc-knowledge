2026-11-04, MFA module 3.1002.0-pr-3-1a0f: anonymous introspection lists Query.mfaSettings(storeId: String!, organizationId: String) and Mutation.requestMfaChangeCode / updateMfaUserMode / updateMfaOrganizationMode (inputs carry storeId, enabled, twoFactorToken, code; organization input adds organizationId); an anonymous mfaSettings call answers Unauthorized. Signed in as a B2B user of a store whose StoreMode is Disabled, opening /account/security fires GetMfaSettings with variables {storeId} only (no organizationId) and the answer is storeMode Disabled, isRequired false, requiredBy None, userMode Off, canChangeUserMode false, organizationMode null, canChangeOrganizationMode false, isProviderAvailable true, destination masked. The page then shows only the Passkeys widget: the MFA widget is registered (the module-version check passed) but hides itself because the store is neither AdminManaged nor CustomerChoice and nothing requires the code. /company/info for an Organization Admin shows no MFA widget either.
