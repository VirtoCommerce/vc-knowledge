Store B2B-store, blob content. A designer-format .page file under blogs (/agent-test-qa-blog/AGENT-TEST-qa-article.page, settings.permalink /agent-test-qa-article), published from the Angular designer (git/publish 200, the published file holds the edit). Query.slugInfo(permalink agent-test-qa-article, en-US) returns entityInfo objectType ContentFile with objectId = base64 of 'B2B-store::blogs::/agent-test-qa-blog/AGENT-TEST-qa-article.page'. The storefront then sends GetPage (Query.page with that id, cultureName en-US) and receives {"data":{"page":null}}, and renders 'Page not found'. A file page under pages, same shape, renders. Whether this predates the Page Builder security hotfix (PB 3.1041.0-pr-182) was not compared.
