Signed in to the AngularJS back office as an administrator, opened Security > Sign-in log, clicked the Sign-ins tile and opened the list filters. The Type filter lists All, Password, External provider, On behalf, On behalf revert, Sign out, Multi-factor authentication - no Passkey option, so the grid cannot be narrowed to passkey sign-ins from the UI. The grid's Type column does render 'Passkey' for passkey rows, and a row's detail shows Type 'Passkey'. The REST search with signInTypes ["Passkey"] filters correctly (KB-3C48DBCA).
