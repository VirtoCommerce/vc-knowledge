On PageBuilderModule 3.1030.0-pr-165 (Chromium/Edge), the Designer section actions menu (Hide/Copy/Paste before/Paste after/Duplicate/Delete) and the page actions menu (Paste section/Delete selected/Save selected as Shared Component/Reset template/Refresh preview) render fully with clipboard-read in prompt OR denied state; navigator.clipboard.readText is not called while opening them. Paste entries are NOT disabled in any permission state; the clipboard is read only when a Paste item is clicked: in prompt state this raises the browser permission prompt, in denied state it is a silent no-op (NotAllowedError console.log, no toast), with granted permission an invalid payload shows the alert 'Incorrect data in clipboard' plus a manual-paste dialog, and a valid copied section pastes with 'Section pasted'. Delete selected and Save selected as Shared Component are disabled until sections are selected.
