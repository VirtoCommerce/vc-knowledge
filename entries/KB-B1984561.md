As a store-scoped author with builder:theme, five create_section_type calls (script element, onclick attribute, CSS position: fixed, binding settings.doesNotExist, CSS url() to a foreign host) each returned errors[] in the dry run and isError on save, each naming custom-sections/<type>.json and the rule; theme/status stayed without drafts and the type was absent. change_section_type on an existing valid type refused the same five and left it unchanged. A template at 65,536 bytes was accepted and 65,537 refused; the total of a theme's types is capped at 256 KB (named in the refusal). A member with builder:update but without builder:theme does not see these tools and gets -32600 on a direct call.
