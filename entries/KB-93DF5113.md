In the Admin Shell account menu, choosing a language from the Language listbox sends POST /api/platform/settings/v2/me/values with {"VirtoCommerce.Platform.UI.Language":"<code>"} (204), e.g. "en" when switching back from Arabic. The choice is therefore stored in the user's UserProfile settings tenant, not only per browser.
