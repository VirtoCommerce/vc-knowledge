On PageBuilderModule 3.1033.0-pr-170-236e (PR #170, the VCST-6010 fix; Platform 3.1076.0), as an administrator: POST /api/page-builder-shared-components with storeId NO-SUCH-STORE-XYZ returned 400 text/plain "Store 'NO-SUCH-STORE-XYZ' does not exist." three times in a row; a follow-up POST /api/page-builder-shared-components/search with that storeId returned totalCount 0 each time, and the real store's count did not change (7 before and after). A padded id " B2B-store " and a random GUID got the same 400. An empty storeId is caught earlier: 400 "StoreId, Name, and Content are required.". Ordering: a store-scoped user (user.StoreId B2B-store, all four builder:shared-components verbs) creating in NO-SUCH-STORE-XYZ got 403 {} and not 400, and a user scoped to a different store got 403 too, so store existence is not revealed to an out-of-scope caller. Creating in a real store is unchanged at 201. Pre-fix builds (e.g. 3.1025.0-pr-159-7361, 2026-09-17) returned 201 and persisted an unreachable orphan, so the answer depends on the module version.
