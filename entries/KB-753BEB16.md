On vcst_qa 2026-11-27 (theme 2.63.0, B2B-store), loading / as a guest sent POST /graphql GetPageContext with variables {domain: the storefront host, userId: "", permalink: "/"} and no organizationId or storeId, selecting pageContext.whiteLabelingSettings { logoUrl secondaryLogoUrl themePresetName isOrganizationLogoUploaded favicons{rel type sizes href} mainMenuLinks{title url priority childItems} footerLinks{...} }. The selection has no faviconUrl, so the only favicon input is favicons[] (an empty list keeps the default favicon). The page showed the store record's logo in the header, the catalog-menu entries as main menu and the footer-links columns with child links, with the Mercury palette: store-level branding applies to visitors who are not signed in.
