2026-10-13 on vcptcore_qa (theme 2.60.0-pr-2485): on the PDP of a configurable product with one optional File section, uploading a second file whose name equals an already-attached file shows "Cannot upload file with the same name" on that row and "Fix file upload errors to continue." under the dropzone. The PDP blocks the duplicate. The same content uploaded through POST /api/files/product-configuration (both 200, distinct ids, 100 B and 333 B) and attached together through Mutation.addItem configurationSections fileUrls is accepted with no error. /cart then renders two rows with the same text and different /api/files/{id} hrefs. Each click downloads its own bytes (100 B and 333 B, byte-identical to the uploads). Both survive "Add cart items to quote" and Submit with the same urls, and download 200 for the buyer. Duplicate names are therefore a UI-side rule only.
