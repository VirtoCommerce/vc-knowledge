On vcptcore_regression, keyword Vendor026 and Vendor02* each return the one vendor; Vend?r026, Vendor0?6 and !Vendor026 each return the entire member set (totalCount = all members, and !Vendor026 still includes the vendor); zzqx? returns 0. Same from the Admin Companies and contacts search box (deepSearch:true, objectType Member).
