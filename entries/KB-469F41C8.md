Theme 2.60.0 (dev server) with the SalesRep plugin built from vc-module-sales-rep PR #26 (unreleased). Every task operation the plugin sent from /company/tasks, /company/dashboard and /company/my-customers/{organizationId} (SalesRepTasks, SalesRepTaskCounts, SalesRepTaskMarkers, SalesRepTaskFilterRules, SalesRepCustomerOptions, CreateSalesRepTask, UpdateSalesRepTask) was a POST to the storefront origin's /graphql, proxied to the platform's /graphql, never to /graphql/sales-rep; all returned HTTP 200 without errors[]. With a sales rep's own token, POST /graphql and POST /graphql/sales-rep both answered salesRepTask(id), salesRepTaskTypes and salesRepCustomers with identical data.
