POST /api/pricing/prices/search with { pricelistIds: [id] } returned 404 with an empty body. POST /api/catalog/products/prices/search with the same body returned 200 { totalCount, results } grouped by product. GET /api/pricing/pricelists/{id} returns the list with prices: null, so it cannot be used to enumerate prices.
