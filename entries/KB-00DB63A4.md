The keyword search and the country / state / city facet dropdowns backed by currentCustomerAddresses and currentOrganizationAddresses are wired only into the checkout shipping address-selection popup on /cart. The /account/addresses page and the header ship-to popover call the same queries but show only the plain list with Add/Edit/Delete - that scope is intentional. The State/Province facet appears only when the listed addresses include US or Canadian ones: other countries carry no region, so the facet request returns an empty term list and the facet is hidden, BY DESIGN. Adding a duplicate from /account/addresses is not pre-checked in the UI; the server silently drops the duplicate.
