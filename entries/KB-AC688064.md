After saveLayout(scope accountDashboard, storeId B2B-store) for a buyer, admin POST /api/customer-preferences/search {userId} lists one preference named Layout.accountDashboard.B2B-store whose value is the layout JSON. The GraphQL schema has only layout and saveLayout (no delete). DELETE /api/customer-preferences?ids=<id> removed it and the next Query.layout for that buyer returned null, the same as a never-saved user.
