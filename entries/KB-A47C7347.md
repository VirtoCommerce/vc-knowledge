vcst, Catalog 3.1046 (PR 909 build), event-based indexation off: with barcode fields = [a Product ShortText property], xAPI products(filter: ... barcode:'<value>') returns 1 hit; after DELETE /api/catalog/properties?id=<id>&doDeleteValues=true and POST /api/search/indexes/index for that product, the same query returns totalCount 0 within about 10 s, with no errors[]. The store setting still lists the field. DELETE /api/catalog/properties/{id} (id in path) answers 405, and PUT /api/stores/{id} answers 405 — store update is PUT /api/stores with the whole store body; Catalog.Search.BarcodeSearchFields is a Json-typed setting whose value is a JSON string.
