Storefront /company/tasks, Edge 1440x1080, theme 2.60.0, Sales Rep hub from the SalesRep storefront plugin. Two seeded reps, both with zero tasks (Query.salesRepTasks counts 0 for the current day, all, upcoming, overdue and completed). On load the page sends Query.salesRepTaskFilterRules(storeId B2B-store, cultureName en-US) on /graphql. For the rep serving 4 organizations it returned three rules, upcoming/Upcoming, overdue/Overdue, completed/Completed, and the page rendered five chips: Today 0, All 0, Upcoming 0, Overdue 0, Completed 0. For the rep holding the sales-rep role with no served organizations (Query.salesRepCustomers totalCount 0) it returned an empty list, and the page rendered only Today 0 and All 0, both enabled. Both responses were HTTP 200 with no errors[]. The status chips follow the filter rules for the rep's served-organization scope; the task count does not decide them.
