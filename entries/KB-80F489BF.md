vcst_qa 2026-11-27, WhiteLabeling 3.1008.0. POST {platform host}/graphql with no Authorization header: { whiteLabelingSettings(organizationId: <organization B GUID>, storeId: "B2B-store", cultureName: "en-US") { logoUrl organizationId } } answered HTTP 200, errors null, with organization B's own logoUrl (cms-content/assets/customization/logo_<orgB>_*.svg) and organizationId = organization B. The same anonymous call with the full field set also returned that organization's favicons, theme preset, main-menu and footer links. So the query is not scoped to the caller's organization; whether organization branding is meant to be public was not decided here. The storefront itself only asks for the signed-in member's own organization (the member's page loads contained no other organization's id or logo).
