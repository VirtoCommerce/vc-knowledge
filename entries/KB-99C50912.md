On store-acme, brand settings were enabled with the brand catalog set to the store's virtual catalog and the Brand property set to "Price USD"; Query.brands(storeId: "store-acme") returned totalCount 0, so no brand slug existed to resolve or to debug in the Admin "Debug SEO links" tool. The source explains it: SearchBrandQueryHandler (vc-module-x-catalog) builds the brand list from the term-facet values of the store's Brand property, so a price aggregation chosen as that property yields no brands by construction. To test brand pages, point the Brand property at a string product property that carries brand names (the xCatalog default is "Brand") and give the brand catalog first-level categories with those names and SEO slugs.
