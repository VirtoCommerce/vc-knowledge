Theme 2.60.0-pr-2523-4263-4263715a with Return 3.1005.0-pr-28-fb4f, 2026-10-12. A buyer created a storefront draft return with a comment and a line reason and cancelled it from /account/returns/:id without submitting. Signed in as a holder of xapi:my_organization:return:view in the same organization, opening /account/returns/<id>/edit rendered the heading 'Add return details' (no RMA number) and the single message 'This return was not found'; none of the buyer's comment or line-reason text appeared. The page's Query.return call answered {"data":{"return":null}} with no errors[]. Contrast: the same holder opening /edit of a colleague's submitted (Requested) return gets the status message 'This return can no longer be changed — its status is Requested' (see KB-58A94337), so the /edit route reveals that a submitted return exists but not that a cancelled draft does.
