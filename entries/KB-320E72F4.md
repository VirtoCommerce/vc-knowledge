Theme 2.60.0 with the SalesRep plugin built from vc-module-sales-rep PR #26 (unreleased). The 'Add to calendar' group (Google Calendar, Apple Calendar, both unticked) appears only on a new call (Schedule call, or New task with type Call); Edit call and non-call tasks do not show it. With Google ticked, Save created the call (Mutation.createSalesRepTask), closed the dialog and opened a second tab whose first request was GET calendar.google.com/calendar/render?action=TEMPLATE&text=Call+—+<customer>&dates=<dueDate UTC>/<dueDate +30 min UTC>&details=<notes>, e.g. dates=20261030T191500Z/20261030T194500Z for dueDate 2026-10-30T19:15:00Z; without a Google session that URL redirects to Google sign-in, carried as the continue parameter. With Apple ticked, Save created the call and downloaded call.ics: VCALENDAR 2.0, PRODID -//Virto Commerce//Sales Rep Hub//EN, METHOD:PUBLISH, one VEVENT with UID = the saved task id, DTSTART = dueDate and DTEND = +30 min in UTC (20261030T223000Z / 20261030T230000Z), SUMMARY 'Call — <customer>', DESCRIPTION = the notes with ; and , escaped, CRLF line endings.
