In StorefrontApp/src/index.ts of the module, `export function init(): void` adds the Company child routes, calls mergeMenuSchema, registerAccountSection (titles are keys such as sales_rep.hub.title) and finally loadLocale(). loadLocale registers a locale loader and fires `void mergeLocale(globals.i18n, current)`, which imports ./locales/<lang>.json as a separate dynamic chunk. Nothing awaits it. The host federation loader accepts `init?: () => void | Promise<void>`, awaits it in runInit, and only then settles the plugin as loaded, which releases the route placeholders. A plugin that returned the locale promise would keep the host's loader up instead of showing raw keys. Separately, plugin.config.ts declares the Corporate header link with title key sales_rep.navigation.link. The host's federation declarations doc states that a declared title is rendered with t(key) before plugin locales load, and shows the raw key until they do.
