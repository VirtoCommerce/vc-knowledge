Signed in as an organization maintainer on vcst, Firefox. At 1024x768 /company/members renders the desktop VcTable (cards below 1024). The table is 854 px wide inside a 738 px card (the VcScrollbar wrapper .vc-table__scrollbar has overflow visible because the page does not pass the scrollable prop), so documentElement.scrollWidth is 1107 and the Active and actions columns sit past the right edge. The Name column measures 320 px although its cell has w-40 truncate: in an auto-layout table a nowrap cell's minimum width is its full text, so the 'truncate' never applies; the widest name in the list was about 288 px of text. The Email column stays at 208 px because its cell also has max-w-52. The table's left edge is fixed by the account sidebar (x=253), so the document scrolls at every width from 1024 to about 1106 px; at 1120 px the table still spills past the card but not the viewport; at 1280 it fits; at 1023 and 768 the card layout is used and nothing overflows. With short names only, the table fits.
