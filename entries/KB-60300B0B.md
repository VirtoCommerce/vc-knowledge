On vcst_qa 2026-11-18: a contact with no Groups of its own belongs to 11 organizations; only one carries user group G. A product indexed with user_groups=[G] (out of stock, so queried without the in-stock term). With the contact's current organization set to the G organization, Query.products(storeId, userId, query:<sku>) as that user returned totalCount 1. After switching the current organization on the storefront to an organization without groups (contact currentOrganizationId changed), the same call with a fresh token returned 0. Anonymous returned 0 in both cases. So the group comes from the currently selected organization, not from the union of all the contact's organizations. A test of org-granted visibility must set the member's current organization to the granting one.
