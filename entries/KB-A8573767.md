On storefront theme 2.59.0-pr-2519 (desktop, split layout), in the /account/orders Filters popover, opening the Start date calendar puts focus on today's day button. ArrowRight moves focus +1 day, ArrowDown +7 days. Enter selects the focused day, writes it to the Start date field as MM/DD/YYYY, closes the calendar and focuses the Start date input. Escape on an open calendar removes the calendar dialog, keeps the Orders filters popover open and returns focus to the Start date input; a second Escape closes the filters popover and focuses the Filters button. None of these steps applies the filter or sends GetOrders.
