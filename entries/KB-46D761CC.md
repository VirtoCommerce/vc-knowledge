Signed-in personal buyer, Edge 1920, theme 2.63.0-alpha.2681. On /search?q=a with Brand 3DR applied (URL facets="BRAND":"3DR", 84 results), clicked Clear in the header box, typed WH-001 and pressed Enter. The page went to /search?q=WH-001&facets="BRAND":"3DR" and showed 0 results ('There are no results found' + Reset search). The same query typed on the home page goes to /search?q=WH-001 and returns 6 results. So the facet filter survives a keyword change made from the results page; whether that is intended is not documented here.
