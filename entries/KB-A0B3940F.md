In xAPI products(storeId, filter), a quoted term such as code:"ABC-1" or gtin:"<13 digits>" matches the whole value only: a strict prefix of an existing product code returns 0. Values are matched case-insensitively on this deployment's search provider. The default scope is products only: a variation is found with is:variation code:"...", and a manufacturerPartNumber held only by a variation is found with is:product,variation manufacturerPartNumber:"..." (1 hit; the parent does not match). A double quote inside a quoted value can be escaped with a backslash and still matches.
