Edge 155, 1440x900, signed-in account, /account/profile, focus in 'Last name' (nothing typed). Tab focuses the 'Default language' combobox and its list opens on focus (aria-expanded=true, three options: Deutsch (Deutschland), English (United States), francais (France)); the list is rendered inline right after the field, not teleported. The next Tab moves focus into the list onto the option 'Deutsch (Deutschland)'. Three more Tabs keep focus inside the same listbox (it cycles over the three options and returns to 'Deutsch (Deutschland)'); 'Default currency' is never reached. Shift+Tab inside the list also moves between options. Escape returns focus to the Default language combobox with the list closed and the value unchanged (English (United States)); Tab then continues normally. The same option-level Tab handling applies to teleported lists once focus is put inside them with ArrowDown (seen in the /company/tasks New task Type list). Nothing was saved.
