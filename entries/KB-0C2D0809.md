VCST-6974 hotfix delivery check (scenario 15). On vcptcore-stable (ProfileExperienceApiModule 3.1009.4, Stable-15 backport) and vcptcore-regression (3.1020.4, Stable-16) an anonymous POST /graphql { role(roleName:"Store administrator"){ id name permissions } } returns HTTP 200 with errors[0].extensions.code=Unauthorized, message "Anonymous access denied or access token has expired or is invalid.", data.role=null — the role's permissions are NOT leaked. The SAME query with an admin bearer returns HTTP 200 with data.role populated (name "Store administrator"), proving the query itself works and the anonymous result is genuine permission gating, not a broken query. Pre-fix this query leaked a role's full permission list to anonymous callers (reconnaissance). Confirmed identical on both stands.
