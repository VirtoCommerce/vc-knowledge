On vcptcore_qa1 (theme 2.59.0-pr-2477-ff59, OTP 3.1000.0-pr-1-11d6, 2026-10-01): typing 12a45 leaves 1245 (letters dropped); with fewer than 6 digits the Sign in button is disabled and Enter sends nothing. The 6th digit auto-submits POST /connect/token grant_type=otp_email. Filling 1234567 keeps 123456 and auto-submits it. Filling " 420 778 " (spaces) sends code=420778 and signs in. A wrong or expired code returns 400 invalid_grant code invalid_code ("The code is invalid or has expired."), and the UI shows ONE alert "That code isn't right. Check the latest email." with the digits kept and the field marked invalid. Resend code issues a NEW, different code, clears the field and the alert, and shows "New code sent."; Use a different email returns to an empty email step with no alert. A code entered ~8.5 minutes after it was issued was refused as invalid_code, while codes used within ~1.5 minutes worked. Success without returnUrl lands on /, with returnUrl=/account/orders on /account/orders.
