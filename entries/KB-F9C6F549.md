On /graphql/sales-rep, salesRepDocuments(keyword) filters on the document metadata Name, which the API exposes as displayName (e.g. name 'AGENT-TEST-Product-Catalog.pdf' has displayName 'AGENT-TEST-Product Catalog 2026'). A keyword equal to the full file name, or any hyphenated/extension fragment that exists only in the file name ('Product-Catalog', 'Filler-07', '.pdf'), returns totalCount 0, while a substring of the displayName ('Catalog', 'TEST-Filler', 'Industrial') matches. Same on SalesRep 3.1014.0 and 3.1015.0-pr-15; source: SalesRepDocumentMetadataSearchService.BuildQuery uses x.Name.Contains(keyword). A test that searches by the file name gets an empty page with no error.
