The bordered field box measures 295x44; each inner date input measures 114x19. elementFromPoint 5px from the top and bottom edges of the box, above/below the Start input, returns the field div itself, and a real click on the '-' separator inside the box leaves focus on the Filters dialog body. The field has no click handler, so the effective pointer target of each input is the 114x19 input. The nearest other target (the 38x38 Open calendar button, or the other input) is more than 12px from each input's centre, so a 24px circle around each input does not overlap another target.
