Theme 2.59.0-pr-2536 on /company/tasks and the deployed 2.59.0 build on /company/calendar, Edge 1920. In the New task and Edit task dialogs, Title/Due date/Priority/Type have a <label for>, but Notes renders <div for="textarea-N" class="vc-label">Notes</div> and the textarea carries aria-labelledby="textarea-N" (its own id), no aria-label and no associated label. The accessibility snapshot lists it as an unnamed textbox (an empty field computes an empty name; Playwright resolves it as getByLabel('')). The shared VcTextarea component passes `for` instead of the label component's for-id prop, so the label falls back to a div. Same on both builds.
