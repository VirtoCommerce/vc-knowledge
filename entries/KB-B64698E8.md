Anonymous shopper, Chromium 1920px, theme 2.62.0-alpha.2647. After searches for laptop, product (scoped) and lap, focusing the empty header search input opens the dropdown with a 'Hints' section listing those terms as buttons; clicking one runs /search?q=<term>. The dropdown exposes no button or link to clear or remove history entries (accessibility tree shows only the hint buttons, 'Start typing to search' and 'Check all products'). The same holds at 375px in the mobile overlay. A legacy regression case (SRCH-008) expects 'History can be cleared on request'.
