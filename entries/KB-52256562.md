Signed in as a two-organization buyer (both Approved), I opened burger → Corporate → My organizations at several CSS viewports in Edge. The list container (.multi-organization-menu) has its own overflow-y:auto and a computed height of exactly viewport height minus 224px: 1.6px at 320x225, 32px at 320x256, 96px at 568x320, 136px at 640x360. At 320x225 both rows are in the DOM but clipped inside the 2px box; the panel's outer scroller only scrolls 28px, so pointer users see no option. Tab still focuses the checked radio (2px focus sliver) and ArrowDown switches the organization without the option ever being visible. At 320x256 one label line shows in a 32px inner scroller; at 568x320 and 640x360 both rows are fully visible. The rule comes from vc-frontend multi-organisation-menu.vue (h-[calc(100vh-224px)] overflow-y-auto), present since PR #2092 (Dec 2025), so it is not new in theme 2.62.
