---
On Return 3.1005.0-pr-28-62f9 the organization list holds every buyer's returns whose status is not Draft, the caller's own non-drafts and admin-created New returns included, with customerName and organizationName. A return belongs to the ORDER's organization (id and name copied when the return is created, also for admin-created returns), so a return on an order without an organization is in no list, a return created with another organization selected still lands in the order's organization, and renaming the organization or removing the buyer does not move existing returns. Drafts are excluded by their current status only: a draft the buyer cancels without ever submitting appears as Cancelled and is readable by holders (reported as a defect candidate). Keyword matches RMA, order number and buyer name in any case; an upper-cased organizationId returns the same rows.
