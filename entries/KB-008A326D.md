2026-11-18, admin token. POST /api/inventory/search {fulfillmentCenterIds:[<one FFC>], take:500} returned totalCount 268 but only 219 distinct productIds: one product carried 50 inventory records with distinct ids in that single FFC, all created within the same millisecond range (one bulk write), mixed inStockQuantity values (0, 200, ...). The Admin FFC 'Products' widget for the same FFC showed 264, and the inventory grid listed the product once. So inventory records are NOT enforced unique per (productId, fulfillmentCenterId) on this build; which record a stock read uses is undetermined. Origin of the duplicates (seeder/import vs platform) not established.
