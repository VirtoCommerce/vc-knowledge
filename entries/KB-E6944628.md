Storefront 2.59.0-pr-2536 (local build against the vcst_qa backend), signed in as a sales rep on B2B-store. Loading /company/my-customers sends SalesRepCustomerFilterRules(storeId, cultureName=en-US), which returns [{name:"All", localizedName:"All"}] with no errors. No filter-chip row renders above or beside the customer table at 1920, 768 or 375 px; the table (or the mobile cards) render normally. The All rule is the baseline and is not shown as a chip, so with no other rule there is nothing to select. Tests of chip selection or a filter-specific empty state cannot run on this data.
