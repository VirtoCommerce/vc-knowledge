On a store with Long links, for a top-level category slug: '/slug' resolves (all 7 stages, 1 item). '//slug', 'slug/' and 'SLUG' list the record in the Candidates stage but reject it with PermalinkMismatch whose details give the correct path, and Stages 1-6 are empty. ' slug ' (surrounding spaces) returns []. With storeDefaultLanguage empty or omitted the response holds only the Candidates stage, and the candidate is marked isResolved:true with no reasons although no pipeline stage follows. An organizationId changed nothing for catalog records. A missing or empty permalink returns HTTP 500 'Value cannot be null. (Parameter permalink)'; a 2.5K-char permalink returns [] and a 9K-char one HTTP 414. The Admin Debug form trims the input and keeps Debug disabled for whitespace only, so the UI never sends an empty permalink.
