A disposable back-office account was given an expired password with POST /api/platform/security/users/{name}/resetpassword (forcePasswordChangeOnNextSignIn=true). Signing in to the AngularJS admin redirected to #!/changepassword: banner "Your password has expired. You must change the password to continue using the manager", fields Current password, New password, Repeat new password. With all three filled (validatepassword answered 200 succeeded=true), Change sent POST /api/platform/security/currentuser/changepassword with body keys ["newPassword"] only; the server answered 500 {"message":"Value cannot be null. (Parameter 'providedPassword')"} and the dialog showed "Sorry, we could't reset password for this user". The scope tree showed the Current password value on the ng-if child scope's own postData, separate from the controller's postData that the submit sends. The same 500 came from a direct REST call with body {newPassword} only. The password stays unchanged and expired.
