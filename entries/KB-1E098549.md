On /account/dashboard edit mode, clearing a checkbox in 'Statuses to show' and pressing 'Save layout' sends Mutation.saveLayout (scope accountDashboard) whose recent_orders block settings carry one entry per hidden status, key tab.<Status> value false (e.g. tab.New=false, tab.Cancelled=false), next to maxRows; Query.layout reads the same back and there is no hiddenTabs array. Re-checking a status removes only its entry. With Processing hidden and the buyer's only Processing order moved to New via the Platform API, edit mode listed only the remaining status (no Processing checkbox), and Save without change still sent tab.Processing=false; after moving the order back to Processing the tab stayed hidden and its checkbox showed cleared.
