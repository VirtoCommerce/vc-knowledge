As a user with store-scoped builder permissions, tools/call publish_page with dryRun returned expected_versions (the draft and settings:<id>) and changes [status Draft -> Published]. The real call with those expected_versions returned {status: pending_approval, change_id, expires_at = +72 h}; the page stayed Draft and the storefront did not show it. As another user (admin) in Admin Shell #/mcp-approvals the request was listed as Publish page / publish_page / Pending; opening it shows What will change, a Review Comment box and the Request block. Approve opens a Confirmation dialog "Approve this change? The tool runs right away as you." with Confirm and Cancel; after Confirm a toast "Approved and applied" appears and the request shows Status Applied, Reviewed by and the comment. The storefront page then rendered the approved draft. In #/mcp-audit the agent's call is publish_page "Waiting for approval" (user = the author, client = the OAuth client id), followed by two rows from the approver with client "back-office": publish_page Succeeded and approve_pending_change Succeeded.
