Local production build of vc-frontend PR 2600 at a4f29534 with design soft, proxied to the vcst backend, Firefox 1920. Signed in, the home page is Builder.io content (76 .builder-block). 26 text nodes compute font-family "Lato, -apple-system, Roboto, Helvetica, sans-serif": they are DIV.builder-text blocks (section titles such as "Popular categories" 30px/700, category names 18px/700, body copy 16px/400). The value comes from the Builder SDK's injected <style data-id="builder-<block id>"> rules (one class per block, no @layer), which beat the theme's layered html font-base rule; Lato faces 400/700/900 are downloaded on that page. The one real heading (h2 "Discounts. Loyalty cards" inside .builder-block) computes Geologica 700, and on /predefined-products and /product-section the products-block h2 is Geologica 700. Anonymous home (page-builder content) has no Lato text. So under soft one page can show Geologica headings, Inter body and Lato Builder text blocks. On classic the authored Lato equals the theme font, so the difference is invisible there.
