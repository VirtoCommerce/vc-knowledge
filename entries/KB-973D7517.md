Admin bearer token, platform 3.1087.0-pr-3134-a3d2. POST me/values with a Store setting (XPickup.TodayAvailabilityNote) -> 400 "Setting '...' is not registered for tenant type 'UserProfile'"; a global setting -> same 400; an unknown name -> 400 "Unknown setting: '...'"; same 400s on tenant/Store/{storeId}/values for a UserProfile setting and an unknown name, and on global/values for an unknown name; an unknown tenant type -> 400 "not registered for tenant type 'NoSuchType'". A body mixing one valid and one invalid name -> 400 and the valid one is NOT saved (all-or-nothing). Empty object -> 400 "Request body must be a non-empty JSON object"; non-JSON -> 400. But an Integer setting (VirtoCommerce.Platform.UI.FullDateThreshold) sent "notanint" -> 500 {"message":"The input string 'notanint' was not in a correct format."}, and a ShortText setting with allowedValues (FullDateThresholdUnit) accepted "Fortnights" with 204 and stored it. Valid me and Store-tenant saves return 204 and read back. Swagger lists only 204/401/403 for these POSTs (no 400).
