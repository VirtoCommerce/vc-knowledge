As an admin, POST /api/carts/search {customerId} lists every cart of a user (default, named, SavedForLater) and DELETE /api/carts?ids=... removes them (search then returns 0). Signed in as that buyer (password grant, store B2B-store), Query.cart(storeId, userId, currencyCode, cultureName) then returned data.cart = null and persisted nothing. It needs userId: without it the query answered Forbidden 'Access denied.'. Mutation.clearCart(command:{storeId,userId,currencyCode,cultureName}) returned a cart named 'default' with itemsQuantity 0, and /api/carts/search afterwards showed exactly one persisted cart, 'default', with 0 items, carrying the buyer's organizationId. So a test that needs 'only an empty default cart' should delete the carts and call clearCart. Calling the cart query alone leaves zero carts.
