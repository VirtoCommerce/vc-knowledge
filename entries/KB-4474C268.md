/account/coupons, signed in, Coffee preset. The hint under the coupon code (12 px, class text-secondary-500) renders rgb(99, 119, 128) on the button background rgb(238, 240, 242): 4.1:1, below the 4.5:1 required for small text. With the storefront colour mode set to dark the same hint is 3.23:1 on rgb(20, 23, 25). axe-core (wcag2a, wcag2aa, wcag21aa, wcag22aa) reports color-contrast serious on every card (16 of 16 on the page). The coupon code itself and the Expires line pass. The same card renders on the Sales Rep customer profile widget and the all-coupons page, with the same ratios.
