2026-10-15 vcptcore_regression (XPickup 3.1008.0, Search 3.1010.0), productPickupLocations(productId with 102 eligible locations, cultureName en-US) vs store-level pickupLocations: "Toronto" 10 / 11; "O'Neil" 102 / 0; "Toronto'" 10 / 0 (apostrophe just dropped); "\"O'Neil\"" (quoted) 0 / 0; "Toronto)" 102 / 0; "(" 102 / 1; "Neil" 0; "Smith & Co" 0; "StoreId:x" 0 / 0 (treated as a filter, not text). Source: XPickup sends Keyword to the Shipping module's indexed pickup search, whose base IndexedSearchRequestBuilder (vc-module-search) runs it through SearchPhraseParser; the grammar's SimpleString allows only letters, digits and _-./@+, so a keyword the parser cannot parse loses its keyword part and the search runs unfiltered. Store-level pickupLocations uses the DB service (Name/Id Contains), so it treats the same text literally.
