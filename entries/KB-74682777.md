A password-grant token (storeId=B2B-store) for the platform administrator carried role "__administrator", no organization_id, and only eight non-storefront permission claims (builder and sql-queries), none of them xapi:my_organization:*. With it, organizationReturns for a real organization, for an organization with legacy backfilled returns and for an unknown id all returned Forbidden "The organization's returns are not available to this contact." with data null, and return(id) for any return was null. A fresh "Organization maintainer" role holder's token also lacks xapi:my_organization:return:view (it carries edit, order:view, user:invite).
