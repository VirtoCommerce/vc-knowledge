Signed in, Bank card (CyberSource) selected on /cart. In design soft (local build of vc-frontend PR 2600 at a4f29534, vcst backend, Firefox 1920) the #cardNumber-container and #securityCode-container wrappers (.cyber-source-input-wrap, rounded-[3px] in payment-processing-cyber-source.vue) compute border-radius 3px, while the Cardholder name and Expiration date vc-input containers compute 16px; Expiration (16px) and Security code (3px) sit in one row. In classic-BASE the same pair is 8px vs 3px. The microform styles pass only font-size and colour (comment: custom font-family not supported), so the iframe text is not Inter. On a localhost origin the microform iframes are refused by CSP frame-ancestors (only the vcst storefront origin is allowed), so the secure fields render empty there.
