Stable 16 (platform 3.1076.1, Customer 3.1029.0), Admin > Contacts > member > Dynamic properties widget. On an Employee and a Contact with Required Short text Dictionary properties (Dictionary+Multilingual+Required and Multivalue+Required+Dictionary, each with 2 dictionary items), OK enabled once every non-dictionary Required property was filled although both Required dictionary pickers were empty; Save then sent PUT /api/members -> 204. An empty Required Short text / Long text / Integer / multivalue property, or one empty language of a Required+Multilingual property, keeps OK disabled. Not documented in the Platform User Guide; not yet compared with Stable 15.
