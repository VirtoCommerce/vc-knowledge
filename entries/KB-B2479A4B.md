DELETE /api/page-builder-multilanguage-pages/{id} on a root with published en-US and de-DE versions answered 400 "Multilanguage page '<id>' has language versions: archive them instead.". DELETE /api/page-builder-pages/grouped/{groupId} on each version answered 200, after which DELETE of the root succeeded and POST /api/page-builder-pages/search no longer listed the pages. The root itself was created by POST /api/page-builder-multilanguage-pages/convert/{groupId} from a single en-US page, and the translation by POST /{id}/languages/de-DE?copyContent=true.
