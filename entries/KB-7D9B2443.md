B2B buyer signed in with the password, Chrome lane with a WebAuthn virtual authenticator (ctap2, internal, resident key, UV). On /account/security the Passkeys card with no keys shows "You have no passkeys yet."; clicking Add passkey and completing the ceremony replaces it, without a reload, with one row: an icon, the name "Unnamed key" (the virtual authenticator has no known AAGUID name) and the line "Device only · Created 10/30/26, 2:39 PM", plus Edit (pencil) and Delete (bin) icon buttons. Edit opens a "Rename key" dialog with one Name field, Cancel and Save; Save shows the new name in the row.
