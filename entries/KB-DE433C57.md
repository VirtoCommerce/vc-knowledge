(1) A personal contact with selectedAddressId null, after its first address was added by updateMemberAddresses, read selectedAddressId = that address id without any updateContact. (2) After the selected address was deleted with deleteMemberAddresses, me.contact.selectedAddressId still returned the deleted id (dangling); currentCustomerAddresses(ids:[thatId]) returned 0 items. Adding eight more addresses left the dangling id in place. (3) For an organization maintainer of two organizations, updateContact(selectedAddressId = an organization A address) read back with a token for organization A as that id, and with a token for organization B (organization_id on the token request) as null; B's currentOrganizationAddresses held only B's two addresses and ids:[A's id] gave 0 items. updateContact validates lastName and rejects digits (extensions.errorCode InvalidCharacters).
