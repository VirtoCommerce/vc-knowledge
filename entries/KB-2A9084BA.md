With a wishlist whose sharingSetting is scope Customer, access Read, and a single target equal to the member's active organization, a buyer of that organization gets errors[Access denied., code Forbidden] with data.wishlist null from wishlist(listId), and the list is absent from that buyer's own wishlists(). A member of a different organization gets the same Access denied. Observed on the multi-target sharing build (sharingSetting.targets[] / addSharedWithIds, vc-module-x-cart 3.1037.0-pr-141, vc-module-cart 3.1011.0-pr-194) on a share created through the storefront; the same denial was observed on the older single sharedWithId model.
