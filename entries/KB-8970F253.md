On vcptcore_regression (platform 3.1076.13, Customer 3.1029.1) two employees created via Contacts > Add > Employee (first/last name typed, Full name auto-composed) were stored with name=null while fullName/firstName/lastName were set (GET /api/members/{id}). The Companies and contacts grid renders their rows with an empty Name cell and the employee blade title is empty; keyword search still finds them. Contacts created the same way get name==fullName, and an employee created by admin in 2024 has name==fullName.
