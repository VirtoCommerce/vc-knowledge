Signed in to the Admin as an administrator, a browser GET /api/members/invitations?take=5 returned HTTP 200 with content-length 0 (no JSON, no totalCount/results). The path is read as GET /api/members/{id} with id = "invitations"; an id that resolves to no member reads 200 with an empty body, as for a deleted member. So a 200 here does not prove an invitations list exists; a test asserting totalCount/results on this route is stale. In the Admin, invitations are sent from the Customers list toolbar action "Invite customers".
