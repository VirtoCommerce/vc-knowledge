They are the same instant in two timezones. Admin prints an order timestamp with no offset; the API returns UTC with an explicit Z. So comparing a timestamp off a screenshot with one off a payload, without converting, shows a discrepancy of however many hours the reader happens to be from UTC, and it is not a discrepancy. This bites hardest when a screenshot is the evidence in a bug report and the reader is in a different timezone from the person who took it.
