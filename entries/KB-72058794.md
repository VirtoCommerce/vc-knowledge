On theme 2.60.0-pr-2523-466f, at 375, 768, 960 and 1023 px both tabs render one card per return with label/value pairs (RMA, Date, Status, Qty, plus Buyer name on the organization tab) and no table; from 1024 px (also 1280 and 1920) a table with RMA, Date, (Buyer name,) Status, Qty columns renders with whole values. Resizing 1024 -> 1023 -> 1024 swapped table -> cards -> table without a reload. An organization card for a colleague's return opens the read-only details page; a Draft card in My returns opens /account/returns/{id}/edit. At 375 px the RMA value wraps at its hyphen inside the two-column card.
