In the AngularJS admin (VirtoCommerce.AdminAngularJs 3.1099.0-pr-7-ef1c), the user API key blade (route #!/workspace/security, user → API key widget) for a user without a key shows the note "The key is generated when you save." An axe-core 4.10.2 scan scoped to the blade reported color-contrast (serious) on that note: text #999999 on background #f9f9f9, about 2.7:1, where WCAG 1.4.3 needs 4.5:1. The style comes from the module's shared .note class in _base-modules.sass ($noteNotifyColor / $noteNotifyBg), not from the API key change. The change only added new text that inherits it, so every other .note text in the AngularJS admin has the same contrast. The other states of the same blade ("New API key" block, reopen with a hint) had 0 axe violations. The blade loads its data from GET /api/platform/security/users/{id}/apikeys.
