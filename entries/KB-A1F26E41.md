With an admin token on vcst: GET /api/platform/security/roles/org-employee returned an empty body (no role), while GET /api/platform/security/roles/Organization%20employee returned id org-employee with permissions storefront:organization:view and storefront:user:view. POST /api/platform/security/roles/search with keyword "org-employee" did not return that role; a search without a keyword listed it (id org-employee, name Organization employee) but without its permissions. So to read a role's permissions by id: list roles, match the id, then GET by the role's name.
