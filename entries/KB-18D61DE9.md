Return 3.1005.0-pr-28-fb4f, 2026-10-12, admin token. GET /api/platform/settings/Return.Status allowedValues = [Completed, New, Canceled, Processing, Approved]: no Draft, Requested, PartiallyApproved, Rejected or the Cancelled spelling the flow writes, although the module guide says the dictionary holds both cancelled spellings. GET /api/return/{id}/available-statuses answers: New -> [Completed, New, Canceled, Processing]; Approved -> [Completed, Processing, Approved]; PartiallyApproved -> [Completed, Processing]; Cancelled -> [Canceled] (not the return's own spelling); Requested, Rejected and Draft -> []. Other stands (vcptcore_dev, vcptcore_qa1) answer [Cancelled] for a Cancelled return and offer the full dictionary, so this is the stored dictionary of the stand, not module behaviour. Explains why the storefront Status filter on vcst lists Approved, Cancelled, Completed, New, Processing only.
