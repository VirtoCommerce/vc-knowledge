On vcst_qa, signed in as a two-organization user (one membership locked), the account-menu popover with listbox 'Organizations' is shown at 1280x900. At 640x450 and 320x225 CSS viewports (the WCAG 1.4.10 equivalents of 200% and 400% zoom) the storefront switches to the mobile layout and organization switching lives under the burger menu → Corporate → 'My organizations'. The option set was the same as on desktop (active org selected, locked org disabled), there was no horizontal overflow and keyboard navigation worked; the option rows measured about 560x20 px with a 1x1 px radio input. Observed in run REG-2026-11-12-1023-W5e (case B2C-ORG-057).
