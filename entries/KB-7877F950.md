2026-11-10 19:15Z, operator authorization-code token (client claude-admin-qa), protocol 2025-06-18, each request sent with a W3C traceparent. tools/call list_modules {take:1} (Succeeded) and restart_platform {reason} (pending_approval) returned results with no _meta at all; list_modules {take:"abc"} and reset_platform_cache {} (tool errors, isError true) returned _meta.trace_id equal to the incoming traceparent trace id. JSON-RPC errors (-32600 forbidden, -32602 unknown tool) carry no trace id. POST /api/mcp/audit/search shows exactly one row per call, each with traceId = the incoming traceparent trace id (outcomes Succeeded, Forbidden, PendingApproval, Error). So an agent can quote a trace id to the user only when its call failed as a tool error.
