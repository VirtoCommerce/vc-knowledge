In the Admin order blade the Status dropdown offers seven settable values: Cancelled, Completed, Custom, New, Payment required, Pending, Ready for pickup. Processing appears in the orders grid but is not settable - it is computed when payment is captured. The storefront relabels statuses for shoppers, so a storefront label need not equal the admin value and the mapping is not always one-to-one. Admin seeding should use the admin value; storefront assertions should use the displayed label.
