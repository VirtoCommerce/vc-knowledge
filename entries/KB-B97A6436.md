2026-10-12, platform 3.1078.0, admin token. GET /api/platform/settings, GET /api/platform/settings?group=Platform and GET /api/platform/settings?keyword=lockout all returned 200 with the same 341 entries (each with name, value, valueType, groupName). None of the 341 names matches lockout, MaxFailedAccessAttempts or MaxPasswordAge; the Platform|Security group holds account types, token prune and sign-in log settings and file-extension lists only, and the Admin Settings > Platform > Security section shows the same. Lockout policy is therefore not readable or editable through the settings API on this build.
