Signed in on vcst with one cart line and a saved shipping address, Firefox. In Shipping details the address line is followed by a 32x32 icon-only pencil button (class vc-address-selection__button, data-test-id select-address-button, type=button). The accessibility tree shows it as a bare 'button' with no name: no aria-label, no aria-labelledby, no title, empty text, and the pencil icon is aria-hidden. Clicking it opens the address picker. The visible 'Shipping address*' label is not associated with it. axe-core 4.10.2 reports button-name (critical) on the same selector.
