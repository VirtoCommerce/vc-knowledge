Signed in as an organization member and measured the first <header> element at several widths. At 375px and 768px the only header is a fixed 90px mobile header (class 'fixed z-40 w-full shadow-md'): no [data-test-id=account-button] is present, and the ship-to line shows inside the mobile header. At 1024px and 1279px the 40px utility bar is present but the account button shows no name text. At 1280px and above the organization-name-label and customer-name-label spans are visible. In frontend 2.59.0-pr-2534 these spans are capped by max-width: 128px each at 1280–1499 when both org and user are shown, and 320px at ≥1500 or when only the user name is shown. A layout test of the account label therefore has to run at ≥1280, and a test of the utility bar has to run at ≥1024.
