Theme 2.59.0: an order placed through the storefront checkout (billing same as shipping) shows separate 'Billing address' and 'Shipping address' sections on /account/orders/{id}. Orders created via API/seed whose CustomerOrder has a Billing-type address (addresses[].addressType=1) but whose inPayments[].billingAddress is null show only 'Shipping address' - the detail page reads the billing block from the payment, not from the order-level addresses. A case asserting billing on such seeded orders fails for data reasons.
