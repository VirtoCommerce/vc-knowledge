Guest, desktop 1280. With exactly one product in a compare category tab, the All/Differences tab-switch gets the vc-tab-switch--disabled class and pointer-events:none, so a mouse cannot change mode and the control looks greyed. The buttons keep tabindex=0, no disabled attribute and no aria-disabled: Tab reaches Differences (focus ring shown), Enter sets aria-pressed=true and the table switches to the differences view. After that, the mouse cannot click All back on that tab (pointer-events:none on both); switching to another category tab with the mouse resets the mode to All. Observed identically on a later 2.60 theme build that reworks the compare table, so it is not caused by the table structure.
