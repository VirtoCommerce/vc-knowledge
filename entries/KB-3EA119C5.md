Set a 540x540 PNG as a category's only image (group=images) via POST /api/catalog/categories, then opened the category's storefront page on a 1920x1080 viewport. The header banner (right of the title) requested the original asset URL with no size suffix and rendered it at about 503x140, object-cover cropped, so only a horizontal strip of a square image shows. Product cards on the same page requested <name>_md thumbnails. So generating image-tools thumbnails does not change what this banner downloads. What matters is the image's aspect ratio (a wide banner around 3.6:1) and the original file's weight.
