On theme 2.60.0-pr-2523-466f with Return 3.1005.0-pr-28-fb4f, the return wizard Continue (createReturn), Submit return (submitReturn) and Cancel return (cancelReturn) were run as an organization maintainer who had just signed in and never opened the organization tab, as the same maintainer after opening the organization tab earlier in the same app instance, and as a buyer without the organization permission. The console showed no Apollo warning in any run (only image 404s and a WebSocket clean close). After CancelReturn the client re-sent only GetReturn, the query mounted on the details page; GetReturns and GetOrganizationReturns were not refetched. Navigating in-app back to My returns and to the organization tab showed the new status without a reload.
