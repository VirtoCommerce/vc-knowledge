The live --color-primary-500 is #e5451c, --color-neutral-400 #a89a8b and --color-neutral-300 #d9cdb8. /sign-in opened on an email-first view, with no Remember me checkbox. The Email field wrapper (.vc-input__container) has border 1px #a89a8b against the surrounding #f5f1ea = 2.44:1. The header 'Search products and parts' wrapper is 1px #d9cdb8 = 1.39:1. So the Next theme carries the same sub-3:1 field-boundary pattern as the vc-frontend 2.x UI kit (neutral-400 #a3a3a3 = 2.52:1 there).
