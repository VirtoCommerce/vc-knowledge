In the Page Builder Designer (page-builder-designer/index.html#/pages), after the toolbar (Desktop, Anonymous, Pages, Theme settings, Preview, Unpublish) Tab reaches Page actions, Settings, Page Header, then per section: Insert section before/after (add_circle), a Select <name> checkbox, the section title button, Actions for <name> (tune), Move section N (drag handle), then Add block, and only then the storefront preview iframe. On a focused Move section N handle ArrowUp/ArrowDown move the section one slot, focus stays on the moved handle, and an aria-live region announces 'Section moved to position X of 3'. Escape closes the Add block panel and the section editor (an open ng-select dropdown closes first) and returns focus to the trigger/row. Observed on PageBuilderModule 3.1030.0-pr-165-1ab4.
