Classic (AngularJS) Admin, Catalog > Import > VirtoCommerce CSV import, comma CSV with columns Sku,Name,CategoryPath,Vendor,AltName. In Map columns I cleared CategoryPath and Vendor with the x and mapped Name to AltName, then OK. Reopening Map columns showed Name=Name, CategoryPath=CategoryPath, Vendor=Vendor again (the auto-mapping); no new GET mappingconfiguration was sent, so the reset is client-side. Start import then POSTed propertyMaps with the auto-mapping, the CSV category was created, Vendor was written and the product name came from the Name column. Without reopening the blade, OK + Start import sent the edits (csvColumnName null for cleared fields, AltName for Name) and they were applied. Reproduced the same way on CatalogCsvImport 3.1008.0 (vcst_qa), 3.1002.0 (vcptcore_stable) and 3.1007.0 (vcptcore_regression). Source: openMappingStep() re-copies initialImportConfiguration on every open; changed in 3.1009.0 and 3.1000.4 (fixed live verification pending). The Admin Shell (Vue) import page is a different implementation and keeps the edits (KB-C27CECBE).
