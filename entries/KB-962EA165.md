On the Multilanguage Page blade (#/page-builder-draft/multilanguage-details/{id}) clicking Link existing on a Missing fr-FR row opens the dialog 'Link an existing fr-FR page' with a Landing Page select. Opening the select lists only fr-FR Landing pages of the store, but the option list renders beneath the dialog's blurred overlay: a pointer click on an option is intercepted by the dialog body/footer, typing in the option search box and ArrowDown+Enter do not select anything, and the Link button stays disabled. Same at 1920x1080 and 1366x768 in Edge (Playwright). The REST call POST /api/page-builder-multilanguage-pages/{id}/link/{groupId} works (200). Other selects (Filters panel, Language on the page blade) open above and are selectable.
