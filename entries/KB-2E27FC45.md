Signed in as a multi-org B2B buyer on B2B-store, I placed a Subscribe & Save order paid with saved card Visa 4242 (MockStoredCardPaymentMethod), giving an Active subscription that pays with that card (also the default). On /account/payment-methods, Remove -> confirm "Remove this card?" -> OK sent Mutation.removeSavedPaymentMethod(id). Response: errors[0].message "This card pays for a subscription. Choose another card for it first.", extensions.code SAVED_PAYMENT_METHOD_ERROR, data null; the card stays Active and listed. The page shows only the red toast "Something went wrong. Please try again." - the server's customer message is not surfaced. Reproduced twice. The same generic toast/inline alert replaces the server message on addSavedPaymentMethod errors ("Your card has expired.").
