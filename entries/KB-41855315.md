In the SalesRep storefront plugin bundle (customer-orders chunk), the empty state renders sales_rep.orders.no_results ("No orders match this filter") whenever a search or filter is active, but its button slot (sales_rep.customer_orders.reset_search, "Reset search") is attached only when a search term is present. A zero match caused by filters alone therefore has no control inside the empty-state region; the chip row above the grid (per-chip remove buttons + common.buttons.reset_filters) is the only clearing affordance. The code is identical in the 3.1014.0 plugin bundle.
