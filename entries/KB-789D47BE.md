On the scoped endpoint /graphql/sales-rep, salesRepCustomer(organizationId) for an organization the calling rep does not serve returns HTTP 200 with data.salesRepCustomer null and no errors[]. A nonexistent organization id is indistinguishable by this query, so it cannot separate 'unserved' from 'does not exist'; Query.organization(id) on /graphql likewise returns errors[Access denied., code Forbidden] for any organization the rep is not a member of. To prove an unserved organization exists without admin rights, list it through a different rep's salesRepCustomers. SalesRepCustomer / SalesRepCustomerDetails expose organizationId and organizationName (no id or name fields).
