On vcptcore_qa1 (DetailedErrors false, theme 2.59.0-pr-2477-cba9, OTP 3.1000.0-pr-1-185e, 2026-10-01) POST /api/otp/request for a fresh unregistered address returned 200 {succeeded:true, error:null, maskedEmail:"a•••7@qa.test", lockoutSecondsRemaining:null}; the form showed the same "Check your email / We sent a code to a•••7@qa.test." step as for a real buyer; no OtpSignInEmailNotification was created for it. A wrong code for that address returned 400 invalid_grant code invalid_code "The code is invalid or has expired." with count 3, identical to a real account, so the "count" field is not a per-user failed-attempt counter. With DetailedErrors on, the same request returned user_not_found and the UI said "User not found".
