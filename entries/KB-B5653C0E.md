2026-10-13, theme 2.59.0, CustomerReviews 3.1007.0: an eligible buyer (completed order for the product) opened the inline FEEDBACK form, picked two JPEGs (~140 kB each) via 'Browse your files'. Each file triggered POST /api/files/review-images -> HTTP 200 with body [{succeeded:false, errorCode:'INVALID_SCOPE', errorMessage:"Unknown scope 'review-images'", errorParameter:'review-images'}]. The form listed each file with the text "Unknown scope ''." (the scope name is blank in the UI message) plus "Fix file upload errors to continue." Removing both files via 'Remove file' cleared the error, and Submit (rating + comment) then succeeded with confirmation "Your feedback has been successfully submitted and is awaiting confirmation. Thank you!" and a review in status New with 0 images. As with other upload scopes, the File Experience API reads scopes only from the platform FileUpload configuration, so this is stand configuration, not a build property; the failure is in the body under HTTP 200.
