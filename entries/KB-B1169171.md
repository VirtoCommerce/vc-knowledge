Admin token, TaskManagement 3.1005.0. I created two tasks with isActive:true and closed one with POST /api/task-management/finish?id=…&completed=true and the other with completed=false. Both then read isActive:false (completed true / false). In the Admin Tasks app, All tasks sent POST /api/task-management/search with body {take:20, sort:"createdDate:DESC", skip:0}, which carries no isActive. It listed both closed tasks ("1–2 of 2"). Archive tasks listed the same two. Over REST, a search without isActive returned both, isActive:false returned both, and isActive:true returned 0. The backend filters correctly when asked. The All tasks view simply never asks: at module tag 3.1005.0, workTasksList.vue calls useWorkTasksList without defaultFilters, while the Archive composable passes {isActive:false}. The user guide (Tasks > Using application) says "All tasks opens all currently active tasks" and that Complete / Reject archive the task, so the UI contradicts the documented behaviour. Earlier runs saw the same through the blade's Complete and Reject buttons.
