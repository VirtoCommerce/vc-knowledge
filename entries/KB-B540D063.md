On x-cart 3.1038.0-pr-141 / cart 3.1011.0-pr-194, 2026-10-05: the owner's changeWishlist(listId, message) with no scope returns HTTP 200 with the list but the message is not changed, on both a Customer-scope list (old message kept) and an Organization-scope list (stays null). A non-owner Write member of an Organization list sending the same gets the same 200 no-op (customerId, scope unchanged), while any scope-bearing edit by that member is Forbidden. Clients must send scope together with message.
