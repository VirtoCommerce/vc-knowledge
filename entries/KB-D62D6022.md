Rep with a never-saved layout (Query.layout scope salesRepCustomerProfile storeId B2B-store = null): profile renders mainLeft = sales, orders, top_sellers, coupons (Sales statistics first). Planted via Mutation.saveLayout a document whose mainLeft = top_sellers, orders, coupons (no sales), other regions unchanged. Reloading /company/my-customers/<served org GUID> rendered mainLeft = top_sellers, orders, coupons, sales: the saved blocks kept their saved order and Sales statistics was appended last; no console error. The stored document still lacked sales until the next UI Save, after which it included it. Hiding the block (Hide + Save) stores it hidden:true at the end of mainLeft; after reload SalesRepMonthlyOrderStatistics is not sent (it is sent with the block visible); restoring it from Hidden widgets + Save brings it back at the end of the left column, not at its previous position. Reset + Save restores sales first.
