On x-cart pr-141 / sales-rep pr-21, changeWishlist with addSharedWithIds or removeSharedWithIds but no scope returns HTTP 200, no errors, and writes nothing, on a Customer list and on a Private list, even for an org the rep does not serve. Adding an unserved org (alone or with a served one) returns Access denied (Forbidden) and writes nothing. An empty Customer set, the same id in add and remove, a legacy sharedWithId on a 2-target list, and a message over 1024 characters all return INVALID_OPERATION with the generic text Error trying to resolve field 'changeWishlist'. instead of the server's specific message. Legacy sharedWithId on a 1-target list replaces the target and keeps the sharing key.
