As admin, POST api/product-subscription/plans with {storeId, name, isActive:true, priority:0, discountType:"Percent"|"FixedAmount"|"None", discountValue, intervals:[{unit:"Month"|"Week"|"Day"|"Year", count, isDefault}], productIds:[...], categoryIds:[]} returned 200 with the saved plan (each interval gets an id). GET api/product-subscription/plans/{id} returns it; changing productIds on that object and POSTing it again to the same endpoint updated the plan in place (200). POST api/product-subscription/plans/search {take} returned {totalCount, results}; with no plans the stand returned totalCount 0. POST api/product-subscription/subscriptions/search {take} returns subscriptions with number SUB<yyMMdd>-<n>, status, customerId (the user id), storedPaymentMethodId, consentId, nextOrderDate, currentRenewalId. POST api/product-subscription/scheduler/run returned 200 and processed due renewals within the request.
