On vcst_qa (platform 3.1090.0-pr-3133, MFA 3.1000.0-pr-1-cf83, global MFA on, DetailedErrors on) one created employee, one request at a time, sent grant_type=mfa with the same twoFactorToken and code 000000: attempts 1 to 4 answered 400 invalid_code, attempt 5 answered 400 user_is_temporary_locked_out with lockoutSecondsRemaining 900, never an access_token. The correct code on the same token then also answered user_is_temporary_locked_out (900 s). No code_attempts_exceeded was seen; the refusal is the platform account lockout (5 failures, 15 minutes), so whoever knows the password can lock the real user out. Each wrong code uses the same counter as wrong passwords.
