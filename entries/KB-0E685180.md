UCP 3.1011.0-pr-13, B2B-store, signed-in B2B buyer. checkout_and_handoff returned top-level continue_url {storefront}/checkout?ucp_session=<token> (the cart object's own continue_url is {storefront}/cart/{cart_id}) and next_step_after_payment = {tool: track_order, arguments: {cart_id, placed_after: <handoff issued_at>, buyer_id, language}}; the handoff object itself carries no issued_at field. After the buyer placed the order in the storefront from the handed-off cart (order created 19:03:32Z, placed_after 19:01:36Z), track_order {cart_id, placed_after} returned order + orders[1] = the new order, status New, line items with their status. placed_after later than the order -> isError 'No order was placed from cart ... at or after ...'. placed_after = 2026-01-01 -> orders[2]: an older order from the same storefront cart id plus the new one (the storefront reuses the default cart id across orders). REST GET /ucp/v1/orders?cart_id= with the buyer token returns the same order. track_order/get_order without a token and without buyer_id -> invalid_request 'buyer_id is required for anonymous continuation'; with another buyer's real id as buyer_id -> 403 buyer_context_mismatch.
