Placed an order from /cart with one selected line plus an auto gift. Mutation.createOrderFromCart returned the order with no errors[]. The following Query.cart (same storeId/userId/currency, no cartId) returned the SAME cart id with itemsQuantity 0, no shipments/payments, and validationErrors(ruleSet '*') = [ALL_LINE_ITEMS_UNSELECTED]. A later bulk add went into that same cart id. Matches XOrder CreateOrderFromCartCommandHandler.CleanupCart, which removes the selected line items, clears shipments/payments/coupons/PO/comment, refreshes CheckoutId and saves the cart rather than deleting it. Unselected lines would therefore survive the order.
