Organizations, contacts, vendors and employees are platform members under /api/members: GET /api/members/{id}, POST /api/members/search, POST and PUT /api/members, and delete as DELETE /api/members with ids as query parameters - the path form DELETE /api/members/{id} returns 405. /api/customer/members/{id} returns 404 even for ids that exist, which reads like a deletion. A deleted member's GET returns 200 with an empty body rather than 404, so check the body; a keyword search with zero results is the authoritative absence check.
