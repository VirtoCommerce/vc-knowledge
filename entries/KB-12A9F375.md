2026-10-09, storefront 3.0.0-alpha.2685: list line for a product with xAPI maxQuantity 0 renders <input type=number min=1 max=0>. Focused the input and pressed ArrowUp twice: value stayed 1 and Save changes stayed disabled. On the same product's PDP the quantity input (min 0, max 1225) went 0 -> 2 on two ArrowUp presses (and the PDP stepper added the item to the cart). Consistent with the HTML rule that stepUp/stepDown do nothing when min > max. Typing a number still works, so keyboard users have a workaround.
