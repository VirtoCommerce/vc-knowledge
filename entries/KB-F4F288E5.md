GET /api/site-builder/git/connection lists every store with a repository <org>/site-<store> (enabled:false); GET /api/site-builder/git/site?storeId=QA-STORE returns configured:true, source:'app', error 'The GitHub organization ... was not found, or the platform has no access to it.'. On B2B-store (GitContentEnabled unset) history/status and history?item=page:{id} -> 200 setupRequired, but Admin Shell > Marketing > Sites > B2B-store > History opens 'Version history' with an alert 'Error' carrying that message, Repository status Off, '(not created yet)', buttons Enable history / GitHub connection - not the 'Not connected' explanation seen before the app existed. On QA-STORE with GitContentEnabled=true: designer/save of a page draft -> 200 with no warning, history/status -> {status:'enabled'}, history?item=page:{id} -> setupRequired; back to false -> setupRequired.
