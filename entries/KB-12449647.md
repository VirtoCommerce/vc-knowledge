vcst_qa, theme 2.63.0-alpha.2681, B2B-store, 2026-11-26. Password form of /sign-in (reached via 'Sign in with a password instead'): opened as plain /sign-in, a successful sign-in (POST /connect/token 200) lands on the home page '/' with the user's name in the header — not on /account. Opened as /sign-in?returnUrl=/account/profile (after a popup logout from that page), the same sign-in lands on /account/profile. Seen for a personal buyer, a self-registered user and B2B buyers.
