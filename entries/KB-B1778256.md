Placed two orders through the /cart checkout (Manual payment) on a store with an active no-coupon auto-gift promotion. Each CreateOrderFromCart response held the shopper's lines plus one gift line (isGift=true). The place_order event in window.dataLayer had items.length equal to the order line count (2 for a one-product order, 3 for a two-product order) and items_count equal to the same; the gift appeared as its own item with item_id = the gift SKU, price 0, quantity 1, and promotion_id / promotion_name / promotions set to the promotion. item_id values matched the order line SKUs one to one with no duplicates. Consequence for test authors: an expected item count must be read from the placed order, not from the products the case added.
