Order CO261013-00005, Addresses widget on /apps/admin-shell#/orders/order/<id>. English: "100 Main St, New York, New York, 10001, United States". Arabic: first visual line "Main St, New 100"; Hebrew: "Main St, New York, 100". The address string is placed in an RTL paragraph without LTR isolation, so the leading number (weak direction) is reordered to the line end. The classic admin (/#!/workspace/orders) in Hebrew shows the same address as "US, New York, New York, 100 Main St" (component order reversed by its own template), so the classic screen is also wrong but differently. Spec item L-04 says mixed-direction data keeps its order.
