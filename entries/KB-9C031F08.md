Signed in as an organization member with 22 org addresses, opened the Select address popup from the shipping-address edit button on /cart, typed a keyword matching nothing and pressed the magnifier. GetCurrentOrganizationAddresses returned totalCount 0 with no errors; the table body showed 'You do not have any addresses yet' (the same copy used when the user has no addresses), the Country/State/City facet dropdowns disappeared, and the keyword stayed in the box with a Clear (X) control. vc-frontend locales carry only select_address_modal.no_addresses_message, no separate no-results string. Searching is submit-based (Enter or magnifier); typing alone sends no request.
