Admin SPA, contact detail > 'Organization memberships' widget > click the membership row: the membership detail blade (organization name, roles, invite status, locked state) renders, but the console logs twice 'TypeError: Cannot read properties of null (reading toLowerCase)' from the VirtoCommerce.Customer admin bundle (inside Array.map) as an unhandled rejection. In the same load GET /api/platform/settings/v2/tenant/Store/B2B-store/values returned "Customer.MembershipRolesWhitelist": [null], while the platform-level GET /api/platform/settings/values/Customer.MembershipRolesWhitelist returned ["Organization maintainer","Organization employee"]; the membership record and all role names were non-null. The store override holding a null element is the likely trigger; the blade has no null guard.
